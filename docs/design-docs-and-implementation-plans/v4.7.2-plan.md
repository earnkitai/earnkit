# v4.7.2 Every reply has a next step: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the three reply gaps the 2026-10-31 dogfood of v4.7.1 found on the owner's own account.

**Spec:** the owner's dogfood report (screenshot, 2026-10-31, 10:04 AM):
- "The 'why' repeats 'None of these fit EarnKit on what EarnKit can see yet' instead of saying what EarnKit would need for Arc."
- "The money line leaves out a16z ($1M, also closes tomorrow) and the $105.5K total."
- "Asking again shows money but no next step."
- "The other four [Stripe] issues are unchanged." These aren't in this plan because the report text isn't in hand yet.

**Architecture:**
- **Money paragraph:** the "Open now" paragraph gains the open-grants total, the same figure as the landing chip and `/api/stats`. It also gains the soonest-closing open investment, named as an investment so it never reads as part of the grants total.
- **Ask:** the ranked no-fit ask (`check_fits`) stops being once-per-person. It names one program at a time.
  - Its why says what the project is missing for that program. The missing items are read from the program file and from what EarnKit already knows about the project.
  - Each program's ask stands aside after a no, a yes, or 3 unanswered showings, using v4.7's apply rules (`DECLINE_MS`, `APPLY_UNANSWERED_MAX`). Then the next program is asked.
  - With no program left, the quiet reply ends with `ASKS_HINT`, so it always says what to do next.

**Tech Stack:** Next.js 16, TypeScript, Postgres, node:test via tsx.

## Exact copy

- **Open money paragraph:** `Open now: {total} in grants. {grant}, {amount}, {when}. [{grant2}, {amount}, {when}.] [{investment}, {amount} investment, {when}.]`
  - The grant parts are unchanged from v4.7.1.
  - The investment part names the soonest-closing open investment the builder hasn't applied to. Rolling ones go last, and there is at most one.
  - `{total}` is omitted (with its sentence) when it is 0.
  - Expected on the owner's account today: `Open now: $105.5K in grants. Arc Microgrants, 500 USDC × 8 grants, closes Nov 1. Base Builder Grant Program, $5,000, rolling. a16z speedrun SR008, up to $1M investment, closes Nov 1.` The investment's amount cell is `upToCell(prizeOf(c))`. If that cell already reads "up to $1M", don't double the "up to".
- **Needs why:** `{program} needs {name} {needs}.`
  - `{needs}` is a list of 1 to 3 items joined with ", " and a final " and ".
  - In this order:
    - `on {Chain} mainnet` when the program has `needs_contract: <chain>` and the project isn't known on that chain
    - `in a public repo` when `needs_repo` and no verified repo
    - `live at a link` when a live link is a required submission field and none is known
  - Example: `Arc Microgrants needs EarnKit on Arc mainnet.`
  - With nothing known missing: `Nothing EarnKit can see rules {name} out of {program}.`
- **Needs question:** `Want the steps to get {name} ready for {program}?` (`{program}` is `shortTitle`).
- **No program left:** the quiet reply's last paragraph is `ASKS_HINT` (`Ask me anytime: where do I stand, what can I apply to, or draft my application.`), with no question.

## Review Focus

1. A ranked builder with no fit and open programs never gets a reply without either one question or `ASKS_HINT` as its last paragraph. This holds for the 1st, 2nd, 3rd and 4th find in a row.
2. The total in the reply equals `/api/stats` `open_money_usd` rendered by `moneyText`. The investment is never summed into it.
3. A program the builder applied to, drafted, or said no to is never asked about or named as the investment.
4. A yes to the needs ask still runs `checkNeedsNote(program)` for that same program. A no declines that program only, for `DECLINE_MS`.
5. A builder with a fit still gets the v4.7 money-first reply unchanged.

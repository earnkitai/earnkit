# v6.1.4: in-person programs never take a remote program's slot

## Goal

The default first reply always leads with something the builder can apply to now. With the 52-file catalog the five
richest ready programs were all in person (YC, Alliance, EF, Z Fellows, Solana Incubator), so the one remote ready
program (Arbitrum Mentorship Program: Cohort 2) fell out of the top 5 and the reply had no "Ready to apply" block.

## Ruling (binding)

- The default list shows up to MAX_READY (5) remote ready programs, ranked as today.
- Then up to 2 in-person ready programs (MAX_IN_PERSON) in their own block, ranked as today.
- In-person programs never take a remote slot; remote programs never take an in-person slot.
- `filter.all` still shows everything. The `more` count counts what was cut from both.
- Numbering stays in display order: remote ready, gaps, then in person (`numbered` in reply.ts). Gaps are unchanged.

## Test

an unlinked find for the earnkit fixture has a "Ready to apply" block that includes Arbitrum Mentorship Program:
Cohort 2 and an in-person block of at most 2. Written first and seen failing.

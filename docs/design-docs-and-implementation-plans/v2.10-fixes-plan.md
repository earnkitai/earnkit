## Plan Rulings (spec gaps)

- **R1, traction's range.** The formula `3·band(tx) + 2·live_ok + 1·band(commits)` with bands 0, 1, 2 reaches 10, not the stated 9. The formula is binding; the range is 0 to 10. Thresholds (4) are unaffected.
- **R2, low-odds reasons,** first that applies: the repo isn't product tier (its `missingSignalNote`, else "not enough signs of a real product yet"); the row's chain is only mentioned ("not deployed yet"); `tx_count` is 0 on Base ("no users yet"); the live link didn't pass ("live link not loading"); else "little recent activity". An unknown `tx_count` (not Base) is never named.
- **R3, local repos' commits.** EarnKit never reads a local repo, so `commits_90d` is 1 (band 1) when `last_commit_at` is within 90 days, else 0.
- **R4, Blockscout budget.** `find` reads at most 2 counters (`LIST_BUDGET.txCounts`); a single-repo eligibility check (`find` with `program_id` and `repo`) reads at most 1 (`ENTRY_BUDGET.txCounts`). Other entry steps read none. A successful read is cached 24 h in `url_checks` (`key txcount:base:<addr>`, `n`); a failed read is not cached and counts as unknown.
- **R5, the error page's text.** `url_checks` gains `note text` (beside the spec's `n`) to hold the matched phrase, so the cached failure can say what the page showed.
- **R6, deploy-config folders.** `deployments/<network>/` counts when `<network>` lowercased is `<chain>`, `<chain>mainnet` or `<chain>-mainnet` for a chain in `CHAINS`. A cached `chains` entry without `basis` reads as `mention` (the cache lives 1 hour).
- **R7, starters.** `EARNKIT_STARTER_NAMES` (in `earnkit-orgs.ts`) is copied from `github.com/earnkitai/chain-kits` (each example's `package.json` name and README first heading), with the link in a comment. Unreadable: the list stays empty and the task report says so.
- **R8, the App proof flow.** The "allow read access" link is a v2.9 nonce with the new purpose `app` (bound to the installation, the repo and, when there is one, the entry; 15 min; single use). `/github/verify?n=` runs the v2.9 confirm page and OAuth sign-in; for purpose `app` the callback stores the login on the nonce (not a verification) and 303s to `https://github.com/apps/<slug>/installations/new?state=<nonce>`. GitHub sends the builder to the setup URL `/github/verify/app?installation_id=&state=`, which needs the same `__Host-` cookie, consumes the nonce atomically, reads the installation with the App JWT, and passes when the installation's account login equals the nonce's login, or the installation token's `GET /repos/{o}/{r}/collaborators/{login}/permission` says `admin`, and the installation's repositories include the repo. A pass writes `github_verifications` with `via = 'app'`, `github_installation_id`, `purpose = 'app'`.
- **R9, what the App grants.** Read access only: matching, `repoCodeFacts` and the gate's `earnkit.txt` read go through a 1-hour installation token minted per call. The launch still needs the v2.9 proof (proof line or a wallet-bound sign-in, G10, G11).
- **R10, a private entry on public pages, fail closed.** `projects.repo_private` is set at confirm: true unless `github_repo_facts` holds a row for that full name read with EarnKit's own token (`via_app = false`). `/p/[id]` and `/bonus` show the repo link only when it's false; tokens.fun gets `website` = the live link, never the repo URL, when it's true.
- **R11, the generated mark.** Rendered by `next/og` at `/api/projects/<id>/mark` from the project id (no letters, no stored bytes, immutable cache). `token-image` stays for old links and is never sent again.
- **R12, the deadline line's place.** In `find`'s first reply the spec's item 2 order wins (news, entries, deadline line, then the lead); in every other reply the deadline line is first.
- **R13, shared clients and the guide.** `working_on` is installation-wide (G7), so on a shared client "first `prepare` for a program" is `coach_asked` not set.
- **R14, the first reply's lead.** Always "Your <repo> can win <prizeOf> on <chain> by <shortDate>. Want me to finish it?" ("on <chain>" dropped for an any-chain program, "by <date>" dropped for a rolling one). No repo reported: "<$X> is open. Want the 3 easiest?"; repos but no good-odds row: the spec's "No repo fits yet. <$X> is open; want the 3 easiest?". An investment row never leads.
- **R15, `confirm` arguments.** `yes: true` (go), `skip_token: true` (go without a token), `check: true` (poll), `project_id` (an existing entry's launch, as `launch_token`), plus today's `program_id`, `project`, `answers`, `token`, `wallet`, `agent`, `signed_in`, `image_data`, `image_url`, `builder_x`, and for EarnKit campaigns `contracts`, `deployer_signature` (described only while a campaign is open, v2.8 Ruling 23). An EarnKit campaign program dispatches to today's `record_submission` handler (one-step entry).
- **R16, `tell` arguments.** `submitted: { program_id, external_submission_url?, project_id? }` (`project_id` is required on a shared client, as v2.9 outcomes); `pickup: 'yes' | 'no'`; plus today's `program_status`, `repo_facts`, `weekly_email`, `signed_in`. `submitted` loads the entry (by `project_id`, else this installation's newest in that program) and its saved `application.answers`, then calls today's `record_submission` handler with `builder_submitted: true`.
- **R17, the alias window.** `ALIASES_UNTIL = new Date('2026-11-09T00:00:00Z')` (30 days after the spec's approval, plus one); after it an old name gets the SDK's normal unknown-tool error. The owner may move the date.
- **R18, deploy cost units.** Counters are in micro-USD. ETH is priced by `prices.ts llamaPrice('coingecko:ethereum')` (DefiLlama, free); Arc's gas token is USDC at $1 with the decimals from Arc's docs. A price read that fails refuses the deploy (fail closed). Before sending, the upper bound `gasLimit × maxFeePerGas` is reserved on the month counter; after the receipt the difference to `gasUsed × effectiveGasPrice` is given back. `TOP_UP` fires when a chain's balance is worth under $0.25 (one capped deploy).
- **R19, the deploy ownership proof.** The same proof a launch accepts, minus the wallet binding: this installation's proof line in `earnkit.txt`, a `github_verifications` row for the repo key (v2.9 sign-in or App, scoped as `verifiedFor`: a shared client only with its code's login), checked by a new `token-gate.ts repoOwnershipPasses`.

// match.ts
const DEPLOY_DIRS: { re: RegExp; chainOf: (m: RegExpMatchArray) => Chain | null }[] = [
  // Foundry: broadcast/<script>/<chainId>/
  { re: /^broadcast\/[^/]+\/(\d{1,8})\//, chainOf: (m) => mainnetOf(Number(m[1])) },
  // Hardhat Ignition: ignition/deployments/chain-<id>/
  { re: /^ignition\/deployments\/chain-(\d{1,8})\//, chainOf: (m) => mainnetOf(Number(m[1])) },
  // hardhat-deploy: deployments/<network>/ (R6)
  { re: /^deployments\/([^/]+)\//, chainOf: (m) => networkChain(m[1]) },
];
const mainnetOf = (id: number): Chain | null => {
  const c = chainOfId(id);
  return c?.mainnet ? c.chain : null;
};
const networkChain = (name: string): Chain | null => {
  const n = name.toLowerCase();
  return CHAINS.find((c) => n === c || n === `${c}mainnet` || n === `${c}-mainnet`) ?? null;
};
/** The `[rpc_endpoints]` table of a foundry.toml, else ''. Pure. */
const rpcEndpoints = (toml: string) => toml.match(/^\[rpc_endpoints\]\s*$([\s\S]*?)(?=^\[|$(?![\s\S]))/m)?.[1] ?? '';

/**
 * v2.10 item 9: the mainnets a repo's deploy config or deploy output names: a network in a
 * hardhat.config.* (its chain id or a mainnet host), an [rpc_endpoints] entry in foundry.toml, or a
 * deploy folder in the tree. Pure.
 */
export function deployConfigChains(files: { path: string; text: string }[], paths: string[]): Partial<Record<Chain, string>> {
  const out: Partial<Record<Chain, string>> = {};
  for (const p of paths)
    for (const d of DEPLOY_DIRS) {
      const m = p.match(d.re);
      const chain = m && d.chainOf(m);
      if (chain) out[chain] ??= p;
    }
  for (const f of files) {
    const base = f.path.split('/').at(-1) ?? '';
    const scope = /^hardhat\.config\.[cm]?[jt]s$/.test(base) ? f.text : base === 'foundry.toml' ? rpcEndpoints(f.text) : '';
    if (!scope) continue;
    for (const [chain, net] of Object.entries(detectMentions([{ path: f.path, text: scope }])) as [Chain, Detection[Chain]][])
      if (net?.mainnet) out[chain] ??= `${f.path}: deploy config`;
  }
  return out;
}

// safe-fetch.ts
export const PROBE_MAX_BYTES = 65_536;
export const ERROR_TEXT_MAX = 5_000;
const ERROR_PHRASES: RegExp[] = [
  /\b404\b/, /not found/i, /NOT_FOUND/, /DEPLOYMENT_NOT_FOUND/,
  /There isn't a GitHub Pages site here/i, /Application failed to respond/i,
  /Internal Server Error/i, /Bad Gateway/i, /Cannot GET \//, /Site not found/i, /This page could not be found/i,
];
export class ErrorPageError extends SafeFetchError {
  constructor(readonly phrase: string) {
    super(`shows an error page (${phrase})`);
    this.name = 'ErrorPageError';
  }
}
/** The page's <title> and its visible text (scripts, styles and tags removed, whitespace folded). Pure. */
export function visibleText(html: string): { title: string; text: string } {
  const title = (html.match(/<title[^>]*>([\s\S]*?)<\/title>/i)?.[1] ?? '').replace(/\s+/g, ' ').trim();
  const text = html
    .replace(/<(script|style|noscript|template)\b[\s\S]*?<\/\1\s*>/gi, ' ')
    .replace(/<[^>]+>/g, ' ')
    .replace(/&nbsp;/g, ' ')
    .replace(/\s+/g, ' ')
    .trim();
  return { title, text };
}
/**
 * v2.10 item 14: the error phrase a short page shows (its title first, else the first matching
 * sentence of its visible text, at most 80 characters), or null. Only pages whose visible text is
 * under 5 KB are judged, so a real page that mentions "404" passes. Pure.
 */
export function errorPageText(html: string): string | null {
  const { title, text } = visibleText(html);
  if (text.length >= ERROR_TEXT_MAX) return null;
  if (ERROR_PHRASES.some((re) => re.test(title))) return title.slice(0, 80);
  const hit = ERROR_PHRASES.map((re) => text.match(re)).find(Boolean);
  if (!hit) return null;
  const at = hit.index ?? 0;
  const start = Math.max(0, text.lastIndexOf('.', at) + 1);
  return text.slice(start, start + 80).trim();
}

// match.ts
export const GOOD_ODDS_TRACTION = 4;
const band = (n: number | null, mid: number, high: number) => (n === null || n <= 0 ? 0 : n < high ? (n >= mid ? 1 : 0) : 2);
/** v2.10 item 6 (R1): 3·band(tx: 0, 1-49, 50+) + 2·live_ok + 1·band(commits: 0, 1-9, 10+), 0 to 10. Unknown counts score 0. Pure. */
export function traction(f: TractionFacts): number {
  return 3 * band(f.tx_count, 1, 50) + 2 * Number(f.live_ok) + band(f.commits_90d, 1, 10);
}
/** v2.10 item 6, R2: good odds are product tier and traction 4+; else low, with the first reason that applies. Pure. */
export function productOdds(p: Pick<Product, 'tier' | 'missing'>, t: TractionFacts, score: number): { odds: Odds; low_reason: string | null } {
  if (p.tier === 'product' && score >= GOOD_ODDS_TRACTION) return { odds: 'good', low_reason: null };
  if (p.tier !== 'product') return { odds: 'low', low_reason: missingSignalNote(p as Product) ?? 'not enough signs of a real product yet' };
  if (t.tx_count === 0) return { odds: 'low', low_reason: 'no users yet' };
  if (!t.live_ok) return { odds: 'low', low_reason: 'live link not loading' };
  return { odds: 'low', low_reason: 'little recent activity' };
}
/** v2.10 items 6, 9: a row is low odds when its repo is, or when its chain is only mentioned. Pure. */
export function rowOdds(p: Product | undefined, v: Verdict, chains: Detection): { odds: Odds; low_reason: string | null } {
  if (!p || p.odds !== 'good') return { odds: 'low', low_reason: p?.low_reason ?? 'not enough signs of a real product yet' };
  const mentioned = (Object.values(chains) as Detection[Chain][]).some((c) => c?.mainnet && c.basis === 'mention' && c.evidence !== CLAIMED_MAINNET);
  return v.missing.includes('mainnet_deploy') && mentioned ? { odds: 'low', low_reason: 'not deployed yet' } : { odds: 'good', low_reason: null };
}

const ADDRESS_RE = /\b0x[0-9a-fA-F]{40}\b/;
const HASH_RE = /\b0x[0-9a-fA-F]{64}\b/;
const HEX_RUN_RE = /\b[0-9a-fA-F]{16,}\b/;
const KEY_VALUE_RE = /(?:^|[,;\n])\s*[A-Za-z][\w ]{0,20}:\s*[\w$.%-]+\s*(?:[,;\n]\s*[A-Za-z][\w ]{0,20}:\s*[\w$.%-]+)+/;

const NUMBER_RE = /\d[\d,.]*/g;
/** v2.10 item 11: why a description field isn't plain words, as an agent fix, or null. Pure. */
export function plainProblem(text: string, kind: PlainKind, limit: { max_chars?: number; limit_words?: number } = {}): string | null {
  const t = text.trim();
  if (!t) return null;
  if (HASH_RE.test(t) || ADDRESS_RE.test(t) || HEX_RUN_RE.test(t)) return 'raw address or hash';
  if (KEY_VALUE_RE.test(t)) return 'key: value list';
  if (t.split(/(?<=[.!?])\s+/).some((s) => (s.match(NUMBER_RE) ?? []).length >= 4)) return 'too many numbers in one sentence';
  if (kind !== 'how_it_works' && URL_RE.test(t)) return 'link in a text field';
  if (kind === 'how_it_works' && (t.match(URL_RE) ?? []).length > 1) return 'more than one link';
  if (limit.max_chars ? t.length > limit.max_chars : limit.limit_words ? t.split(/\s+/).length > limit.limit_words : false) return 'too long';
  return null;
}

const attr = (tag: string, name: string) => tag.match(new RegExp(`\\b${name}\\s*=\\s*["']([^"']*)["']`, 'i'))?.[1] ?? null;
/** v2.10 item 12: the best logo a site names: apple-touch-icon, the largest raster icon of 128 px+, else og:image. Pure. */
export function pickIconHref(html: string, pageUrl: string): string | null {
  const abs = (h: string | null) => {
    if (!h) return null;
    try {
      const u = new URL(h, pageUrl);
      return u.protocol === 'https:' && !/\.(svg|ico)(\?|#|$)/i.test(u.pathname) ? u.href : null;
    } catch {
      return null;
    }
  };
  const links = [...html.matchAll(/<link\b[^>]*>/gi)].map((m) => m[0]);
  const touch = links.find((l) => /\brel\s*=\s*["'][^"']*apple-touch-icon/i.test(l));
  if (abs(attr(touch ?? '', 'href'))) return abs(attr(touch!, 'href'));
  const icons = links
    .filter((l) => /\brel\s*=\s*["'](shortcut )?icon["']/i.test(l))
    .map((l) => ({ href: abs(attr(l, 'href')), type: attr(l, 'type') ?? '', size: Math.max(0, ...(attr(l, 'sizes') ?? '').split(/\s+/).map((s) => Number(s.split('x')[0]) || 0)) }))

    .sort((a, b) => b.size - a.size);
  if (icons[0]) return icons[0].href;
  const og = html.match(/<meta\b[^>]*property\s*=\s*["']og:image["'][^>]*>/i)?.[0];
  return abs(attr(og ?? '', 'content'));
}

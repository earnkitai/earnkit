## Data

- `programs/*.json` gains optional `pool_usd` (number). Set only where the program's own source
  states a pool; `reward` must state the same amount (`$840,000`, `$840K`, `10,000 USDC`), checked
  by `programs:check` (`pool.ts` `poolStated`). A "+" right after it in `reward` carries through.
- `programs.pool_usd numeric` (additive `ALTER TABLE … ADD COLUMN IF NOT EXISTS`), written by
  `upsertProgram`, read by `listPrograms` into `programCard` → `poolFacts` (`pool_usd`, `pool_plus`,
  `pool_line`).
- Wording of a pool's big line (`poolLine`): USDC-stated → "10,000 USDC pool"; a title containing
  "grant" → "$200K in grants"; else "$840K in prizes".

| Program | pool_usd | Source text |
|---|---|---|
| colosseum-worlds-fair | 840000 | colosseum.com/worldsfair: "$840,000 in prizes" |
| monad-metropolis | 250000 | monad.xyz/…/metropolis: "$250,000+ USD prize pool" |
| arc-microgrants | 10000 | community.arc.io event page: "10,000 USDC pool" |
| circle-developer-grants | 200000 | circle.questbook.app (`pool_source_url`): "Circle 2026 Cohort 2 · $200k available" |
| base-builder-grants | (unset) | docs.base.org: "up to $5,000 in grants"; no pool |

Sum: $1,300,000 → "$1.3M+" ("+" for Monad's "+" and Base's missing pool).

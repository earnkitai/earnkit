# Sponsor Campaigns (v2.1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Anyone can create and fund a builder campaign through their agent. The pool sits in an
isolated escrow clone on Base, and EarnKit earns 10% only when prizes are paid.

**Architecture:**
- **Contracts:** a Foundry project at `contracts/` holds a timelock-owned factory
  (`EarnKitCampaigns`). It deploys one OpenZeppelin `Clones` copy of `EarnKitCampaign` per
  campaign, and that clone holds only its own pool.
- **App:** `apps/frontend` reads the chain only (viem, no keys). Sponsor drafts become ordinary
  `programs` rows once funding is confirmed from a transaction receipt.
- **Sponsor side:** sponsors act through one new MCP tool (`sponsor_campaign`), plus two
  wallet pages for sponsors whose agent has no wallet.
- **Admin:** the operator acts only through local `pnpm campaign` commands.

**Tech Stack:**
- Solidity 0.8.28 (EVM `cancun`) with Foundry 1.8 and OpenZeppelin Contracts **v5.4.0** (pinned).
- Analysis tools: Halmos, Slither, Aderyn.
- App: Next.js 16, postgres.js, zod v4, viem.

**Spec:** `docs/design-docs-and-implementation-plans/v2.1-sponsor-campaigns.md` (read it first; this
plan implements it and argues from it).

## Global Constraints

**Contracts:**
- OpenZeppelin Contracts pinned to `v5.4.0`. No proxy or upgrade path, no inline assembly, no
  external calls except ERC-20 transfers and `balanceOf`.
- Fee is `amount / 10` (rounded down) and `prize = amount - fee`. The fee is paid in full on award
  and refunded in full on refund.
- `AWARD_GRACE = 7 days`, `RECLAIM_AFTER = 60 days`, `MAX_WINNERS = 50`, and the contract-level
  `endsAt` is at most 180 days from now.
- The factory owner is a `TimelockController` with a 48 h minimum delay, the owner's wallet as
  proposer and executor, and no admin.

**App rules:**
- Campaign end is 3 to 90 days out. Text limits: title ≤ 80, theme ≤ 1,000, criteria ≤ 1,000,
  sponsor name ≤ 60, reason ≤ 280.
- Unfunded drafts expire 7 days after creation. Entries are re-scored when the last score is
  older than 6 hours.

**Keys:**
- The server never holds a private key.
- `OPERATOR_PRIVATE_KEY` and deployer keys exist only in a local shell.

**Display:**
- Sponsor text is rendered as plain text, and only `http(s)` links are made clickable.

**Tools:**
- EarnKit ends with **6** MCP tools: list_programs, get_program, prepare_submission,
  record_submission, launch_token, and sponsor_campaign.

**Rollout:**
- The starting cap is USDC $10,000 (`10_000e6`).
- An independent audit happens before any mainnet deployment.

## Review Focus

The input classes the spec implies but no happy-path test exercises. Each has a pinning test in the
named task.

1. **Too many decimals** (`"100.1234567"` USDC, which has 6 decimals). Expect a clear error at
   draft creation, not silent rounding. → Task 5 test `rejects amounts finer than the token's
   decimals`.
2. **Pools whose 10% doesn't divide evenly** (e.g. `100.000001` USDC). `status` must give the
   exact prize string, and an award summing to it must pass, while a sum off by 1 unit fails. →
   Task 5 test `prize is exact for pools that don't divide by 10`.
3. **Confirming the wrong transaction:** a receipt for another ref, a reverted transaction, a
   different amount, or the same transaction twice. The campaign must not go live wrongly or
   twice. → Task 6 tests on `fundingFromReceipt`, plus the e2e script in Task 10.
4. **One payout wallet used by two entries** (the same builder entered twice). The award must map
   to entries by the stored plan, not by address. → Task 7 test `matches award to entries by plan
   order, even with a repeated wallet`.
5. **Award attempts before the end date, or from a different installation.** Expect clear errors
   and no award link. → Task 7 test `award plan rejected before end and from another
   installation`.

import {ERC20} from "@openzeppelin/contracts/token/ERC20/ERC20.sol";

/// 6-decimal token like USDC, freely mintable in tests.
contract MockERC20 is ERC20 {
    constructor() ERC20("Mock USD", "mUSD") {}

    function decimals() public pure override returns (uint8) {
        return 6;
    }

    function mint(address to, uint256 amount) external {
        _mint(to, amount);
    }
}

/// Takes 1% on every transfer: must be rejected by createCampaign.
contract FeeOnTransferERC20 is MockERC20 {
    function _update(address from, address to, uint256 value) internal override {
        if (from != address(0) && to != address(0)) {
            uint256 cut = value / 100;
            super._update(from, address(0xdead), cut);
            value -= cut;
        }
        super._update(from, to, value);
    }
}

import {Test} from "forge-std/Test.sol";

        r = new address[](1);
        r[0] = a;

pragma solidity 0.8.28;

import {IERC20} from "@openzeppelin/contracts/token/ERC20/IERC20.sol";
import {Ownable} from "@openzeppelin/contracts/access/Ownable.sol";
import {Pausable} from "@openzeppelin/contracts/utils/Pausable.sol";
import {BaseTest} from "./Base.t.sol";
import {EarnKitCampaigns} from "../src/EarnKitCampaigns.sol";

    function test_create_movesFundsIntoTheCloneAndRecordsIt() public {
        uint64 endsAt = uint64(block.timestamp + 14 days);
        vm.expectEmit(true, true, false, false);
        emit EarnKitCampaigns.CampaignCreated(REF, sponsor, address(0), address(usdc), 1000e6, endsAt);
        EarnKitCampaign c = create(1000e6, endsAt);

        assertEq(usdc.balanceOf(address(c)), 1000e6);
        assertEq(usdc.balanceOf(address(factory)), 0);
        assertEq(factory.campaignOf(sponsor, REF), address(c));
        assertEq(c.sponsor(), sponsor);
        assertEq(address(c.token()), address(usdc));
        assertEq(c.fee(), 100e6);
        assertEq(c.prize(), 900e6);
        assertEq(c.endsAt(), endsAt);
        assertEq(uint8(c.state()), 1);
        assertEq(c.factory(), address(factory));

        EarnKitCampaign c = create(100_000_001, uint64(block.timestamp + 1 days));
        assertEq(c.fee(), 10_000_000);
        assertEq(c.prize(), 90_000_001);
    }

    function test_create_eachCampaignIsItsOwnAddress() public {
        EarnKitCampaign a = create(10e6, uint64(block.timestamp + 1 days));
        vm.prank(sponsor);
        address b = factory.createCampaign(keccak256("ref-2"), IERC20(address(usdc)), 20e6, uint64(block.timestamp + 1 days));
        assertTrue(address(a) != b);
        assertEq(usdc.balanceOf(address(a)), 10e6);

        vm.prank(sponsor);
        vm.expectRevert(EarnKitCampaigns.TokenNotAllowed.selector);

    }

    function test_create_reverts_zeroOrOverCap() public {
        vm.startPrank(sponsor);
        vm.expectRevert(EarnKitCampaigns.BadAmount.selector);
        factory.createCampaign(REF, IERC20(address(usdc)), 0, uint64(block.timestamp + 1 days));
        vm.expectRevert(EarnKitCampaigns.BadAmount.selector);
        factory.createCampaign(REF, IERC20(address(usdc)), CAP + 1, uint64(block.timestamp + 1 days));
        vm.stopPrank();
    }

        vm.startPrank(sponsor);
        vm.expectRevert(EarnKitCampaigns.BadEndsAt.selector);

        vm.expectRevert(EarnKitCampaigns.BadEndsAt.selector);
        factory.createCampaign(REF, IERC20(address(usdc)), 1e6, uint64(block.timestamp + 180 days + 1));
        vm.stopPrank();
    }

        create(1e6, uint64(block.timestamp + 1 days));
        vm.prank(sponsor);
        vm.expectRevert(EarnKitCampaigns.RefUsed.selector);
        factory.createCampaign(REF, IERC20(address(usdc)), 1e6, uint64(block.timestamp + 1 days));

        // Another sender can't squat this sponsor's ref, and can use the same bytes for itself.
        usdc.mint(alice, 1e6);
        vm.startPrank(alice);
        usdc.approve(address(factory), 1e6);
        address c = factory.createCampaign(REF, IERC20(address(usdc)), 1e6, uint64(block.timestamp + 1 days));
        vm.stopPrank();

    }

        vm.prank(owner);
        factory.setCap(address(fot), CAP);
        fot.mint(sponsor, 100e6);
        vm.startPrank(sponsor);
        fot.approve(address(factory), 100e6);
        vm.expectRevert(EarnKitCampaigns.AmountMismatch.selector);
        factory.createCampaign(REF, IERC20(address(fot)), 100e6, uint64(block.timestamp + 1 days));
        vm.stopPrank();
    }

    function test_pause_stopsCreateOnly_pauserCanPause_onlyOwnerUnpauses() public {
        EarnKitCampaign c = create(100e6, uint64(block.timestamp + 1 days));
        vm.prank(pauser);
        factory.pause();

        vm.prank(sponsor);
        vm.expectRevert(Pausable.EnforcedPause.selector);
        factory.createCampaign(keccak256("x"), IERC20(address(usdc)), 1e6, uint64(block.timestamp + 1 days));

        // Payouts and refunds still work while paused.
        vm.warp(block.timestamp + 1 days);
        vm.prank(sponsor);
        c.award(one(alice), oneAmt(90e6));
        assertEq(usdc.balanceOf(alice), 90e6);

        vm.prank(pauser);
        vm.expectRevert(abi.encodeWithSelector(Ownable.OwnableUnauthorizedAccount.selector, pauser));
        factory.unpause();
        vm.prank(owner);
        factory.unpause();
    }

    function test_pause_reverts_forStrangers() public {
        vm.prank(alice);
        vm.expectRevert(EarnKitCampaigns.NotPauser.selector);
        factory.pause();
    }

    function test_config_onlyOwner_andNoZeroAddresses() public {
        vm.startPrank(alice);
        vm.expectRevert(abi.encodeWithSelector(Ownable.OwnableUnauthorizedAccount.selector, alice));
        factory.setCap(address(usdc), 1);
        vm.expectRevert(abi.encodeWithSelector(Ownable.OwnableUnauthorizedAccount.selector, alice));
        factory.setOperator(alice);
        vm.expectRevert(abi.encodeWithSelector(Ownable.OwnableUnauthorizedAccount.selector, alice));
        factory.setTreasury(alice);
        vm.expectRevert(abi.encodeWithSelector(Ownable.OwnableUnauthorizedAccount.selector, alice));
        factory.setPauser(alice);
        vm.stopPrank();

        vm.startPrank(owner);
        vm.expectRevert(EarnKitCampaigns.ZeroAddress.selector);
        factory.setOperator(address(0));
        vm.expectRevert(EarnKitCampaigns.ZeroAddress.selector);
        factory.setTreasury(address(0));
        vm.expectRevert(EarnKitCampaigns.ZeroAddress.selector);
        factory.setPauser(address(0));
        factory.setOperator(bob);
        factory.setTreasury(bob);
        factory.setPauser(bob);
        factory.setCap(address(usdc), 0);
        vm.stopPrank();
        assertEq(factory.operator(), bob);
        assertEq(factory.treasury(), bob);
        assertEq(factory.pauser(), bob);
        assertEq(factory.capOf(address(usdc)), 0);
    }

    function test_renounceOwnership_isDisabled() public {
        vm.prank(owner);
        vm.expectRevert(EarnKitCampaigns.RenounceDisabled.selector);
        factory.renounceOwnership();
    }

    function test_constructor_reverts_onBadConfig() public {
        address[] memory tokens = new address[](1);
        tokens[0] = address(usdc);
        uint256[] memory caps = new uint256[](0);
        vm.expectRevert(EarnKitCampaigns.LengthMismatch.selector);

    function test_implementation_cannotBeInitialized() public {

        vm.prank(address(factory));
        vm.expectRevert();
        c.initialize(alice, IERC20(address(usdc)), 1, uint64(block.timestamp + 1));
    }

import {BaseTest} from "./Base.t.sol";
import {EarnKitCampaign} from "../src/EarnKitCampaign.sol";

contract EarnKitCampaignTest is BaseTest {

        vm.warp(endsAt);
        vm.expectEmit(false, false, false, true, address(c));

// SPDX-License-Identifier: MIT
pragma solidity 0.8.28;

import {IERC20} from "@openzeppelin/contracts/token/ERC20/IERC20.sol";
import {SafeERC20} from "@openzeppelin/contracts/token/ERC20/utils/SafeERC20.sol";
import {Initializable} from "@openzeppelin/contracts/proxy/utils/Initializable.sol";
import {ReentrancyGuard} from "@openzeppelin/contracts/utils/ReentrancyGuard.sol";

interface IEarnKitCampaigns {
    function operator() external view returns (address);
    function treasury() external view returns (address);
}

/// @title One EarnKit campaign's prize pool (deployed as a clone by EarnKitCampaigns)
/// @notice Money leaves only by `award` (whole prize to winners + fee to the treasury) or
///         `refund` (everything back to the sponsor), once, under the time rules below.
contract EarnKitCampaign is Initializable, ReentrancyGuard {
    using SafeERC20 for IERC20;

    enum State {
        None,
        Funded,
        Awarded,
        Refunded
    }

    uint64 public constant AWARD_GRACE = 7 days;
    uint64 public constant RECLAIM_AFTER = 60 days;
    uint256 public constant MAX_WINNERS = 50;

    /// The factory that deployed the implementation; shared by every clone (immutable is in code).
    address public immutable factory;

    address public sponsor;
    IERC20 public token;
    uint256 public prize;
    uint256 public fee;
    uint64 public endsAt;
    State public state;

    event Awarded(address[] winners, uint256[] amounts, uint256 fee);
    event Refunded(address indexed by, uint256 amount);

    error NotFactory();
    error NotFunded();
    error NotEnded();
    error NotAllowed();
    error BadWinners();
    error WrongTotal();

    constructor() {
        factory = msg.sender;
        _disableInitializers();
    }

    /// @dev Called once by the factory right after cloning, before it moves the funds in.
    function initialize(address sponsor_, IERC20 token_, uint256 amount, uint64 endsAt_) external initializer {
        if (msg.sender != factory) revert NotFactory();
        sponsor = sponsor_;
        token = token_;
        fee = amount / 10;
        prize = amount - amount / 10;
        endsAt = endsAt_;
        state = State.Funded;
    }

    /// @notice Pays the whole prize to `winners` and the fee to the treasury.
    /// @dev Sponsor after `endsAt`; the operator only after `endsAt + AWARD_GRACE`.
    function award(address[] calldata winners, uint256[] calldata amounts) external nonReentrant {
        if (state != State.Funded) revert NotFunded();
        if (block.timestamp < endsAt) revert NotEnded();
        bool bySponsor = msg.sender == sponsor;
        bool byOperator = msg.sender == IEarnKitCampaigns(factory).operator()
            && block.timestamp >= uint256(endsAt) + AWARD_GRACE;
        if (!bySponsor && !byOperator) revert NotAllowed();

        uint256 n = winners.length;
        if (n == 0 || n > MAX_WINNERS || n != amounts.length) revert BadWinners();
        uint256 total;
        for (uint256 i; i < n; ++i) {
            if (winners[i] == address(0) || amounts[i] == 0) revert BadWinners();
            total += amounts[i];
        }
        if (total != prize) revert WrongTotal();

        state = State.Awarded;
        for (uint256 i; i < n; ++i) {
            token.safeTransfer(winners[i], amounts[i]);
        }
        token.safeTransfer(IEarnKitCampaigns(factory).treasury(), fee);
        emit Awarded(winners, amounts, fee);
    }

    /// @notice Returns prize + fee to the sponsor.
    /// @dev The operator at any time (takedown / no eligible entries); the sponsor after
    ///      `endsAt + RECLAIM_AFTER`, so funds are never stuck if EarnKit disappears.
    function refund() external nonReentrant {
        if (state != State.Funded) revert NotFunded();
        bool byOperator = msg.sender == IEarnKitCampaigns(factory).operator();
        bool bySponsor = msg.sender == sponsor && block.timestamp >= uint256(endsAt) + RECLAIM_AFTER;
        if (!byOperator && !bySponsor) revert NotAllowed();

        state = State.Refunded;
        uint256 amount = prize + fee;
        token.safeTransfer(sponsor, amount);
        emit Refunded(msg.sender, amount);
    }
}

// SPDX-License-Identifier: MIT
pragma solidity 0.8.28;

import {IERC20} from "@openzeppelin/contracts/token/ERC20/IERC20.sol";
import {SafeERC20} from "@openzeppelin/contracts/token/ERC20/utils/SafeERC20.sol";
import {Clones} from "@openzeppelin/contracts/proxy/Clones.sol";
import {Ownable} from "@openzeppelin/contracts/access/Ownable.sol";
import {Ownable2Step} from "@openzeppelin/contracts/access/Ownable2Step.sol";
import {Pausable} from "@openzeppelin/contracts/utils/Pausable.sol";
import {ReentrancyGuard} from "@openzeppelin/contracts/utils/ReentrancyGuard.sol";
import {EarnKitCampaign} from "./EarnKitCampaign.sol";

/// @title EarnKit campaign factory
/// @notice Creates one isolated escrow clone per sponsor campaign. Holds no funds and cannot move
///         a campaign's funds. Owned by a TimelockController, so config changes are public in advance.
contract EarnKitCampaigns is Ownable2Step, Pausable, ReentrancyGuard {
    using SafeERC20 for IERC20;

    uint256 public constant MAX_DURATION = 180 days;

    address public immutable implementation;
    address public operator;
    address public treasury;
    address public pauser;
    /// Max amount per campaign for each allowed token (0 = not allowed).
    mapping(address token => uint256 cap) public capOf;
    mapping(address sponsor => mapping(bytes32 ref => address campaign)) public campaignOf;

    event CampaignCreated(
        bytes32 indexed ref, address indexed sponsor, address campaign, address token, uint256 amount, uint64 endsAt
    );
    event CapSet(address indexed token, uint256 cap);
    event OperatorSet(address operator);
    event TreasurySet(address treasury);
    event PauserSet(address pauser);

    error ZeroAddress();
    error LengthMismatch();
    error TokenNotAllowed();
    error BadAmount();
    error BadEndsAt();
    error RefUsed();
    error AmountMismatch();
    error NotPauser();
    error RenounceDisabled();

    constructor(
        address owner_,
        address operator_,
        address treasury_,
        address pauser_,
        address[] memory tokens,
        uint256[] memory caps
    ) Ownable(owner_) {
        if (tokens.length != caps.length) revert LengthMismatch();
        implementation = address(new EarnKitCampaign());
        _setOperator(operator_);
        _setTreasury(treasury_);
        _setPauser(pauser_);
        for (uint256 i; i < tokens.length; ++i) {
            _setCap(tokens[i], caps[i]);
        }
    }

    /// @notice Deposits `amount` of `token` into a new escrow clone for this sponsor's `ref`.
    function createCampaign(bytes32 ref, IERC20 token, uint256 amount, uint64 endsAt)
        external
        whenNotPaused
        nonReentrant
        returns (address campaign)
    {
        uint256 cap = capOf[address(token)];
        if (cap == 0) revert TokenNotAllowed();
        if (amount == 0 || amount > cap) revert BadAmount();
        if (endsAt <= block.timestamp || endsAt > block.timestamp + MAX_DURATION) revert BadEndsAt();
        if (campaignOf[msg.sender][ref] != address(0)) revert RefUsed();

        campaign = Clones.clone(implementation);
        campaignOf[msg.sender][ref] = campaign;
        EarnKitCampaign(campaign).initialize(msg.sender, token, amount, endsAt);

        uint256 before = token.balanceOf(campaign);
        token.safeTransferFrom(msg.sender, campaign, amount);
        if (token.balanceOf(campaign) - before != amount) revert AmountMismatch();

        emit CampaignCreated(ref, msg.sender, campaign, address(token), amount, endsAt);
    }

    function setCap(address token, uint256 cap) external onlyOwner {
        _setCap(token, cap);
    }

    function setOperator(address operator_) external onlyOwner {
        _setOperator(operator_);
    }

    function setTreasury(address treasury_) external onlyOwner {
        _setTreasury(treasury_);
    }

    function setPauser(address pauser_) external onlyOwner {
        _setPauser(pauser_);
    }

    /// @notice Stops new campaigns. Awards and refunds are never affected.
    function pause() external {
        if (msg.sender != pauser && msg.sender != owner()) revert NotPauser();
        _pause();
    }

    function unpause() external onlyOwner {
        _unpause();
    }

    /// @dev An ownerless factory could never change caps or the operator again.
    function renounceOwnership() public view override onlyOwner {
        revert RenounceDisabled();
    }

    function _setCap(address token, uint256 cap) private {
        if (token == address(0)) revert ZeroAddress();
        capOf[token] = cap;
        emit CapSet(token, cap);
    }

    function _setOperator(address operator_) private {
        if (operator_ == address(0)) revert ZeroAddress();
        operator = operator_;
        emit OperatorSet(operator_);
    }

    function _setTreasury(address treasury_) private {
        if (treasury_ == address(0)) revert ZeroAddress();
        treasury = treasury_;
        emit TreasurySet(treasury_);
    }

    function _setPauser(address pauser_) private {
        if (pauser_ == address(0)) revert ZeroAddress();
        pauser = pauser_;
        emit PauserSet(pauser_);
    }
}

    address constant TREASURY = address(0x3000);

        address[] memory tokens = new address[](1);
        tokens[0] = address(usdc);
        uint256[] memory caps = new uint256[](1);
        caps[0] = type(uint128).max;

        usdc.mint(SPONSOR, amount);
        vm.startPrank(SPONSOR);
        usdc.approve(address(factory), amount);
        c = EarnKitCampaign(factory.createCampaign(bytes32(0), IERC20(address(usdc)), amount, endsAt));
        vm.stopPrank();

    /// prize + fee == amount and fee == amount / 10, for every amount.

        vm.assume(amount > 0 && duration > 0 && duration <= 180 days);
        EarnKitCampaign c = _create(amount, uint64(block.timestamp + duration));
        assert(c.prize() + c.fee() == amount);
        assert(c.fee() == uint256(amount) / 10);
    }

    /// A successful award moves exactly prize to the two winners and fee to the treasury.
    function check_awardPaysExactly(uint128 amount, uint128 first, address caller, uint64 when) public {
        vm.assume(amount >= 2);
        EarnKitCampaign c = _create(amount, uint64(block.timestamp + 1 days));
        uint256 prize = c.prize();
        vm.assume(first > 0 && first < prize);
        address[] memory w = new address[](2);
        (w[0], w[1]) = (address(0xA), address(0xB));
        uint256[] memory a = new uint256[](2);
        (a[0], a[1]) = (first, prize - first);
        vm.warp(when);
        vm.prank(caller);
        try c.award(w, a) {
            assert(usdc.balanceOf(address(0xA)) == first);
            assert(usdc.balanceOf(address(0xB)) == prize - first);
            assert(usdc.balanceOf(TREASURY) == c.fee());
            assert(usdc.balanceOf(address(c)) == 0);
            // Only the sponsor after the end, or the operator after the grace period.
            assert(
                (caller == SPONSOR && when >= c.endsAt())
                    || (caller == OPERATOR && uint256(when) >= uint256(c.endsAt()) + 7 days)
            );
        } catch {
            assert(usdc.balanceOf(address(c)) == amount);
        }
    }

    /// A successful refund returns everything to the sponsor, only by allowed callers and times.
    function check_refundRules(uint128 amount, address caller, uint64 when) public {
        vm.assume(amount > 0);
        EarnKitCampaign c = _create(amount, uint64(block.timestamp + 1 days));
        vm.warp(when);
        vm.prank(caller);
        try c.refund() {
            assert(usdc.balanceOf(SPONSOR) == amount);
            assert(usdc.balanceOf(TREASURY) == 0);
            assert(caller == OPERATOR || (caller == SPONSOR && uint256(when) >= uint256(c.endsAt()) + 60 days));
        } catch {
            assert(usdc.balanceOf(address(c)) == amount);
        }

        vm.warp(when);

            w[0] = OWNER;
            uint256[] memory a = new uint256[](1);
            a[0] = c.prize();
            try c.award(w, a) {
                assert(false);
            } catch {}
        } else {
            try c.refund() {
                assert(false);
            } catch {}
        }
        vm.stopPrank();
        assert(usdc.balanceOf(OWNER) == 0);
    }

```solidity
// SPDX-License-Identifier: MIT
pragma solidity 0.8.28;

import {Script, console2} from "forge-std/Script.sol";
import {TimelockController} from "@openzeppelin/contracts/governance/TimelockController.sol";
import {EarnKitCampaigns} from "../src/EarnKitCampaigns.sol";

/// forge script script/Deploy.s.sol --rpc-url $RPC --broadcast --verify (owner's wallet signs)
contract Deploy is Script {
    function run() external returns (TimelockController timelock, EarnKitCampaigns factory) {
        address proposer = vm.envAddress("PROPOSER");
        address[] memory proposers = new address[](1);
        proposers[0] = proposer;
        address[] memory executors = new address[](1);
        executors[0] = proposer;
        address[] memory tokens = new address[](1);
        tokens[0] = vm.envAddress("USDC");
        uint256[] memory caps = new uint256[](1);
        caps[0] = vm.envUint("USDC_CAP");
        uint256 delay = vm.envOr("TIMELOCK_DELAY", uint256(48 hours));

        vm.startBroadcast();
        timelock = new TimelockController(delay, proposers, executors, address(0));
        factory = new EarnKitCampaigns(
            address(timelock), vm.envAddress("OPERATOR"), vm.envAddress("TREASURY"), vm.envAddress("PAUSER"), tokens, caps
        );
        vm.stopBroadcast();

        console2.log("timelock", address(timelock));
        console2.log("factory ", address(factory));
    }
}
```

/**
 * Pure rules for sponsor campaigns (v2.1): what a sponsor may create, how the pool splits, the
 * program builders see, and how an award maps to entries. No DB or chain access here.
 */

export class SponsorError extends Error {}

const httpsUrl = z
  .string()
  .url()
  .refine((u) => /^https?:\/\//i.test(u), 'an http(s) link');

export const DraftInput = z
  .object({
    sponsor_name: z.string().trim().min(1).max(60),
    sponsor_url: httpsUrl.optional(),
    title: z.string().trim().min(5).max(80),
    theme: z.string().trim().min(20).max(1000),
    criteria: z.string().trim().min(10).max(1000),
    chains: z.array(z.enum(CHAINS)).min(1).max(CHAINS.length),
    token: z.string().trim().min(1).max(10),
    amount: z.string().regex(/^\d+(\.\d+)?$/, 'a number like "5000" or "100.5"'),
    winners: z.number().int().min(1).max(50),
    existing_work: z.enum(['allowed', 'new_work_only']).default('new_work_only'),
    starts_at: z.string().datetime({ offset: true }).optional(),
    ends_at: z.string().datetime({ offset: true }),
  })
  .strict();
export type Draft = z.infer<typeof DraftInput>;

const DAY = 86_400_000;

export function checkDraft(d: Draft, token: TokenInfo | null, cap: bigint, now: Date) {
  if (!token)
    throw new SponsorError(`token: "${d.token}" isn't allowed. Use USDC or an allowlisted token.`);
  const places = d.amount.split('.')[1]?.length ?? 0;
  if (places > token.decimals)
    throw new SponsorError(`amount: ${token.symbol} has ${token.decimals} decimals; "${d.amount}" has ${places}.`);
  const amountUnits = parseUnits(d.amount, token.decimals);
  if (amountUnits <= 0n) throw new SponsorError('amount: must be more than 0.');
  if (amountUnits > cap)
    throw new SponsorError(`amount: over the current cap of ${formatUnits(cap, token.decimals)} ${token.symbol} per campaign.`);
  const ends = Date.parse(d.ends_at);
  if (ends < now.getTime() + 3 * DAY || ends > now.getTime() + 90 * DAY)
    throw new SponsorError('ends_at: the campaign must end 3 to 90 days from now.');
  if (d.starts_at && Date.parse(d.starts_at) >= ends)
    throw new SponsorError('starts_at: must be before ends_at.');
  return { amountUnits };
}

/** 10% fee (rounded down), the rest is the prize. Mirrors EarnKitCampaign.initialize. */
export const splitUnits = (amountUnits: bigint) => {
  const fee = amountUnits / 10n;
  return { prize: amountUnits - fee, fee };
};

const fmt = (n: string) => Number(n).toLocaleString('en-US', { maximumFractionDigits: 18 });

export type PlanItem = { entry_id: number; wallet: string; amount: string; reason: string };

export const AwardWinner = z
  .object({
    entry_id: z.number().int().positive(),
    amount: z.string().regex(/^\d+(\.\d+)?$/),
    reason: z.string().trim().min(3).max(280),
  })
  .strict();

/** Checks the sponsor's picks and returns what the award transaction must contain. */
export function planAward(a: {
  winners: z.infer<typeof AwardWinner>[];
  entries: { id: number; payout_wallet: string }[];
  prizeUnits: bigint;
  decimals: number;
}) {
  const seen = new Set<number>();
  const plan: PlanItem[] = a.winners.map((w) => {
    if (seen.has(w.entry_id)) throw new SponsorError(`winners: entry ${w.entry_id} is listed more than once.`);
    seen.add(w.entry_id);
    const e = a.entries.find((x) => x.id === w.entry_id);
    if (!e) throw new SponsorError(`winners: ${w.entry_id} isn't an entry in this campaign.`);
    return { entry_id: e.id, wallet: e.payout_wallet, amount: w.amount, reason: w.reason };
  });
  const amountsUnits = plan.map((p) => parseUnits(p.amount, a.decimals));
  if (amountsUnits.some((u) => u <= 0n)) throw new SponsorError('winners: every amount must be more than 0.');
  const total = amountsUnits.reduce((s, u) => s + u, 0n);
  if (total !== a.prizeUnits)
    throw new SponsorError(
      `winners: amounts must add up to ${formatUnits(a.prizeUnits, a.decimals)} exactly (got ${formatUnits(total, a.decimals)}).`,
    );
  return { wallets: plan.map((p) => p.wallet), amountsUnits, plan };
}

/** Maps the onchain Awarded event back to entries, in plan order. Throws if they differ. */
export function matchAwardToPlan(plan: PlanItem[], winners: string[], amounts: bigint[], decimals: number) {
  const same =
    plan.length === winners.length &&
    plan.every(
      (p, i) =>
        p.wallet.toLowerCase() === winners[i].toLowerCase() &&
        parseUnits(p.amount, decimals) === amounts[i],
    );
  if (!same) throw new SponsorError('The onchain award differs from the plan EarnKit prepared.');
  return plan.map((p) => ({ entry_id: p.entry_id, amount: p.amount, reason: p.reason }));
}

export type EscrowChain = 'base' | 'base-sepolia' | 'local';

export type RawTx = {

  data: `0x${string}`;
  value: '0';

/** Tokens the app offers per chain; the contract's capOf is the real allowlist. */

  base: [{ symbol: 'USDC', address: '0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913', decimals: 6 }],

export function awardTx(escrow: `0x${string}`, wallets: string[], amountsUnits: bigint[]): RawTx {
  return {
    to: escrow,
    data: encodeFunctionData({
      abi: campaignAbi,
      functionName: 'award',
      args: [wallets as `0x${string}`[], amountsUnits],
    }),
    value: '0',
    chain_id: escrowConfig().chainId,
    description: 'Pay the winners from escrow (10% fee to EarnKit)',
  };
}

/** The CampaignCreated event in a factory receipt, or null. */
export function readCreated(receipt: TransactionReceipt) {
  const { factory } = escrowConfig();
  for (const log of receipt.logs) {
    if (log.address.toLowerCase() !== factory.toLowerCase()) continue;
    try {
      const e = decodeEventLog({ abi: campaignsAbi, data: log.data, topics: log.topics });
      if (e.eventName === 'CampaignCreated') {
        const a = e.args as { ref: `0x${string}`; sponsor: string; campaign: string; token: string; amount: bigint; endsAt: bigint };
        return { ref: a.ref, sponsor: a.sponsor, campaign: a.campaign, token: a.token, amount: a.amount, endsAt: Number(a.endsAt) };
      }
    } catch {
      // other events from the factory (CapSet etc.) don't concern us
    }
  }
  return null;
}

/** The Awarded event emitted by `escrow` in a receipt, or null. */
export function readAwarded(receipt: TransactionReceipt, escrow: string) {
  for (const log of receipt.logs) {
    if (log.address.toLowerCase() !== escrow.toLowerCase()) continue;
    try {
      const e = decodeEventLog({ abi: campaignAbi, data: log.data, topics: log.topics });
      if (e.eventName === 'Awarded') {
        const a = e.args as { winners: string[]; amounts: bigint[]; fee: bigint };
        return { winners: [...a.winners], amounts: [...a.amounts], fee: a.fee };
      }
    } catch {
      // not an Awarded log
    }
  }
  return null;
}

  capOf,

  escrowConfig,

  checkDraft,

  splitUnits,
  type Draft,

/** Sponsor campaigns (v2.1): drafts, funding, status, and awards. Reads the chain; never signs. */

export type SponsorRow = {
  ref: string;
  program_id: string | null;
  installation_id: number;
  sponsor_name: string;
  sponsor_url: string | null;
  draft: Draft;
  token: string;
  token_symbol: string;
  token_decimals: number;
  amount: string;
  chain_id: number;
  escrow_address: string | null;
  sponsor_wallet: string | null;
  fund_tx: string | null;
  state: 'draft' | 'live' | 'awarded' | 'refunded' | 'expired' | 'taken_down';
  award_plan: { entry_id: number; wallet: string; amount: string; reason: string }[] | null;
  award_tx: string | null;
  created_at: Date;
};

const baseUrl = () => (process.env.EARNKIT_URL ?? 'https://earnkit.com').replace(/\/$/, '');
const DRAFT_TTL_MS = 7 * 86_400_000;

export async function createSponsorDraft(d: Draft, installationId: number) {
  const token = findToken(d.token);
  const cap = token ? await capOf(token.address) : 0n;
  const { amountUnits } = checkDraft(d, token, cap, new Date());
  const ref = `0x${randomBytes(32).toString('hex')}` as `0x${string}`;
  const { chainId } = escrowConfig();
  await sql()`INSERT INTO sponsor_campaigns ${sql()({
    ref,
    installation_id: installationId,
    sponsor_name: d.sponsor_name,
    sponsor_url: d.sponsor_url ?? null,
    draft: sql().json(d as never),
    token: token!.address,
    token_symbol: token!.symbol,
    token_decimals: token!.decimals,
    amount: d.amount,
    chain_id: chainId,
  })}`;
  const { prize, fee } = splitUnits(amountUnits);
  const fmt = (u: bigint) => (Number(u) / 10 ** token!.decimals).toLocaleString('en-US');
  return {
    ref,
    fund_url: `${baseUrl()}/fund/${ref}`,
    transactions: fundTxs(ref, token!, amountUnits, Math.floor(Date.parse(d.ends_at) / 1000)),
    show_to_builder:
      `Campaign drafted: ${d.title}. To go live, deposit ${d.amount} ${token!.symbol} into escrow: ` +
      `${baseUrl()}/fund/${ref} (or I can send the two transactions if I hold your wallet). ` +
      `${fmt(prize)} ${token!.symbol} goes to the winners you pick; EarnKit's 10% (${fmt(fee)} ${token!.symbol}) ` +
      `is paid only when prizes are paid, and refunded if nobody qualifies. Unfunded drafts expire in 7 days.`,
  };
}

/** The row, with lazy expiry of drafts older than 7 days. */
export async function loadCampaign(ref: string) {
  const [row] = await sql()<SponsorRow[]>`SELECT * FROM sponsor_campaigns WHERE ref = ${ref}`;
  if (!row) throw new NotFoundError(`No sponsor campaign "${ref}".`);
  if (row.state === 'draft' && Date.now() - row.created_at.getTime() > DRAFT_TTL_MS) {
    await sql()`UPDATE sponsor_campaigns SET state = 'expired' WHERE ref = ${ref} AND state = 'draft'`;
    return { ...row, state: 'expired' as const };
  }
  return row;
}

/** Checks a receipt is exactly this draft's funding. Pure; exported for tests. */
export function fundingFromReceipt(
  row: Pick<SponsorRow, 'ref' | 'token' | 'token_decimals' | 'amount'> & { draft: { ends_at: string } },
  receipt: TransactionReceipt,
) {
  if (receipt.status !== 'success') throw new SponsorError('That transaction failed onchain.');
  const created = readCreated(receipt);
  if (!created || created.ref.toLowerCase() !== row.ref.toLowerCase())
    throw new SponsorError("That transaction isn't the funding for this campaign.");
  if (created.token.toLowerCase() !== row.token.toLowerCase())
    throw new SponsorError('Funded with a different token than the draft.');
  if (created.amount !== parseUnits(row.amount, row.token_decimals))
    throw new SponsorError('Funded amount differs from the draft.');
  if (created.endsAt !== Math.floor(Date.parse(row.draft.ends_at) / 1000))
    throw new SponsorError('Funded end date differs from the draft.');
  return { escrow: created.campaign, sponsor: created.sponsor };
}

/** Confirms the deposit and publishes the campaign. Idempotent. */
export async function confirmFunding(ref: string, tx: `0x${string}`) {
  const row = await loadCampaign(ref);
  if (row.state !== 'draft') {
    if (row.program_id) return { program_id: row.program_id, campaign_url: `${baseUrl()}/campaigns/${row.program_id}` };
    throw new SponsorError(`This campaign is ${row.state}.`);
  }
  const receipt = await escrowClient().getTransactionReceipt({ hash: tx });
  const { escrow, sponsor } = fundingFromReceipt(row, receipt);
  const token = { symbol: row.token_symbol, address: row.token as `0x${string}`, decimals: row.token_decimals };
  const file = sponsorProgramFile({
    ref,
    draft: row.draft,
    token,
    amountUnits: parseUnits(row.amount, row.token_decimals),
    chainId: row.chain_id,
    escrow,
    baseUrl: baseUrl(),
    now: new Date(),
  });
  await upsertProgram(file, 'sponsor');
  const [updated] = await sql()<{ ref: string }[]>`
    UPDATE sponsor_campaigns SET state = 'live', program_id = ${file.id}, escrow_address = ${escrow.toLowerCase()},
      sponsor_wallet = ${sponsor.toLowerCase()}, fund_tx = ${tx}, funded_at = now()
    WHERE ref = ${ref} AND state = 'draft' RETURNING ref`;
  if (!updated) throw new SponsorError('This campaign changed while confirming; check status again.');
  return { program_id: file.id, campaign_url: `${baseUrl()}/campaigns/${file.id}` };
}

  return sql()<EntryRow[]>`
    SELECT id, name, live_url, repo_url, payout_wallet, contracts, score, scored_at FROM projects
    WHERE program_id = ${programId} AND payout_wallet IS NOT NULL ORDER BY submitted_at`;

/** Re-scores entries with Base contracts when the last score is over 6 hours old (chain 8453 only). */
async function refreshScores(row: SponsorRow, entries: EntryRow[]) {
  if (row.chain_id !== 8453) return;
  const from = new Date(row.draft.starts_at ?? row.created_at);
  const until = new Date(Math.min(Date.now(), Date.parse(row.draft.ends_at)));
  for (const e of entries) {
    if (e.contracts.length === 0) continue;
    if (e.scored_at && Date.now() - e.scored_at.getTime() < SCORE_MAX_AGE_MS) continue;
    const r = await scoreEntry(e.contracts, from, until);
    await sql()`UPDATE projects SET score = ${r.score}, scored_at = now() WHERE id = ${e.id}`;
    e.score = r.score;
  }
}

export function assertCanAward(
  row: Pick<SponsorRow, 'state' | 'installation_id'> & { draft: { ends_at: string } },
  installationId: number,
  now: Date,
) {
  if (row.installation_id !== installationId)
    throw new SponsorError('Only the agent that created this campaign can award it.');
  if (row.state !== 'live') throw new SponsorError(`This campaign is ${row.state}.`);
  if (now.getTime() < Date.parse(row.draft.ends_at))
    throw new SponsorError(`Awards open after the campaign ends (${row.draft.ends_at}).`);
}

export async function sponsorStatus(ref: string, installationId: number) {
  const row = await loadCampaign(ref);
  const units = parseUnits(row.amount, row.token_decimals);
  const prize = formatUnits(splitUnits(units).prize, row.token_decimals);
  const base = {
    state: row.state,
    title: row.draft.title,
    pool: `${row.amount} ${row.token_symbol}`,
    prize: `${prize} ${row.token_symbol}`,
    ends_at: row.draft.ends_at,
  };
  if (row.state === 'draft') return { ...base, fund_url: `${baseUrl()}/fund/${ref}`, entries: [] };
  if (!row.program_id) return { ...base, entries: [] };
  const entries = await entriesOf(row.program_id);
  if (row.installation_id === installationId) await refreshScores(row, entries);
  return {
    ...base,
    campaign_url: `${baseUrl()}/campaigns/${row.program_id}`,
    ...(row.award_plan && row.state === 'live' && { award_url: `${baseUrl()}/award/${ref}` }),
    entries: entries.map((e) => ({
      entry_id: e.id,
      name: e.name,
      live_url: e.live_url,
      repo_url: e.repo_url,
      score: e.score,
    })),
  };
}

export async function prepareAward(ref: string, installationId: number, winners: z.infer<typeof AwardWinner>[]) {
  const row = await loadCampaign(ref);
  assertCanAward(row, installationId, new Date());
  const entries = await entriesOf(row.program_id!);
  const { prize } = splitUnits(parseUnits(row.amount, row.token_decimals));
  const { wallets, amountsUnits, plan } = planAward({ winners, entries, prizeUnits: prize, decimals: row.token_decimals });
  await sql()`UPDATE sponsor_campaigns SET award_plan = ${sql().json(plan as never)} WHERE ref = ${ref}`;
  return {
    award_url: `${baseUrl()}/award/${ref}`,
    transaction: awardTx(row.escrow_address as `0x${string}`, wallets, amountsUnits),
    plan,
  };
}

/** Records an onchain award against the stored plan. Idempotent. */
export async function confirmAward(ref: string, tx: `0x${string}`) {
  const row = await loadCampaign(ref);
  if (row.state === 'awarded') return { paid: row.award_plan?.length ?? 0 };
  if (row.state !== 'live' || !row.escrow_address)
    throw new SponsorError('This campaign is not live.');
  if (!row.award_plan) row.award_plan = [];
  const receipt = await escrowClient().getTransactionReceipt({ hash: tx });
  if (receipt.status !== 'success') throw new SponsorError('That transaction failed onchain.');
  const ev = readAwarded(receipt, row.escrow_address);
  if (!ev) throw new SponsorError("That transaction isn't this campaign's award.");
  let matched: { entry_id: number; amount: string; reason: string }[];
  let offPlan: { wallet: string; amount: string; entry_id: number | null }[] | null = null;
  try {
    matched = matchAwardToPlan(row.award_plan, ev.winners, ev.amounts, row.token_decimals);
  } catch {
    // Paid outside EarnKit's plan (e.g. straight to the contract): record what happened onchain and
    // flag any winner that isn't an entry's payout wallet. The leaderboard shows these publicly.
    const entries = await entriesOf(row.program_id!);
    const used = new Set<number>();
    offPlan = ev.winners.map((w, i) => {
      const e = entries.find((x) => !used.has(x.id) && x.payout_wallet.toLowerCase() === w.toLowerCase());
      if (e) used.add(e.id);
      return { wallet: w.toLowerCase(), amount: formatUnits(ev.amounts[i], row.token_decimals), entry_id: e?.id ?? null };
    });
    matched = offPlan
      .filter((o) => o.entry_id !== null)
      .map((o) => ({ entry_id: o.entry_id!, amount: o.amount, reason: 'Paid by the sponsor (no reason given)' }));
  }
  await sql().begin(async (q) => {
    for (const m of matched) {
      await q`UPDATE projects SET prize_tx = ${tx}, prize_paid_at = now(), prize_amount = ${m.amount},
        prize_reason = ${m.reason} WHERE id = ${m.entry_id}`;
    }
    await q`UPDATE sponsor_campaigns SET state = 'awarded', award_tx = ${tx}, awarded_at = now(),
      award_onchain = ${offPlan ? q.json(offPlan as never) : null} WHERE ref = ${ref}`;
    await q`UPDATE programs SET status = 'closed' WHERE id = ${row.program_id}`;
  });
  return { paid: matched.length, ...(offPlan && { flagged: offPlan.filter((o) => o.entry_id === null).length }) };
}

import { confirmAward, confirmFunding, loadCampaign } from '@/lib/earnkit/sponsor';
import { SponsorError } from '@/lib/earnkit/sponsor-rules';
import { NotFoundError } from '@/lib/earnkit/programs';

/** The fund/award pages report a tx hash; this verifies it onchain. Public and idempotent. */
export async function POST(request: Request, { params }: { params: Promise<{ ref: string }> }) {
  const { ref } = await params;
  const body = (await request.json().catch(() => ({}))) as { tx?: string };
  if (!/^0x[0-9a-fA-F]{64}$/.test(body.tx ?? ''))
    return Response.json({ error: 'tx must be a transaction hash' }, { status: 400 });
  try {
    const row = await loadCampaign(ref);
    if (row.state === 'draft') return Response.json({ ok: true, ...(await confirmFunding(ref, body.tx as `0x${string}`)) });
    return Response.json({ ok: true, ...(await confirmAward(ref, body.tx as `0x${string}`)) });
  } catch (err) {
    if (err instanceof SponsorError || err instanceof NotFoundError)
      return Response.json({ error: err.message }, { status: 400 });
    throw err;
  }
}

'use client';

import { createWalletClient, custom, publicActions, type Chain } from 'viem';
import { base, baseSepolia, foundry } from 'viem/chains';
import type { RawTx } from '@/lib/earnkit/escrow';

declare global {
  interface Window {
    ethereum?: { request(args: { method: string; params?: unknown[] }): Promise<unknown> };
  }
}

const CHAINS: Record<number, Chain> = { 8453: base, 84532: baseSepolia, 31337: foundry };

/** Connects the browser wallet, switches chain, sends each tx in order, waits for each. */
export async function sendAll(txs: RawTx[], onStep: (msg: string) => void) {
  if (!window.ethereum) throw new Error('No browser wallet found. Install MetaMask, Coinbase Wallet, or Rabby.');
  const chain = CHAINS[txs[0].chain_id];
  const wallet = createWalletClient({ chain, transport: custom(window.ethereum) }).extend(publicActions);
  const [account] = await wallet.requestAddresses();
  if ((await wallet.getChainId()) !== chain.id) {
    onStep(`Switching your wallet to ${chain.name}…`);
    await wallet.switchChain({ id: chain.id }).catch(async () => {
      await wallet.addChain({ chain });
      await wallet.switchChain({ id: chain.id });
    });
  }
  let last: `0x${string}` = '0x';
  for (const [i, tx] of txs.entries()) {
    onStep(`Step ${i + 1} of ${txs.length}: ${tx.description}. Confirm in your wallet…`);
    last = await wallet.sendTransaction({ account, to: tx.to, data: tx.data, chain });
    onStep(`Waiting for step ${i + 1} to confirm…`);
    const r = await wallet.waitForTransactionReceipt({ hash: last });
    if (r.status !== 'success') throw new Error(`Step ${i + 1} failed onchain (${last}).`);
  }
  return last;
}

**Goal:** Grow `programs/` from 18 files (8 active or upcoming) to at least 50, every new file read from the program's official pages and form on 2026-11-09, so `find` has something to say to most builders.

**Spec:** `programs/README.md` (the format and the sourcing rule: write only what the source states), `apps/frontend/lib/v5/program-file.ts` (`ProgramFile`). Owner direction: "for the catalog, you do it" (2026-11-06).

## Global Constraints

- Registered chain slugs only (`apps/frontend/lib/v5/chains.ts`); a program tied to no chain sets `any_chain: true`. No new chains in this build.
- Never Optimism or an OP Stack-only program (owner rule 2026-10-07).
- `verified_at` is 2026-11-09 for every new file. `status: active` only when the form is open today.
- No emoji, no em dash anywhere in a file. `summary` at most 90 characters.
- `pnpm programs:check` passes on the whole directory before any commit.
- Research agents never commit; the controller commits per lane.

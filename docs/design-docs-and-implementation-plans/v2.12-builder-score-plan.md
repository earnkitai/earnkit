## Plan Rulings (spec gaps and conflicts with the code)

- **R1, the person key.** The code's group root is `COALESCE(installations.builder_id, installations.id)` (`identity.ts rootOf`); `builder_id` is NULL for an unlinked installation, not "set to that installation" as spec 1 says. `builder_profiles.builder_id` and every v2.12 table key on that root. Nothing backfills `installations.builder_id`.
- **R2, shared clients.** A group holding a `shared_client` installation (`installations.ts sharedGroup`) gets no profile and no score; `score` there answers `SCORE_SHARED` ("Open EarnKit in your own coding agent to see your score.").
- **R3, linking.** `identity.ts linkInstallations` merges groups, so it also merges v2.12 rows in the same transaction (T7): sources move to the root (a duplicate is set `rejected`, `reject_reason = 'merged'`), the other profile's slug goes to `profile_slug_history` pointing at the root, the other profile row is deleted, scores stay as history.
- **R4, who the GitHub login is.** Only a sign-in (`github_verifications`) or the v2.11 proof line (`github-verify.ts loginBasisFor` with `token-gate.ts proofLineOwner`) names a login. `local_git` emails and remotes are clues only: remotes become `proposed` repo sources, never a login. Without a proven login the profile is empty with `missing: 'ownership_unproven'` (remotes given) or `'no_github'` (none), and its fill step is the earnkit.txt line.
- **R5, the X handle.** A typed handle is self-reported, which spec owner rule 1 forbids showing. Plan default: a handle is accepted only when it equals the `twitter_username` on the person's verified GitHub profile (the "Use @name?" prefill). Any other handle is refused with an `agent_note` (add it to your GitHub profile, then say yes). Owner decision D3.
- **R6, slugs.** `x_handle` lowercased, else the verified GitHub login, else `0x` + first 4 + last 4 hex of the first verified wallet (`0xabcd1234`; the shown fallback is `0xabcd…1234`), else `b-` + 8 random `[a-z2-9]`. A slug taken by another person, or in another person's history, gets `-2`, `-3`, ... An old slug is kept in history forever and never given to anyone else.
- **R7, percentiles.** Computed each run over every person's public score (the latest unheld or released row), hidden included, into the mutable `builder_ranks` table (one SQL pass). `builder_scores.percentile` is the snapshot at insert. A held person's new score never moves anyone's rank.
- **R8, one score per day.** `builder_scores` is append-only with UNIQUE (`builder_id`, `day`). A person is scored once per UTC day, when every verified source has a reading for today (ok or failed) or the run starts at 22:00 UTC or later. Releasing a hold is a row in `score_releases`, never an UPDATE.
- **R9, contract reads.** Base: the existing Blockscout transactions read (`campaigns.ts walletsUsing`'s `TxPage` shape, free, already how campaigns count users), from the last reading's day forward (first read: 365 days, at most 20 pages). Arc: `eth_getLogs` of the contract over the recent `ARC_LOG_MAX_CHUNKS` chunks (`events.ts recentChunks`), then `eth_getTransactionByHash` for at most 200 distinct transactions for the sender. Daily readings accumulate history. Spec 2 names getLogs for both; Base's public RPC limits log ranges, so Blockscout is used there (owner decision D7).
- **R10, money.** M = verified fees + 0.01 x volume, from contract readings only. v2.12 has no readable fee source (Stripe is v2.13), so in practice M is 0.01 x the native value of successful outside calls (priced with `deploy.ts nativeUsd`; Arc native is USDC at $1). ERC-20 transfers (USDC tips on the arc-tipjar) are not read in v2.12. EarnKit token trading fees are not money (trading-based, and "token spend scores 0"). The 10% per-wallet cap applies to fees and volume alike. Owner decision D6.
- **R26, the first score.** The 30-point jump rule needs a previous score; a first (backfilled) score is held only by the one-source rule, so a real history found on day one is not held.
- **R11, merged-PR adoption credit.** Each merged PR to a repo with S outside stargazers adds `min(5, log10(1 + S))` users; top 30 PRs by S. Spec 2 names the weight but not the curve.
- **R12, fresh accounts.** GitHub `created_at` within 30 days before the touch, or unknown, counts 50%. A wallet's first transaction within 7 days of its call, or unknown, counts 50% (Base: Blockscout `filter=from` oldest page, at most 3 pages; more than 3 pages reads as old; Arc: unknown).
- **R13, the `find` two lines.** Changing v2.10's lead line wording would break the v2.10/v2.11 flows and journeys. Line 1 stays the existing lead (`leadLine`, `submitStepLine`, `usersAskLine` or the fresh lead); line 2 is new: `You: score 41, top 22%. earnkit.com/b/<slug>`, or the fill step when the profile is empty. The spec's `Base Builder Grants: $5k, closes Oct 30, good odds.` is read as an illustration. News and entries lines above stay as today. The first find adds the consent line last.
- **R14, one question.** When line 1 already asks, the fill step and the card offer are declarative ("Your site isn't linked yet; say link it and I'll add earnkit.txt.") or wait for the next reply.
- **R15, the share redirect.** A route can send a real 301; a page segment can't. `/b/<old slug>` uses `permanentRedirect` (308, permanent). `/bonus/<round>` and `/campaigns/<slug>` become route handlers that send 301.
- **R16, the card route file.** It needs JSX, so it is `app/b/[slug]/card.png/route.tsx` (spec says `route.ts`).
- **R17, accents.** `ek-orange` and `ek-purple` already exist; `ek-purple` (#562AA7) is about 2:1 on the navy panel. Two new tokens, `ek-score-orange` (#FF7A1A, 6.7:1 on #0F1839) and `ek-score-purple` (#9B6BFF, 4.9:1), pinned at 4.5:1 or more by a test; hex values are shown to the owner in the design pass (spec open decision 3).
- **R18, the archive mechanism.** The app never imports from `archive/`. Each feature folder holds `MANIFEST.txt` (original repo-relative paths), `files/<original path>` (the moved files), `README.md` and `TABLES.md`. `apps/frontend/scripts/archive-restore.mts <feature>` moves the files back; live seams also check the flag, so restored files stay dormant until `EARNKIT_<NAME>=on`. "With the flag ON the existing tests pass" is checked by restoring in a scratch worktree (T13, T14).
- **R19, what of sponsor campaigns can move.** Live code imports parts of it: `bonus-ledger.ts` and `cron.ts` use `sponsor.ts withScoringLock` and `escrow.ts` log-chunk helpers; `programs.ts`, `leaderboard.ts`, `token-proposal.ts`, `mcp.ts`, `app/components/wallet.ts` and `app/campaigns/[slug]` read `sponsor-rules.ts`, `sponsor-identity.ts`, `sponsor-verify.ts` and `escrow.ts`. So T13 first moves `withScoringLock` to `scoring-lock.ts`, then archives the write side and entry points (`sponsor.ts`, `sponsor-text.ts`, the tool, `/fund`, `/award`, `/api/sponsor/[ref]/check`, `sponsor-e2e`), and leaves the read-side modules live, with sponsor rows filtered out of `listPrograms` while the flag is off.
- **R20, the bonus-round traction scorer stays live.** `bonus-payout.ts advanceRounds` ranks rounds with `traction.ts finalRanking` and `readyToFreeze`, `cron.ts` runs `scoreOpenRounds`, and `projects.ts`, `alerts.ts` and `policy.ts` import `coinSql`, `eligibleSql`, `CLANKER_ADDRESSES` and `WEIGHTS`. - **R21, `agent_completable` rides the score flag.** The derivation filters out Base Builder Grants, Colosseum World's Fair and Monad Metropolis (all have required `team` or `demo_video` items). Owned by T6 (6.5), T10 (10.4), T11 (11.3), T12 (12.3).

Expected: failed readings are written `ok: false` with the error class, the step stops at its slice end, the existing steps' JSON is unchanged, and no `needs_owner` line is added. Owned by T6 (6.2, 6.3).

import type { Calibration } from './score-calibration';

/**
 * v2.12 spec 4: the builder score, formula v1. Absolute 0 to 100 within a calibration: it does not
 * move when others join (the percentile does). Inputs are already through anti-farming
 * (anti-farming.ts), per project (one project_key). Commits alone score 0: consistency counts only
 * on projects with an outside user, and is 0 with no outcome anywhere. Pure.
 */
export const FORMULA = 'v1';
export const MAX = { users: 45, money: 20, staying: 15, recency: 10, consistency: 10 } as const;
const HALF_LIFE_DAYS = 90;
const DAY_MS = 86_400_000;

export type Outcome = { at: Date; weight: number };
export type ProjectInput = {
  key: string;
  /** What the project is called on the profile (repo name, site host, package name). */
  title: string;
  /** U for this project after anti-farming (weighted outside users, PR credit, downloads/50). */
  users: number;
  /** M for this project: verified fees + 0.01 x volume, USD, last 365 days, after the fee cap. */
  money_usd: number;
  /** Dated outcomes (a counted user, a day of money), each with its weight, for recency. */
  outcomes: Outcome[];
  first_outcome_at: Date | null;
  /** The last day the project was seen live or used. */
  last_used_at: Date | null;
  /** ISO weeks (YYYY-Www) with commits in the last 52, own non-fork non-template repos only. */
  commit_weeks: string[];
};
export type Part = { points: number; raw: Record<string, number> };
export type Parts = { users: Part; money: Part; staying: Part; recency: Part; consistency: Part };
export type Scored = { score: number; parts: Parts; top: ProjectInput | null };

const scaled = (max: number, x: number, bar: number) => (x <= 0 ? 0 : max * Math.min(1, Math.log10(1 + x) / Math.log10(1 + bar)));
const strength = (p: ProjectInput) => p.users + p.money_usd / 10;

export function computeScore(projects: ProjectInput[], cal: Calibration, now: Date): Scored {
  const U = projects.reduce((n, p) => n + Math.max(0, p.users), 0);
  const M = projects.reduce((n, p) => n + Math.max(0, p.money_usd), 0);
  const withOutcome = projects.filter((p) => p.users > 0 || p.money_usd > 0);
  const top = withOutcome.length === 0 ? null : [...withOutcome].sort((a, b) => strength(b) - strength(a) || a.key.localeCompare(b.key))[0];

  // Staying power: best project counts double.
  let num = 0;
  let den = 0;
  for (const p of withOutcome) {
    const w = p === top ? 2 : 1;
    const stayed = p.first_outcome_at && p.last_used_at && (p.last_used_at.getTime() - p.first_outcome_at.getTime()) / DAY_MS >= cal.staying_days;
    num += stayed ? w : 0;
    den += w;
  }
  const share = den === 0 ? 0 : num / den;

  // Recency: 90-day half-life.
  let recent = 0;
  let all = 0;
  for (const p of withOutcome)
    for (const o of p.outcomes) {
      const age = Math.max(0, (now.getTime() - o.at.getTime()) / DAY_MS);
      recent += o.weight * 0.5 ** (age / HALF_LIFE_DAYS);
      all += o.weight;
    }

  // Consistency: union of commit weeks on projects with an outside user.
  const weeks = new Set(projects.filter((p) => p.users > 0).flatMap((p) => p.commit_weeks)).size;

  const parts: Parts = {
    users: { points: scaled(MAX.users, U, cal.users), raw: { U } },
    money: { points: scaled(MAX.money, M, cal.money_usd), raw: { M } },
    staying: { points: MAX.staying * share, raw: { stayed: num, weighted: den } },
    recency: { points: all === 0 ? 0 : MAX.recency * Math.min(1, recent / Math.max(1, all)), raw: { recent, all } },
    consistency: { points: top === null ? 0 : MAX.consistency * Math.min(1, weeks / cal.weeks), raw: { weeks } },
  };
  const sum = Object.values(parts).reduce((n, p) => n + p.points, 0);
  return { score: Math.min(100, Math.round(sum)), parts, top };
}

/** Share (0 to 100) of `all` strictly below `score`. Pure. */
export function percentileOf(score: number, all: readonly number[]): number {
  if (all.length === 0) return 0;
  return (100 * all.filter((s) => s < score).length) / all.length;
}

/** "Top N%": N = max(1, ceil(100 - percentile)). Pure. */
export const topPercent = (percentile: number): number => Math.max(1, Math.ceil(100 - percentile));

/** Points moved per part since `before` (null: all of now). Pure. */
export function partDeltas(now: Parts, before: Parts | null): Record<keyof Parts, number> {
  const keys = Object.keys(now) as (keyof Parts)[];
  return Object.fromEntries(keys.map((k) => [k, now[k].points - (before?.[k]?.points ?? 0)])) as Record<keyof Parts, number>;
}

import type { Outcome } from './score';

/**
 * v2.12 spec 5: what counts as a user and as money, applied before the formula. Every rule is
 * strict from day one (only the calibration bars are generous); an unknown fact counts as the
 * stricter case (plan R12). Weights multiply: spread x fresh x ring. Pure.
 */
export const RULES = {
  feeCap: 0.1,
  minDays: 3,
  burstShare: 0.5,
  burstWeight: 0.25,
  freshGithubDays: 30,
  freshWalletDays: 7,
  freshWeight: 0.5,
  ringWeight: 0.5,
  clusterMin: 5,
  clusterCap: 5,
} as const;

export type ActorKind = 'wallet' | 'github';
export type TouchKind = 'caller' | 'stargazer' | 'forker' | 'issue_author' | 'contributor';
export type Touch = { project: string; actor: string; kind: TouchKind; at: Date; fee_usd?: number; volume_usd?: number };
export type ActorFacts = { created_at?: Date | null; first_tx_at?: Date | null };
export type FarmCtx = {
  self: ReadonlySet<string>;
  actors: ReadonlyMap<string, ActorFacts>;
  ring: ReadonlyMap<string, number>;
  clusterCap?: { actors: ReadonlySet<string>; cap: number };
};
export type Counted = { project: string; users: number; fees_usd: number; volume_usd: number; outcomes: Outcome[]; actors: Map<string, number> };

const DAY_MS = 86_400_000;
const dayOf = (d: Date) => d.toISOString().slice(0, 10);
const isWallet = (actor: string) => actor.startsWith('wallet:');

function freshWeight(actor: string, at: Date, facts: ActorFacts | undefined): number {
  if (isWallet(actor)) {
    const first = facts?.first_tx_at;
    if (!first) return RULES.freshWeight;
    return Math.abs(at.getTime() - first.getTime()) <= RULES.freshWalletDays * DAY_MS ? RULES.freshWeight : 1;
  }
  const created = facts?.created_at;
  if (!created) return RULES.freshWeight;
  return at.getTime() - created.getTime() < RULES.freshGithubDays * DAY_MS ? RULES.freshWeight : 1;
}

/** One project's counted users and money after every rule. */
export function countProject(project: string, touches: Touch[], ctx: FarmCtx): Counted {
  // Self-exclusion, then one per account (earliest touch; its money summed per account).
  const first = new Map<string, Touch>();
  const fee = new Map<string, number>();
  const vol = new Map<string, number>();
  for (const t of touches) {
    if (t.project !== project || ctx.self.has(t.actor)) continue;
    const seen = first.get(t.actor);
    if (!seen || t.at < seen.at) first.set(t.actor, t);
    fee.set(t.actor, (fee.get(t.actor) ?? 0) + Math.max(0, t.fee_usd ?? 0));
    vol.set(t.actor, (vol.get(t.actor) ?? 0) + Math.max(0, t.volume_usd ?? 0));
  }
  // Spread, onchain callers only.
  const callers = [...first.values()].filter((t) => t.kind === 'caller');
  const byDay = new Map<string, number>();
  for (const t of callers) byDay.set(dayOf(t.at), (byDay.get(dayOf(t.at)) ?? 0) + 1);
  const burstDay = [...byDay].find(([, n]) => n > RULES.burstShare * callers.length)?.[0];
  const spread = (t: Touch) => (t.kind !== 'caller' ? 1 : byDay.size < RULES.minDays ? 0 : dayOf(t.at) === burstDay ? RULES.burstWeight : 1);

  const actors = new Map<string, number>();
  for (const [actor, t] of first) {
    const w = spread(t) * freshWeight(actor, t.at, ctx.actors.get(actor)) * (ctx.ring.get(actor) ?? 1);
    actors.set(actor, w);
  }
  // Cluster cap: in-cluster credit at most `cap`, scaled down evenly.
  if (ctx.clusterCap) {
    const inCluster = [...actors].filter(([a]) => ctx.clusterCap!.actors.has(a));
    const sum = inCluster.reduce((n, [, w]) => n + w, 0);
    if (sum > ctx.clusterCap.cap) for (const [a, w] of inCluster) actors.set(a, (w * ctx.clusterCap.cap) / sum);
  }
  // Money: per-account cap at 10% of the project's (self-excluded) total, weighted like the account.
  const capped = (m: Map<string, number>) => {
    const total = [...m.values()].reduce((n, x) => n + x, 0);
    let out = 0;
    for (const [a, x] of m) out += Math.min(x, RULES.feeCap * total) * (actors.get(a) ?? 0);
    return out;
  };
  const users = [...actors.values()].reduce((n, w) => n + w, 0);
  const outcomes: Outcome[] = [...first].map(([a, t]) => ({ at: t.at, weight: actors.get(a) ?? 0 })).filter((o) => o.weight > 0);
  return { project, users, fees_usd: capped(fee), volume_usd: capped(vol), outcomes, actors };
}

export const moneyOf = (c: Pick<Counted, 'fees_usd' | 'volume_usd'>) => c.fees_usd + 0.01 * c.volume_usd;

/**
 * Rings (spec 5). `edges`: [counter, counted] person pairs (an account of `counter` counts as a user
 * of `counted`). For `person`: each actor of someone in a mutual pair with them weighs 0.5; when
 * the mutual-pair component holding them has 5+ people, their in-cluster credit is capped at 5.
 * `owner` maps actor ids to the person who owns them (verified wallets and logins). Pure.
 */
export function ringWeights(edges: Array<[number, number]>, person: number, owner: ReadonlyMap<string, number>): Pick<FarmCtx, 'ring' | 'clusterCap'> {
  const has = new Set(edges.map(([a, b]) => `${a}>${b}`));
  const mutual = new Map<number, Set<number>>();
  for (const [a, b] of edges)
    if (a !== b && has.has(`${b}>${a}`)) {
      if (!mutual.has(a)) mutual.set(a, new Set());
      mutual.get(a)!.add(b);
    }
  const partners = mutual.get(person) ?? new Set<number>();
  // The connected component of `person` in the mutual graph.
  const comp = new Set<number>([person]);
  const queue = [person];
  while (queue.length) for (const n of mutual.get(queue.shift()!) ?? []) if (!comp.has(n)) (comp.add(n), queue.push(n));
  const ring = new Map<string, number>();
  const clusterActors = new Set<string>();
  for (const [actor, who] of owner) {
    if (partners.has(who)) ring.set(actor, RULES.ringWeight);
    if (who !== person && comp.has(who)) clusterActors.add(actor);
  }
  return { ring, ...(comp.size >= RULES.clusterMin && { clusterCap: { actors: clusterActors, cap: RULES.clusterCap } }) };
}

export function foundryBroadcast(path: string, text: string): ContractClue[] {
  const fromPath = /broadcast\/[^/]+\/(\d+)\/run-latest\.json$/.exec(path);
  const run = json(text) as { chain?: unknown; transactions?: unknown } | null;
  const chain = scored(typeof run?.chain === 'number' ? run.chain : fromPath ? Number(fromPath[1]) : null);
  if (!chain || !Array.isArray(run?.transactions)) return [];
  const out: ContractClue[] = [];
  for (const t of run.transactions as { transactionType?: unknown; contractAddress?: unknown; transaction?: { from?: unknown } }[]) {
    if ((t.transactionType !== 'CREATE' && t.transactionType !== 'CREATE2') || typeof t.contractAddress !== 'string' || !ADDR.test(t.contractAddress)) continue;
    const from = typeof t.transaction?.from === 'string' && ADDR.test(t.transaction.from) ? t.transaction.from.toLowerCase() : null;
    out.push({ chain, address: t.contractAddress.toLowerCase(), deployer: from, via: 'foundry' });

/**
 * v2.12 spec 3: finding a person's past work. `find` never waits on it: it records the agent's
 * clues and queues the person; the hourly cron's `discover` step (Task 6) does the reads.
 */
export type LocalGit = { emails: string[]; remotes: string[]; live_urls: string[] };

const strings = (v: unknown, max: number): string[] => (Array.isArray(v) ? v.filter((x): x is string => typeof x === 'string').map((s) => s.trim()).filter(Boolean).slice(0, max) : []);

/** find's `local_git`, read leniently (v2.8.1 §B6 style): never throws; at most 20 remotes and 5 emails and live links. */
export function localGitInput(v: unknown): LocalGit {
  const o = v && typeof v === 'object' && !Array.isArray(v) ? (v as Record<string, unknown>) : {};
  const remotes = [...new Set(strings(o.remotes, 200).map(githubRemote).filter((r): r is string => !!r))].slice(0, 20);
  const emails = strings(o.emails, 5).filter((e) => /^[^@\s]{1,64}@[^@\s]{1,255}$/.test(e)).map((e) => e.toLowerCase());
  const live_urls = strings(o.live_urls, 5).filter((u) => URL.canParse(u) && new URL(u).protocol === 'https:').map((u) => new URL(u).origin);
  return { emails, remotes, live_urls };
}

export async function enqueueDiscovery(builderId: number, reason: 'first_find' | 'wallet' | 'signin' | 'local_repo', db: Db = sql()): Promise<void> {
  await db`
    INSERT INTO discovery_queue (builder_id, reason) VALUES (${builderId}, ${reason})
    ON CONFLICT (builder_id) DO UPDATE SET reason = EXCLUDED.reason, queued_at = now(), done_at = NULL
    WHERE discovery_queue.done_at IS NOT NULL`;
}

/** Proposes the agent's remotes and live links as sources (never verified here); queues discovery on anything new. */
export async function noteLocalGit(builderId: number, g: LocalGit): Promise<number> {
  const db = sql();
  const rows = [
    ...g.remotes.map((r) => ({ builder_id: builderId, kind: 'repo', ref: r, project_key: r, proposed_by: 'agent' })),
    ...g.live_urls.map((u) => ({ builder_id: builderId, kind: 'site', ref: u, project_key: u, proposed_by: 'agent' })),
  ];
  if (rows.length === 0) return 0;
  const added = await db<{ id: string; kind: string; ref: string }[]>`
    INSERT INTO builder_sources ${db(rows)} ON CONFLICT (builder_id, kind, ref) DO NOTHING RETURNING id, kind, ref`;
  for (const s of added)
    await noteEvent('source_proposed', () => ({
      type: 'source_proposed', dedupe_key: `source_proposed:${s.id}`, installation_id: builderId,
      detail: { source_id: Number(s.id), kind: s.kind, by: 'agent' },
    }));
  if (added.length > 0) await enqueueDiscovery(builderId, 'local_repo', db);
  return added.length;
}

import type { TxPage } from './campaigns';
import { ARC_LOG_CHUNK, recentChunks } from './events';

/**
 * v2.12 spec 2: one reader per source kind. Every outside read is injected (ReaderDeps), so tests
 * never touch the network and the cron passes the real, free, keyless sources. Readers return
 * signals only: who touched what and when. Anti-farming and scoring happen later. A reader may
 * throw; the caller writes a failed reading.
 */
export type Who = { id: string; at: string; created_at?: string | null };
export type RepoSignals = { owner: string; fork: boolean; template: boolean; stargazers: Who[]; forkers: Who[]; issue_authors: Who[]; contributors: Who[]; commit_weeks: string[]; partial: boolean };
export type SiteSignals = { status: number; up: boolean };
export type PackageSignals = { weekly: number; repo_url: string | null };
export type ContractSignals = { callers: (Who & { value_usd: number; first_tx_at?: string | null })[]; partial: boolean };
export type PrSignals = { target: string; target_stars: number; merged_at: string | null; author: string };
export type ReaderDeps = {
  gh: <T>(path: string, accept?: string) => Promise<T>;
  probe: (url: string) => Promise<{ status: number }>;
  fetchText: (url: string) => Promise<string>;
  json: <T>(url: string) => Promise<T>;
  baseTxs: (path: string) => Promise<TxPage>;
  arcLogs: (address: string, from: bigint, to: bigint) => Promise<{ tx: string }[]>;
  arcHead: () => Promise<bigint>;
  arcSender: (tx: string) => Promise<{ from: string; value: bigint; at: string }>;
  usdPerNative: (chain: 'base' | 'arc') => Promise<number>;
  now: Date;
};

export const READ_CAPS = { stargazerPages: 3, userLookups: 80, basePages: 20, arcSenders: 200, prs: 30 } as const;
const STAR = 'application/vnd.github.star+json';

/** ISO 8601 week, 'YYYY-Www'. Pure. */
export function isoWeek(d: Date): string {
  const t = new Date(Date.UTC(d.getUTCFullYear(), d.getUTCMonth(), d.getUTCDate()));
  const day = t.getUTCDay() || 7;
  t.setUTCDate(t.getUTCDate() + 4 - day);
  const year = t.getUTCFullYear();
  const week = Math.ceil(((t.getTime() - Date.UTC(year, 0, 1)) / 86_400_000 + 1) / 7);
  return `${year}-W${String(week).padStart(2, '0')}`;
}

export async function readRepo(fullName: string, d: ReaderDeps): Promise<RepoSignals> {
  const meta = await d.gh<{ owner: { login: string }; fork: boolean; is_template?: boolean }>(`/repos/${fullName}`);
  let partial = false;
  const stargazers: Who[] = [];
  for (let page = 1; page <= READ_CAPS.stargazerPages; page++) {
    const rows = await d.gh<{ starred_at: string; user: { login: string } }[]>(`/repos/${fullName}/stargazers?per_page=100&page=${page}`, STAR);
    stargazers.push(...rows.map((r) => ({ id: `gh:${r.user.login.toLowerCase()}`, at: r.starred_at })));
    if (rows.length < 100) break;
    if (page === READ_CAPS.stargazerPages) partial = true;
  }
  const forkers = (await d.gh<{ owner: { login: string }; created_at: string }[]>(`/repos/${fullName}/forks?per_page=100`)).map((f) => ({ id: `gh:${f.owner.login.toLowerCase()}`, at: f.created_at }));
  const issue_authors = (await d.gh<{ user: { login: string }; created_at: string; pull_request?: unknown }[]>(`/repos/${fullName}/issues?state=all&per_page=100`))
    .filter((i) => !i.pull_request)
    .map((i) => ({ id: `gh:${i.user.login.toLowerCase()}`, at: i.created_at }));
  const contributors = (await d.gh<{ login: string }[]>(`/repos/${fullName}/contributors?per_page=100`)).map((c) => ({ id: `gh:${c.login.toLowerCase()}`, at: d.now.toISOString() }));
  const activity = await d.gh<{ week: number; total: number }[]>(`/repos/${fullName}/stats/commit_activity`).catch(() => []);
  const commit_weeks = (Array.isArray(activity) ? activity : []).filter((w) => w.total > 0).map((w) => isoWeek(new Date(w.week * 1000)));
  // Account ages for the fresh-account rule (R12), at most READ_CAPS.userLookups; the rest stay unknown (counted 50%).
  const outside = [...stargazers, ...forkers, ...issue_authors, ...contributors].filter((w) => w.id !== `gh:${meta.owner.login.toLowerCase()}`);
  const ages = new Map<string, string | null>();
  for (const w of outside) {
    if (ages.has(w.id)) continue;
    if (ages.size >= READ_CAPS.userLookups) {
      partial = true;
      break;
    }
    ages.set(w.id, (await d.gh<{ created_at?: string }>(`/users/${w.id.slice(3)}`).catch(() => ({ created_at: undefined }))).created_at ?? null);
  }
  const aged = (ws: Who[]) => ws.map((w) => (ages.has(w.id) ? { ...w, created_at: ages.get(w.id) } : w));
  return {
    owner: meta.owner.login.toLowerCase(), fork: meta.fork, template: meta.is_template === true,
    stargazers: aged(stargazers), forkers: aged(forkers), issue_authors: aged(issue_authors), contributors: aged(contributors),
    commit_weeks, partial,
  };
}

export async function readSite(origin: string, d: ReaderDeps): Promise<SiteSignals> {
  const status = await d.probe(origin).then((r) => r.status, () => 0);
  return { status, up: status >= 200 && status < 300 };
}

const repoUrlOf = (raw: unknown): string | null => {
  const s = typeof raw === 'string' ? raw : null;
  const m = s && /github\.com[/:]([A-Za-z0-9-]+)\/([A-Za-z0-9._-]+?)(?:\.git)?(?:[/#].*)?$/.exec(s);
  return m ? `https://github.com/${m[1]}/${m[2]}` : null;
};

export async function readNpm(name: string, d: ReaderDeps): Promise<PackageSignals> {
  const range = await d.json<{ downloads: { day: string; downloads: number }[] }>(`https://api.npmjs.org/downloads/range/last-month/${encodeURIComponent(name)}`);
  const last28 = range.downloads.slice(-28);
  const weeks = [0, 1, 2, 3].map((i) => last28.slice(i * 7, i * 7 + 7).reduce((n, x) => n + x.downloads, 0));
  const meta = await d.json<{ repository?: { url?: string } | string }>(`https://registry.npmjs.org/${encodeURIComponent(name)}/latest`);
  const repo = typeof meta.repository === 'string' ? meta.repository : meta.repository?.url;
  return { weekly: weeks.reduce((n, w) => n + w, 0) / 4, repo_url: repoUrlOf(repo) };
}

export async function readPypi(name: string, d: ReaderDeps): Promise<PackageSignals> {
  const recent = await d.json<{ data: { last_month: number } }>(`https://pypistats.org/api/packages/${encodeURIComponent(name)}/recent`);
  const meta = await d.json<{ info: { project_urls?: Record<string, string> | null; home_page?: string | null } }>(`https://pypi.org/pypi/${encodeURIComponent(name)}/json`);
  const urls = [...Object.values(meta.info.project_urls ?? {}), meta.info.home_page ?? ''];
  return { weekly: recent.data.last_month / 4, repo_url: urls.map(repoUrlOf).find((u) => u !== null) ?? null };
}

export async function readContract(ref: string, since: Date, d: ReaderDeps): Promise<ContractSignals> {
  const [chain, address] = ref.split(':') as ['base' | 'arc', string];
  const usd = await d.usdPerNative(chain);
  const callers: ContractSignals['callers'] = [];
  if (chain === 'base') {
    let params = 'filter=to';
    for (let page = 0; page < READ_CAPS.basePages; page++) {
      const data = await d.baseTxs(`/api/v2/addresses/${address}/transactions?${params}`);
      for (const tx of data.items as (TxPage['items'][number] & { value?: string })[]) {
        if (new Date(tx.timestamp) < since) return { callers, partial: false };
        if (tx.status !== 'ok') continue;
        callers.push({ id: `wallet:${tx.from.hash.toLowerCase()}`, at: tx.timestamp, value_usd: (Number(BigInt(tx.value ?? '0')) / 1e18) * usd });
      }
      if (!data.next_page_params) return { callers, partial: false };
      params = new URLSearchParams(Object.entries(data.next_page_params).map(([k, v]) => [k, String(v)])).toString();
    }
    return { callers, partial: true };
  }
  // Arc (R9): recent chunks only; daily readings accumulate the history.
  const head = await d.arcHead();
  const txs: string[] = [];
  for (const [from, to] of recentChunks(head, ARC_LOG_CHUNK).reverse())
    for (const l of await d.arcLogs(address, from, to)) if (!txs.includes(l.tx)) txs.push(l.tx);
  for (const tx of txs.slice(0, READ_CAPS.arcSenders)) {
    const s = await d.arcSender(tx);
    callers.push({ id: `wallet:${s.from.toLowerCase()}`, at: s.at, value_usd: (Number(s.value) / 1e18) * usd });
  }
  return { callers, partial: txs.length > READ_CAPS.arcSenders };
}

export async function readMergedPrs(login: string, d: ReaderDeps): Promise<PrSignals[]> {
  const q = encodeURIComponent(`type:pr author:${login} is:merged -user:${login}`);
  const found = await d.gh<{ items: { html_url: string; repository_url: string; pull_request?: { merged_at?: string | null } }[] }>(`/search/issues?q=${q}&per_page=100`);
  const own = `/repos/${login.toLowerCase()}/`;
  const prs = found.items.filter((i) => !i.repository_url.toLowerCase().includes(own));
  const out: PrSignals[] = [];
  for (const p of prs) {
    const target = p.repository_url.replace('https://api.github.com/repos/', '').toLowerCase();
    const repo = await d.gh<{ stargazers_count: number }>(`/repos/${target}`).catch(() => ({ stargazers_count: 0 }));
    out.push({ target, target_stars: repo.stargazers_count, merged_at: p.pull_request?.merged_at ?? null, author: login.toLowerCase() });
  }
  return out.sort((a, b) => b.target_stars - a.target_stars).slice(0, READ_CAPS.prs);
}

export async function proposeSource(s: { builder_id: number; kind: string; ref: string; project_key: string; proposed_by: 'agent' | 'server' }): Promise<number | null> {

export const SCORE_SLICE = 0.4;

export const HOLD = { jump: 30, oneSource: 0.8, minScore: 60 } as const;

export type SourceRow = { id: number; kind: string; ref: string; project_key: string; owner_is_org: boolean };
export type ReadingRow = { source_id: number; day: string; ok: boolean; signals: unknown };

const DAY_MS = 86_400_000;
const YEAR_MS = 365 * DAY_MS;
const d = (s: string) => new Date(s);

/** Readings to the formula's inputs: touches per project through anti-farming, plus PR credit and downloads. Pure. */
export function buildInputs(
  sources: SourceRow[],
  readings: ReadingRow[],
  ctx: { self: Set<string>; owner: Map<string, number>; edges: [number, number][]; person: number; now: Date },
): { projects: ProjectInput[]; perSource: Map<number, { users: number; money: number }> } {
  const ring = ringWeights(ctx.edges, ctx.person, ctx.owner);
  const ok = readings.filter((r) => r.ok);
  const latest = new Map<number, ReadingRow>();
  for (const r of ok) if (!latest.has(r.source_id) || latest.get(r.source_id)!.day < r.day) latest.set(r.source_id, r);
  const keys = [...new Set(sources.map((s) => s.project_key))];
  const projects: ProjectInput[] = [];
  const perSource = new Map<number, { users: number; money: number }>();
  for (const key of keys) {
    const inProject = sources.filter((s) => s.project_key === key);
    const touches: Touch[] = [];
    const facts = new Map<string, { created_at?: Date | null; first_tx_at?: Date | null }>();
    const self = new Set(ctx.self);
    let extraUsers = 0;
    const extraOutcomes: { at: Date; weight: number }[] = [];
    let commitWeeks: string[] = [];
    let lastUp: Date | null = null;
    const bySource = new Map<number, string[]>();
    const add = (sid: number, kind: Touch['kind'], w: Who, money = 0) => {
      touches.push({ project: key, actor: w.id, kind, at: d(w.at), volume_usd: money });
      if (w.created_at !== undefined) facts.set(w.id, { ...facts.get(w.id), created_at: w.created_at ? d(w.created_at) : null });
      bySource.set(sid, [...(bySource.get(sid) ?? []), w.id]);
    };
    for (const s of inProject) {
      const r = latest.get(s.id);
      if (s.kind === 'repo' && r) {
        const g = r.signals as RepoSignals;
        // Members of their own org never count (spec 5): every contributor of an org repo is self.
        if (s.owner_is_org) for (const c of g.contributors) self.add(c.id);
        for (const w of g.stargazers) add(s.id, 'stargazer', w);
        for (const w of g.forkers) add(s.id, 'forker', w);
        for (const w of g.issue_authors) add(s.id, 'issue_author', w);
        for (const w of g.contributors) add(s.id, 'contributor', w);
        commitWeeks = [...new Set([...commitWeeks, ...g.commit_weeks])];
      }
      if (s.kind === 'contract')
        for (const rr of ok.filter((x) => x.source_id === s.id && ctx.now.getTime() - d(x.day).getTime() <= YEAR_MS))
          for (const c of (rr.signals as ContractSignals).callers) {
            add(s.id, 'caller', c, c.value_usd);
            facts.set(c.id, { ...facts.get(c.id), first_tx_at: c.first_tx_at ? d(c.first_tx_at) : null });
          }
      if ((s.kind === 'package_npm' || s.kind === 'package_pypi') && r) {
        const credit = (r.signals as PackageSignals).weekly / 50;
        extraUsers += credit;
        extraOutcomes.push({ at: d(r.day), weight: credit });
        perSource.set(s.id, { users: credit, money: 0 });
      }
      if (s.kind === 'merged_pr' && r) {
        const p = r.signals as PrSignals;
        const credit = Math.min(5, Math.log10(1 + p.target_stars));
        extraUsers += credit;
        if (p.merged_at) extraOutcomes.push({ at: d(p.merged_at), weight: credit });
        perSource.set(s.id, { users: credit, money: 0 });
      }
      if (s.kind === 'site')
        for (const rr of ok.filter((x) => x.source_id === s.id && (x.signals as SiteSignals).up))
          if (!lastUp || d(rr.day) > lastUp) lastUp = d(rr.day);
    }
    const c = countProject(key, touches, { self, actors: facts, ...ring });
    for (const [sid, actors] of bySource)
      perSource.set(sid, { users: actors.reduce((n, a) => n + (c.actors.get(a) ?? 0), 0), money: 0 });
    const outcomes = [...c.outcomes, ...extraOutcomes];
    const times = outcomes.map((o) => o.at.getTime());
    const first = times.length ? new Date(Math.min(...times)) : null;
    const lastTouch = times.length ? new Date(Math.max(...times)) : null;
    const lastUsed = lastTouch && lastUp && lastUp > lastTouch ? lastUp : lastTouch;
    projects.push({
      key, title: key, users: c.users + extraUsers, money_usd: moneyOf(c), outcomes,
      first_outcome_at: first, last_used_at: lastUsed,
      commit_weeks: commitWeeks.filter((w) => w >= weekFloor(ctx.now)),
    });
  }
  return { projects, perSource };
}
const weekFloor = (now: Date) => {
  const y = new Date(now.getTime() - 52 * 7 * DAY_MS);
  return `${y.getUTCFullYear()}-W00`;
};

export function holdReason(prev: number | null, next: number, shares: number[]): 'jump' | 'one_source' | null {
  if (prev !== null && next - prev >= HOLD.jump) return 'jump';
  if (next >= HOLD.minScore && shares.some((s) => s > HOLD.oneSource)) return 'one_source';
  return null;
}

/**
 * Each source's share of the outcomes the score stands on: its part of the users and money points
 * over both. Every other part derives from those outcomes, so one source holding all users is 1.0
 * (a share of the total score could never pass 0.8 at 60+, since users top out at 45). Pure.
 */
export function sourceShares(perSource: Map<number, { users: number; money: number }>, s: Scored): number[] {
  const denom = s.parts.users.points + s.parts.money.points;
  if (denom === 0) return [];
  const U = s.parts.users.raw.U || 1;
  const M = s.parts.money.raw.M || 1;
  return [...perSource.values()].map((x) => ((x.users / U) * s.parts.users.points + (x.money / M) * s.parts.money.points) / denom);
}

export function emptyReason(f: { login: boolean; proposed: number; verified: number; okReadings: number; failedReadings: number }): EmptyReason {
  if (f.verified === 0) return f.proposed > 0 || f.login ? 'ownership_unproven' : 'no_github';
  if (f.okReadings === 0 && f.failedReadings > 0) return 'read_failed';
  return 'nothing_live';
}

export async function publicScore(builderId: number) {

/** Who is due today (R8): no score today, and every verified source read today or it's late. */
async function dueToday(day: string, late: boolean, only?: number[]) {
  return sql()<{ builder_id: number }[]>`
    SELECT p.builder_id FROM builder_profiles p

export async function scoreBuilders(now: Date, o: { deadline: number; only?: number[] }) {
  const day = now.toISOString().slice(0, 10);
  const cal = calibration(LIVE_CALIBRATION);
  const due = await dueToday(day, now.getUTCHours() >= LATE_HOUR_UTC, o.only);
  // Who owns which account, for rings (spec 5): proven logins and every group wallet.
  const owners = await sql()<{ actor: string; builder_id: number }[]>`
    SELECT 'gh:' || github_login AS actor, builder_id FROM builder_profiles WHERE github_login IS NOT NULL
    UNION ALL
    SELECT 'wallet:' || w.wallet, COALESCE(i.builder_id, i.id) FROM installation_wallets w JOIN installations i ON i.id = w.installation_id`;
  const owner = new Map(owners.map((r) => [r.actor, r.builder_id]));
  const edges = await ringEdges(owner);
  let scored = 0;
  const held: number[] = [];
  for (const { builder_id: id } of due) {
    if (Date.now() >= o.deadline) break;
    const sources = await sql()<SourceRow[]>`
      SELECT id::int, kind, ref, project_key, (kind = 'repo' AND split_part(ref, '/', 1) <> COALESCE(p.github_login, '')) AS owner_is_org
      FROM builder_sources b JOIN builder_profiles p USING (builder_id)
      WHERE b.builder_id = ${id} AND b.state = 'verified'`;
    const readings = sources.length === 0 ? [] : await sql()<ReadingRow[]>`
      SELECT source_id::int, day::text, ok, signals FROM source_readings
      WHERE source_id IN ${sql()(sources.map((s) => s.id))} AND day > ${new Date(now.getTime() - YEAR_MS)}`;
    const self = new Set([...owner].filter(([, b]) => b === id).map(([a]) => a));
    const { projects, perSource } = buildInputs(sources, readings, { self, owner, edges, person: id, now });
    const s = computeScore(projects, cal, now);
    const prev = await publicScore(id);
    const reason = holdReason(prev?.score ?? null, s.score, sourceShares(perSource, s));
    const all = (await sql()<{ score: number }[]>`SELECT score FROM builder_ranks`).map((r) => r.score);
    const top = s.top ? { key: s.top.key, title: s.top.title, users: Math.round(s.top.users), money_usd: Math.round(s.top.money_usd) } : {};
    const [row] = await sql()<{ id: string }[]>`
      INSERT INTO builder_scores (builder_id, day, score, percentile, parts, top_outcome, formula, calibration, held)
      VALUES (${id}, ${day}, ${s.score}, ${percentileOf(s.score, all)}, ${sql().json(s.parts as never)}, ${sql().json(top as never)}, ${FORMULA}, ${cal.id}, ${reason !== null})
      ON CONFLICT (builder_id, day) DO NOTHING RETURNING id`;
    if (!row) continue;
    scored++;
    await noteEvent('score_computed', () => ({ type: 'score_computed', dedupe_key: `score:${id}:${day}`, installation_id: id, detail: { score: s.score, calibration: cal.id } }));
    if (reason) {
      held.push(id);
      await sql()`UPDATE builder_profiles SET held = true, updated_at = now() WHERE builder_id = ${id}`;
      await noteEvent('score_held', () => ({ type: 'score_held', dedupe_key: `score_held:${id}:${day}`, installation_id: id, detail: { reason, score: s.score, previous: prev?.score ?? null } }));
    }
  }
  return { scored, held };
}

/** Person pairs where one's account is a counted touch of the other's verified sources (latest readings). */
async function ringEdges(owner: Map<string, number>): Promise<[number, number][]> {
  const rows = await sql()<{ builder_id: number; actor: string }[]>`
    SELECT DISTINCT b.builder_id, a.actor FROM builder_sources b
    JOIN LATERAL (SELECT signals FROM source_readings r WHERE r.source_id = b.id AND r.ok ORDER BY r.day DESC LIMIT 1) last ON true
    CROSS JOIN LATERAL (
      SELECT jsonb_array_elements(COALESCE(last.signals->'stargazers', '[]'::jsonb) || COALESCE(last.signals->'forkers', '[]'::jsonb) || COALESCE(last.signals->'callers', '[]'::jsonb))->>'id' AS actor) a
    WHERE b.state = 'verified'`;
  const out: [number, number][] = [];
  for (const r of rows) {
    const counter = owner.get(r.actor);
    if (counter !== undefined && counter !== r.builder_id) out.push([counter, r.builder_id]);
  }
  return out;
}

export async function percentiles(now: Date): Promise<number> {
  const rows = await sql()<{ n: number }[]>`
    WITH pub AS (
      SELECT DISTINCT ON (s.builder_id) s.builder_id, s.score FROM builder_scores s
      WHERE NOT s.held OR EXISTS (SELECT 1 FROM score_releases x WHERE x.builder_id = s.builder_id AND x.day = s.day)
      ORDER BY s.builder_id, s.day DESC),
    ranked AS (
      SELECT builder_id, score, 100.0 * (rank() OVER (ORDER BY score) - 1) / count(*) OVER () AS percentile FROM pub),
    up AS (
      INSERT INTO builder_ranks (builder_id, score, percentile, computed_at)
      SELECT builder_id, score, percentile, ${now} FROM ranked
      ON CONFLICT (builder_id) DO UPDATE SET score = EXCLUDED.score, percentile = EXCLUDED.percentile, computed_at = EXCLUDED.computed_at
      RETURNING 1)
    SELECT count(*)::int AS n FROM up`;
  return rows[0].n;
}

export async function profileEmpty(now: Date): Promise<number> {
  const due = await sql()<{ builder_id: number; login: boolean; proposed: number; verified: number; ok_r: number; failed_r: number; filled: boolean }[]>`
    SELECT p.builder_id, p.github_login IS NOT NULL AS login,
      (SELECT count(*)::int FROM builder_sources b WHERE b.builder_id = p.builder_id AND b.state = 'proposed') AS proposed,
      (SELECT count(*)::int FROM builder_sources b WHERE b.builder_id = p.builder_id AND b.state = 'verified') AS verified,
      (SELECT count(*)::int FROM source_readings r JOIN builder_sources b ON b.id = r.source_id WHERE b.builder_id = p.builder_id AND r.ok) AS ok_r,
      (SELECT count(*)::int FROM source_readings r JOIN builder_sources b ON b.id = r.source_id WHERE b.builder_id = p.builder_id AND NOT r.ok) AS failed_r,
      EXISTS (SELECT 1 FROM builder_scores s WHERE s.builder_id = p.builder_id AND s.score > 0) AS filled
    FROM builder_profiles p
    WHERE p.empty_checked_at IS NULL AND p.first_find_at <= ${new Date(now.getTime() - 10 * 60_000)}`;
  let n = 0;
  for (const r of due) {
    await sql()`UPDATE builder_profiles SET empty_checked_at = ${now} WHERE builder_id = ${r.builder_id}`;
    if (r.filled) continue;
    const missing = emptyReason({ login: r.login, proposed: r.proposed, verified: r.verified, okReadings: r.ok_r, failedReadings: r.failed_r });
    await noteEvent('profile_empty', () => ({ type: 'profile_empty', dedupe_key: `profile_empty:${r.builder_id}`, installation_id: r.builder_id, detail: { missing } }));
    n++;
  }
  return n;
}

export type ScoreCronDeps = { reader?: ReaderDeps; login?: LoginOf; only?: number[] };

/** spec 6: discover, readSources, scoreBuilders, percentiles then profileEmpty; each fails soft. */
export async function runScoreSteps(now: Date, sliceEnd: number, deps: ScoreCronDeps = {}) {
  const reader = deps.reader ?? defaultReaderDeps(now, sliceEnd);
  const out: Record<string, unknown> = {};
  const step = async (name: string, fn: () => Promise<unknown>) => {
    if (Date.now() >= sliceEnd) return void (out[name] = { step: 'skipped' });
    try {
      out[name] = await fn();
    } catch (err) {
      console.error(`[cron] builder score ${name}`, err instanceof Error ? err.name : 'error');
      out[name] = { step: 'error' };
    }
  };
  await step('discover', () => discover(now, { deadline: sliceEnd, reader, login: deps.login, only: deps.only }));
  await step('read', () => readSources(now, { deadline: sliceEnd, reader, only: deps.only }));
  await step('score', () => scoreBuilders(now, { deadline: sliceEnd, only: deps.only }));
  await step('ranks', () => percentiles(now));
  await step('empty', () => profileEmpty(now));
  return out;
}

const NAMES: Record<keyof Parts, string> = { users: 'users', money: 'money', staying: 'staying power', recency: 'recency', consistency: 'shipping consistency' };
export function movedLine(d: Record<keyof Parts, number>): string | null {
  const moved = (Object.keys(d) as (keyof Parts)[]).filter((k) => Math.abs(d[k]) >= 1).sort((a, b) => Math.abs(d[b]) - Math.abs(d[a]));
  if (moved.length === 0) return null;
  const s = moved.map((k) => `${NAMES[k]} ${d[k] > 0 ? '+' : ''}${Math.round(d[k])}`).join(', ');
  return `${s[0].toUpperCase()}${s.slice(1)}.`;
}

export function scoreLines(a: { score: number; percentile: number; change: number | null; moved: string | null; held: boolean; slug: string; next: NextAction; program: string | null }): string {
  const change = a.change === null || a.change === 0 ? '' : `, ${a.change > 0 ? 'up' : 'down'} ${Math.abs(a.change)} since you last asked`;

    `Score ${a.score}, top ${topPercent(a.percentile)}%${change}. ${PROFILE_URL(a.slug)}`,
    a.held ? 'Your newest score is in a quick review.' : a.moved,
    a.next.line,
    a.program,
  ].filter((x): x is string => Boolean(x)).join('\n');
}

export function cardModel(p: ProfileData): CardModel {
  const best = p.projects[0];

  return {
    score: p.score,
    top: `Top ${p.top_percent}% of builders`,

export async function offerCard(builderId: number, lineOneAsks: boolean): Promise<string | null> {

    UPDATE builder_profiles SET card_offered_at = now() WHERE builder_id = ${builderId} AND card_offered_at IS NULL AND NOT hidden RETURNING builder_id`;

export function leaderboardFilters(q: Record<string, string | string[] | undefined>): BoardFilters {
  const one = (k: string) => (typeof q[k] === 'string' ? (q[k] as string) : null);
  const chain = one('chain');

  const page = Number(one('page'));
  return {

    program: program && /^[a-z0-9-]{1,100}$/.test(program) ? program : null,

```ts
import './env.mts';
import { parseArgs } from 'node:util';
import { sql } from '../lib/earnkit/db';

/**
 * v2.12 spec 3: the empty-profile rate for new installs, per day. Shown, never a target. Read-only
 * (one READ ONLY transaction). New: a profile whose first find fell on that UTC day. Empty: it has a
 * profile_empty event (written by the cron 10+ minutes after the first find; needs EARNKIT_EVENT_LOG=on).
 *   pnpm exec tsx apps/frontend/scripts/v212-metric.mts [--as-of <ISO time>] [--days 14]
 */
const { values } = parseArgs({ options: { 'as-of': { type: 'string' }, days: { type: 'string' } } });
const asOf = values['as-of'] ? new Date(values['as-of']) : new Date();
const days = Number(values.days ?? 14);
if (Number.isNaN(asOf.getTime()) || !Number.isInteger(days) || days < 1) {
  console.error('Usage: v212-metric.mts [--as-of <ISO time>] [--days <n>]');
  process.exit(2);
}
const db = sql();
try {
  const rows = await db.begin('read only', (tx) => tx<{ day: string; made: number; empty: number }[]>`
    SELECT p.first_find_at::date::text AS day, count(*)::int AS made,
      count(*) FILTER (WHERE EXISTS (SELECT 1 FROM builder_events e WHERE e.dedupe_key = 'profile_empty:' || p.builder_id))::int AS empty
    FROM builder_profiles p
    WHERE p.first_find_at <= ${asOf} AND p.first_find_at > ${new Date(asOf.getTime() - days * 86_400_000)}
    GROUP BY 1 ORDER BY 1`);
  for (const r of rows) console.log(`${r.day}: ${r.made} new, ${r.empty} empty (${r.made ? Math.round((100 * r.empty) / r.made) : 0}%)`);
  if (rows.length === 0) console.log('No new profiles in the window.');
} finally {
  await db.end();
}
```

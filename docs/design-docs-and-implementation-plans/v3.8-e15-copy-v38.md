**Approval:** Jenil, "Yes, build v3.8" (Nov 24 2026), logged in earnkitai/earnkit#159. Plan: power-user plan v3.8
sections 23.3 (style rules), 23.4 (before and after), 23.5 (next ideal state), 23.7 (enforcement); build plan row

**Goal:** builder lines that are short, plain, and push to the next ideal state, and that never ask the builder for
anything EarnKit or their agent can find or decide (decision 33). Behind `copy_v38`; off, main's lines (`COPY_V37`).

**Shape:**

- `lib/v5/copy.ts`: `COPY_V38` has the same keys as `COPY_V37`; `copy()` picks it when `copy_v38` is on. New keys,
  empty or identical on main so flag-off output is unchanged: `openAskLinked`, `openAskUnlinked`, `openNote`, `usersLookup`,
  `usersNoteLead`, `usersOneNote`, `demoNote`, `startedNote`, `outcomeNote`, `tellWhenLiveNote`, `wholeDollarsNote`,
  `tellAmount`, `amountUnread`, `underADollar`, `sentOr`.
- A removed ask moves to the agent: each fix has an agent note saying what to find and where, and to ask the builder
  only when it is not public. The builder line says what will happen.
- Line parsers that read the old wording also accept the new (`isDoUsersSay`, `isUsersRuleSay`, `SIGNED_USERS`,
  `asksSignIn` and the sign-in link fold, `usersDraft`, find's users note).
- `fixtures/builder-rules.ts`: `builderRulesV2` = v1 + no `;`, en dash or `!`, the 23.7 banned list (`BANNED_V2`), no
  delegable ask (`DELEGABLE`), a sentence cap, and a closing question or Say only when the line needs the builder.

### Task 2: ranking, round 4

**Rulings:**
- L1c-2: a `rule` item may carry `keywords: string[]` (program-file schema, optional, lower-case, at most 8, each at most 30 characters). A rule-bearing program takes the default slot only when one keyword appears (case-insensitive, whole word or phrase) in the project's name, description, README excerpt or topics, or when none of its rules carry keywords. A domain rule with no hit is "unlikely": the program shows under `filter.all` only, and `more` counts it. Catalog: keywords on Meta VR (`vr`, `quest`, `meta`, `hands-first`, `oculus`), Codegeist (`atlassian`, `forge`, `jira`, `confluence`), QNX (`qnx`), PayPal (`paypal`), Farcaster (`farcaster`, `mini app`, `warpcast`), Kiroween (`kiro`), Solana Mobile (`solana mobile`, `seeker`, `saga`, `android`), UGREEN (`ugreen`, `nas`), OTF (`censorship`, `circumvention`, `privacy`, `vpn`, `tor`), goose (`goose`), Filecoin (`filecoin`, `fvm`, `ipfs`), Lido (`lido`, `steth`), Uniswap (`uniswap`, `hook`, `v4`). Person or licence rules (Thiel, Antler, GitHub Secure, HeroDevs, Sovereign) get none.
- L1c-3: step order is own-chain rule-free, own-chain rule-bearing, chain-agnostic rule-free, chain-agnostic rule-bearing (one slot), then deploys on other chains.
- O1: a program closing within 7 days that the project fits (ready or one step) is always in the default reply, in its group, ahead of the caps, its line carrying `closes in {n} days`.
- O2: a rule-only in-person program lists in the In person block with its rule sentence and `Say "yes {n}" if that is you.`; when in-person programs are listed and nothing remote is ready, the closing reads `Nothing remote is ready yet. Say yes and I start the in-person applications.`
- L1c-4: an empty read is cached like any other.

Files: `program-file.ts`, `rank.ts`, `find.ts`, `reply.ts`, `repo-facts.ts`, `programs/*.json` (keywords), `programs/README.md`; tests; Review Focus 2, 3, 5 pinned; re-pin the persona replies and paste them.

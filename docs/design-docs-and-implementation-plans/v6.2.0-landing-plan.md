# v6.2.0: the landing page, fewer programs and fewer words

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task.

**Goal:** The owner's note of 2026-11-10: "fix the landing page, it's so bad, too many programs and overall copy, and any design issues." Today the landing shows every open program (45 cards in four cycling gradients, some with raw summary text as the money), three wordy step cards and a sub line that explains the mechanism. Keep the approved look (the Eckersberg hero, Kaftan, dark rounded cards, the Panini footer) and cut everything that does not help a builder decide to add EarnKit.

**Architecture:** The hero and the footer stay as they are. The steps shrink to three short lines on one strip. The program section becomes a curated "This week" of six programs chosen by a pure rule (closing soon first, then the biggest real amounts, open only, no investments, at most one hackathon per organizer) with a clean money line and a "See all {n} programs" link to /programs, which keeps the full grid. Card looks go from four gradients to two (neutral; the first card blue). Copy follows the owner's rules: short, money first, no eyebrow labels.

**Tech Stack:** Next.js 16 app in `apps/frontend`; the design system in `apps/frontend/DESIGN.md` (tokens in `lib/v5/site-theme.ts`, class strings in `app/components/site/ui.ts`); node:test for `landing.test.ts`, `site-copy.test.ts`, `pages.test.ts`.

**Spec:** this file. Design rules: `apps/frontend/DESIGN.md` (owner-approved; multi-hue gradients read as cheap; premium and minimal; no literal titles; no eyebrow labels; sentence case; no em dashes). The v3.1 landing had four program cards; v5 made it every program.

## Global Constraints

- No new colours, fonts, images or paid services; every token from `site-theme.ts`; no raw hex in components (a test scans `app/`).
- Copy: sentence case, no em dash, no emoji, never score, rank, grade, points, coin, token, streak; every sentence a full stop; no field, tool or file names; no "server".
- Every number on the page comes from real data (`readLanding`); the chip stays the stats money.
- Phone first: nothing wider than 320px breaks; the hero title stays one line as today.
- Commit messages start with `v6.2.0:`. Docs (`DESIGN.md`, `architecture-guide.md`, `code-map.md`) updated in the last task.

## Review Focus

1. The landing never shows more than six program cards; /programs still shows every listed program.
2. A program with no stated amount never shows summary prose as its money; it shows its kind line only.
3. A closing-within-14-days program the rule selects shows `Closes {day}` and sits first.
4. The first card is blue and the others neutral; no third look remains in the landing components.
5. The page text contains no sentence over 12 words in the steps strip.

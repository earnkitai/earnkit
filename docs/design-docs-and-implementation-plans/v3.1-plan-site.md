# v3.1 site redesign. Implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the owner-approved v3.1 site (landing, profile, leaderboard, feed, docs, 404, nav, footer) in `apps/frontend`, every number from real data, no card ever empty, phone-safe at 390px.

**Architecture:** New tokens (`lib/earnkit/site-theme.ts`, mirrored as `--ek-s-*` in `globals.css`, read by Tailwind as `s-*`) sit beside the v3 `THEME` (which keeps serving the shell pages, the share card, the badge and the OG image). All new reads live in one new module, `lib/earnkit/site-data.ts`; all new copy and pure formatters in `lib/earnkit/site-copy.ts`. Existing lib modules change only where a shape gains a field (`BenchRow.streak`, `FeedCard.score/commits`, `ProfileCard.commits`, `Landing`), never in the reply logic the P0 plan is editing. Pages are server components; only the hero (pointer drift and arch glow), the footer light, the nav's active link, the docs agent tabs and the install sheet are client components.

**Tech Stack:** Next.js 16.1 app router, React 19, Tailwind 3.4, Postgres (`postgres` tagged template), node:test via tsx, `renderToStaticMarkup` render tests (the v3 pattern in `v3-profile.test.ts`), Playwright from the npx cache for screenshots.

**Spec:** `docs/design-docs-and-implementation-plans/v3.1-site-design.md` (frozen) and the canvas boards (Artifact `https://claude.ai/artifact/MR4rD7VoQWrUaKMNFJzyet`, read with `action: "read"`, `path: "project/<Board>.dc.html"`: Landing, Profile, BackedBuilder, NewBuilder, Leaderboard, Feed, Docs, NotFound, Nav, Foot). The canvas holds exact markup, sizes and copy; this plan quotes what an implementer must not get wrong and maps every element to data. Owner rules: `v3.1-brief-for-next-session.md`. Supersedes `v3.1-plan-p0.md` Task 13.

## Global Constraints

- Copy: short, money first, no emojis, never an em dash, sentence case, no all-caps; "points" never shown on any page until $EARN exists; "Backing" never "community round"; "of N builders" and any rank ("#N", "Top N%", metal pills) only from `RANK_MIN_POOL` (10) ranked builders; never "this week" right after "builders"; no period directly after a link.
- Cost: no new paid service, no new cron, no new table. Paintings and the Kaftan font are static files committed to the repo and served by the app; no Next image optimizer for the paintings (pre-sized variants, plain `<img srcSet>`), so Railway CPU stays flat.
- Every number on a page comes from a read named in this plan. Canvas example data (`[N]`, `[month]`, Maya, Sam, Ari...) never ships.
- Backing (the Token card, the Backed filter and tag, any coin line) only while `raisingEnabled()` (`lib/earnkit/builder-score-flag.ts`), and never for a project whose GitHub owner is in `EARNKIT_ORGS` (`lib/earnkit/earnkit-orgs.ts`; covers `earnkitai/earnkit`). Backing never moves Shipping or rank.
- Phone: every page works at 390x844 with 16px side gutters (`px-4`), no horizontal page scroll, every tap target at least 44px tall on a phone. Desktop gutters 24px (`md:px-6`). Column max-width 1240px (landing, feed) or 1200px (profile, leaderboard, docs, 404).
- Motion: every transition, the hero drift, the footer light, the live dot pulse and the twinkles are off under `prefers-reduced-motion: reduce` (CSS media query plus a `useReducedMotion()` check in the two pointer components).
- Colours only from `SITE` tokens (Tailwind `s-*`); `tailwind.config.ts` holds no raw hex; no `/NN` opacity modifier on a token class (the var() tokens cannot carry it; v3-landing (i) rule still applies).
- P0 is running in parallel: do not edit `mcp.ts`, `tools.ts`, `present.ts`, `bench-find.ts`, `bench-reply.ts`, `weekly-moment.ts`, `digest.ts`, `backers.ts`, `best-fit.ts`, `copy-review.test.ts`, `db/schema.sql`. Lib files this plan may edit: `bench-data.ts`, `feed.ts`, `landing.ts`, `page-data.ts`, `week-facts.ts` (one export), `docs-copy.ts`, `footer-links.ts`, `brand-page.ts` (one nav link), `theme.ts` (no value changes). Rebase on P0 commits before each task (`git log --oneline -3` first).
- Tests: `node:test` via tsx, a `*.test.ts` in `apps/frontend/lib/earnkit/`. One file:
  `DATABASE_URL=postgres://jenil@localhost:5432/earnkit_test node apps/frontend/lib/earnkit/fixtures/test-db-template.mjs && DATABASE_URL=postgres://jenil@localhost:5432/earnkit_test npx tsx --test --import ./apps/frontend/lib/earnkit/fixtures/test-guard.ts apps/frontend/lib/earnkit/<file>.test.ts`
  Full: `DATABASE_URL=... pnpm test`. Also `cd apps/frontend && npx tsc --noEmit -p . && npx eslint .`, and `npx next build` in each page task.
- Old pins: a task that replaces markup updates the existing tests that pin the replaced markup (the lists are in each task). A pin on a rule (em dash, rank pool, raising gate, private repo name, copy words) is moved to the new markup, never deleted.
- Commit after each task on `v3.1-founder-power-user`; messages end with a blank line then `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`; no push.
- Model per task: **I** = implementer, **R** = reviewer. Opus for design-heavy page tasks, money/Backing reads and copy; Sonnet otherwise.

## Review Focus

1. **Backing guard.** With `EARNKIT_RAISING=on`, a builder whose main project is `earnkitai/earnkit` (or any `EARNKIT_ORGS` owner) with an open coin shows no Token card, no Backed tag, no "Back" link; with the flag off nobody does. Pinned in Task 3 test (f) and Task 7 test (d).
2. **Pool under 10.** With 9 ranked builders no page shows a standing pill, "#N", a metal place pill, "Top N%" or "of N builders"; with 10 they show. Pinned in Task 3 test (e), Task 7 test (e), Task 8 test (c).
3. **Empty and partial data.** A no-project page, a confirming page, a first-week page with one log card and no score, and a feed week with zero rows each render every card with content; no rendered text contains `undefined`, `null`, `NaN`, `[`, or a bare `$`. Pinned in Task 7 test (f), Task 6 test (d), Task 9 test (d).
4. **Private repo.** A hidden repo's project panel shows `Private project` (`PRIVATE_NAME`), no repo link, no GitHub button, no about line from the repo, and Highlights never names the repo. Pinned in Task 3 test (g) and Task 7 test (g).
5. **Phone width with long strings.** A 50-character X name, a 15-character handle, a 40-character project name and a 6-digit commit count never widen any page past 390px. Pinned by the seeded `long_name_builder` in the harness (Task 5) and measured on every page in Task 11.

# Install and GitHub steps research (2026-10-22)

Source of truth for install copy and the "No GitHub yet?" help. Only use steps marked confirmed. Re-check before changing copy.

## Agents (EarnKit MCP URL: https://earnkit.com/mcp, OAuth via X)

**Claude (claude.ai and desktop), confirmed** (https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp)
1. Customize, then Connectors.
2. "+ Add", then "Add custom connector".
3. Name it EarnKit, paste https://earnkit.com/mcp, "Continue".
4. Choose "Sign in now", keep "Use Claude's published identity (Recommended)", "Add". Sign in with X.
5. In a chat: "+" at the lower left, "Connectors", turn EarnKit on.
Plans: Free (one custom connector), Pro, Max, Team, Enterprise. Team/Enterprise: an owner adds it first under Organization settings, Connectors. Desktop uses the same account setting.

**Grok (grok.com), confirmed steps, OAuth for custom servers unconfirmed** (https://docs.x.ai/grok/connectors)
1. grok.com/connectors.
2. "New Connector", then "Custom".
3. Paste the URL and sign in.
Grok Bot (xAI's agent product) adds servers by plugin or by asking the bot in chat (third-party guides only).

**ChatGPT, unconfirmed (official pages not readable on 2026-10-22)**
Settings, Apps, Advanced settings, turn on Developer mode, "Create app", paste URL, auth OAuth. Reported plans: Plus, Pro, Business, Enterprise, Edu on web; Free not supported; write actions on Plus may be limited. Verify before shipping copy.

## Vibecoding tools to GitHub

**Lovable, confirmed** (https://docs.lovable.dev/integrations/github): Project settings, Git, GitHub (or "+" by the chat, Project, GitHub); "Add connection", install on GitHub, pick your account, "Install & Authorize"; "Connect" next to your account. New private repo in your account; two-way auto sync on main.

**Bolt.new, confirmed** (https://support.bolt.new/integrations/git): GitHub icon top right; "Log in to GitHub", "Authorize"; "Install the GitHub App", "Install & Authorize"; GitHub icon again, name the repo, "Create repository". Private repo in your account; auto commits on main.

**v0, medium** (https://v0.app/docs/github): Project menu, Settings, GitHub, "Connect"; choose account; name it, "Create Repository". Private. Changes land on a working branch; "Publish" merges to main. EarnKit must read the commits that reach the default branch, so v0 users should publish.

**Replit, unconfirmed**: Tools, Git, "Initialize Git Repository", then "Connect to GitHub". Do not ship step-by-step copy until confirmed.

**GitHub App page wording, confirmed**: "All repositories" / "Only select repositories" (https://docs.github.com/en/apps/using-github-apps/installing-a-github-app-from-a-third-party).

# Install and GitHub steps research (2026-10-22)

Source of truth for install copy and the "No GitHub yet?" help. Only use steps marked confirmed. Re-check before changing copy.

## Agents (EarnKit MCP URL: https://earnkit.com/mcp, OAuth via X)

**Claude (claude.ai and desktop), confirmed** (https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp)
1. Customize, then Connectors.
2. "+ Add", then "Add custom connector".
3. Name it EarnKit, paste https://earnkit.com/mcp, "Continue".
4. Choose "Sign in now", keep "Use Claude's published identity (Recommended)", "Add". Sign in with X.
5. In a chat: "+" at the lower left, "Connectors", turn EarnKit on.
Plans: Free (one custom connector), Pro, Max, Team, Enterprise. Team/Enterprise: an owner adds it first under Organization settings, Connectors. Desktop uses the same account setting.

**Grok Bot, confirmed from the app code** (Grok Bot v0.75.0 by SpaceXAI, built by Anysphere; read from its app.asar on 2026-10-23, evidence in the v3.1 GTM journey audit)
Grok Bot is not Grok (grok.com, its own connectors at grok.com/connectors). Three ways in:
1. One click (what earnkit.com shows): `grokbot://app/v1/prompt?text=<urlencoded, at most 1000 characters>` opens Grok Bot with the ask typed in the main bot's composer: "Add a custom MCP server called EarnKit at https://earnkit.com/mcp, sign me in, then ask EarnKit what I can earn." It never sends: the builder presses Enter, then "Add it" (the bot's confirmation), then "Authorize". A composer that already holds a draft keeps it. Needs the app's main-agent gate (rejected with "no-main-agent" without it), so the manual steps stay under the button. The prompt route is not allowed over https.
2. By hand: Plugins, then "Add a custom connector": Name, Type "Remote HTTPS", "Server URL", optional headers and OAuth client id/secret, or a JSON tab ("MCP server JSON", `{"mcpServers":{"earnkit":{"url":"https://earnkit.com/mcp"}}}`). "Save", then under Installed "Authenticate" runs the browser OAuth (sign in with X).
3. Marketplace: Plugins, search, Add, Authenticate; only once EarnKit is a published Cursor plugin (one listing covers Cursor and Grok Bot). The https one-click is then `https://cursor.com/grok-bot/link/v1/plugin/add?id=<numeric plugin id>`.
OAuth: discovery, DCR and CIMD. Its client metadata (https://cursor.com/oauth/mcp-client.json) names the client "Cursor" with redirect URIs `https://www.cursor.com/agents/mcp/oauth/callback`, `https://www.cursor.com/bot/mcp/oauth/callback`, `https://grok.com/connectors-oauth-exchange-code/` and localhost:8787; the app also uses `grokbot://mcp/oauth/callback`. EarnKit trusts the three https callbacks exactly (`oauth.ts AGENT_REDIRECT_URIS`, v3.1 GTM W1), so a Grok Bot builder goes straight to X. Which one Grok Bot registers is still to read from the `/oauth/register` logs on a real install.
Paid: $200/mo standalone after a 14-day trial, or in SuperGrok Heavy, Cursor Ultra and Cursor Teams Premium. Team admins can block custom servers.

**Muse (Meta), medium (third-party guides)**: no add-server form. The builder asks Muse in chat to "build a custom connector" to the URL, then to test it and "save it as a skill" (else Muse rebuilds it every time). OAuth for custom connectors is undocumented. earnkit.com shows a copy-message box.

**OpenClaw, confirmed** (https://docs.openclaw.ai/tools/mcp): `openclaw mcp add earnkit --url https://earnkit.com/mcp --transport streamable-http`, then with the gateway stopped `openclaw gateway stop`, `openclaw mcp login earnkit`, `openclaw gateway start`. A headless server whose browser can't reach the callback uses the `--code` command the login prints.

**Hermes Agent, confirmed** (https://hermes-agent.nousresearch.com/docs/user-guide/features/mcp): no add-by-URL command. `~/.hermes/config.yaml`: `mcp_servers: earnkit: url: "https://earnkit.com/mcp", auth: oauth`, then `hermes mcp login earnkit` and `/reload-mcp`. Once EarnKit is in the Hermes reviewed catalog, `hermes mcp install earnkit` is the one-liner (owner step).

**ChatGPT, unconfirmed (official pages not readable on 2026-10-22)**
Settings, Apps, Advanced settings, turn on Developer mode, "Create app", paste URL, auth OAuth. Reported plans: Plus, Pro, Business, Enterprise, Edu on web; Free not supported; write actions on Plus may be limited. Verify before shipping copy.

## Vibecoding tools to GitHub

**Lovable, confirmed** (https://docs.lovable.dev/integrations/github): Project settings, Git, GitHub (or "+" by the chat, Project, GitHub); "Add connection", install on GitHub, pick your account, "Install & Authorize"; "Connect" next to your account. New private repo in your account; two-way auto sync on main.

**Bolt.new, confirmed** (https://support.bolt.new/integrations/git): GitHub icon top right; "Log in to GitHub", "Authorize"; "Install the GitHub App", "Install & Authorize"; GitHub icon again, name the repo, "Create repository". Private repo in your account; auto commits on main.

**v0, medium** (https://v0.app/docs/github): Project menu, Settings, GitHub, "Connect"; choose account; name it, "Create Repository". Private. Changes land on a working branch; "Publish" merges to main. EarnKit must read the commits that reach the default branch, so v0 users should publish.

**Replit, unconfirmed**: Tools, Git, "Initialize Git Repository", then "Connect to GitHub". Do not ship step-by-step copy until confirmed.

**GitHub App page wording, confirmed**: "All repositories" / "Only select repositories" (https://docs.github.com/en/apps/using-github-apps/installing-a-github-app-from-a-third-party).

# v2.14 One Account Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a builder adds EarnKit to an agent and signs in with X during the install's OAuth step, so every agent signed in with the same X is the same person with one page at earnkit.com/<x-handle>; a repo counts only once the read-only GitHub App is installed on it; every Monday EarnKit writes the week's ship log entry itself from the repo (titles, or facts only for a private repo); and every reply is one of five states with one link and one question. Everything the two retired flags hid, the claim and join machinery, the proof branch and the proof line are deleted. Free: no AI, no new paid service.

**Architecture:**
- **Tasks 1 to 3 clear the ground:** the client preflight and the fallback design (T1); one test database per test file and the real-MCP-layer test helper (T2); `EARNKIT_BUILDER_SCORE` and `EARNKIT_BENCH` retired, with every flag-off path deleted (T3).
- **Tasks 4 and 5 are the account:** "Sign in with X" at `/oauth/authorize`, the issued token bound to the X user id, the person resolved from it, and the migration of claimed pages and their installations (T4); the one-time sign-in link with a paste-back code, for clients that can't and for installations from before v2.14 (T5).
- **Task 6 is the one proof:** the App install verifies the repo (`github_app`), readings use the installation's token, and the proof branch, the proof line, discovery's login clues and the GitHub sign-in proof go (T6).
- **Task 7 removes what X at install makes dead:** claims, joins, notices, detach, probation, pickup and login contests, tables kept (T7).
- **Tasks 8 and 9 are what the builder sees:** the self-writing ship log (T8); the reply as a five-state machine with one copy table (T9).
- **Tasks 10 to 12 close:** self-hosted fonts (T10); docs and the acceptance runbook (T11); the journey test of acceptance 1 to 5 (T12).

**Tech Stack:** Next.js 16 app router (route handlers, `next/font/local`, `permanentRedirect`), postgres.js, zod v4, `@modelcontextprotocol/sdk` (`McpServer`, `Client`, `InMemoryTransport`), React 19 `renderToStaticMarkup` for markup tests, node:test via `tsx --test` (Node 24). No new dependency, no new service.

**Spec:** docs/design-docs-and-implementation-plans/v2.14-one-account.md (binding).

Read with it: `docs/codebase-context/architecture-guide.md` sections "v2.12.1 Where you stand" (Identity), "v2.13 The Bench", "v2.13.3" (item 5, the App) and "v2.13.4"; `v2.13-the-bench-plan.md` (house style). 2. **The token's X binding across reconnects and accounts.** Same registration and same X is the same installation; same registration and another X is a new installation that never sees the first one's data; a code whose `x` payload was edited fails `invalid_grant`; a pre-v2.14 anonymous token keeps working anonymously; a Grok-hosted client gets no X step; a claude.ai client signed in with X is not a shared client. ## Plan rulings (spec ambiguities and conflicts with the code, resolved)

- **A1, per-user connectors are not shared clients.** Claude Desktop, claude.ai and the Claude mobile apps all return to `https://claude.ai/api/mcp/auth_callback`, and ChatGPT to `chatgpt.com`, so today's `isSharedClient` (by redirect host) marks every Claude Desktop and web user "shared" (no page at all). Each of their users signs in in their own browser, so they get the X step. "Serves many builders" (no X step, today's per-call behaviour) is only `HOSTED_CLIENT_NAMES` or a redirect host under `grok.com`, `x.ai`, `x.com`, `meta.ai` (`oauth.ts servesMany`). An installation made from an X-signed code is never `shared_client`.
- **A2, one installation per registration and X account.** For an X-signed code the installation key is `clientKeyOf(client_id + "\nx:" + x_user_id)`: the same agent re-authorizing with the same X is the same installation; another X account on the same registration makes a new installation (the first is never handed over).
- **A3, person = the page that holds the X user id.** `installations.x_user_id` (written only at the token exchange from the signed code, or by the T5 paste code, and by the v2.14 bind migration; cleared by events-redact) decides the tools' id: `connectInstallation` returns the root of `builder_profiles.x_user_id = installations.x_user_id` first, then `builder_id`, then the installation itself.
- **A4, which redirects go straight to X.** Loopback, a custom app scheme (`cursor://`) and the per-user agent hosts (`claude.ai`, `chatgpt.com`, `openai.com`, `cursor.com`) go straight to X (the code can only land in the signer's own agent). Any other https host first shows one page naming it ("You're connecting EarnKit to <host>.") with the warning and a "Continue with X" link. **Superseded by ruling S6 (T4):** only the three exact documented callbacks (`https://claude.ai/api/mcp/auth_callback`, `https://chatgpt.com/connector_platform_oauth_redirect`, `https://www.cursor.com/agents/mcp/oauth/callback`), loopback (any port) and the known agent app schemes (`cursor`, `vscode`, `vscode-insiders`, `windsurf`, `claude`; T4 fix round 1) skip the page; every other redirect, including subdomains, other paths, `chatgpt.com/connector/oauth/<id>` and every other non-http(s) scheme (browser trampolines, unknown), sees it with the full redirect URI (`oauth.ts AGENT_REDIRECT_URIS`, `AGENT_APP_SCHEMES`).
- **A5, X off or the X account cleared by the owner.** Without `X_CLIENT_ID` and `X_CLIENT_SECRET` the authorize step approves anonymously, as today. An X account in `x_owner_clears` gets "This X account can't sign in to EarnKit right now." and no code.
- **A6, the fallback is a link plus a paste-back code.** The link alone never binds (a forwarded link would otherwise attach the sender's agent to the victim's X). After X, the page shows a 12-character code; the agent that minted the link sends it as `find { sign_in_code }` within 15 minutes and only then is that installation bound. Installations from before v2.14 that never claimed get the same link (they can't re-run OAuth by themselves).
- **A7, the one merge left.** An installation from before v2.14 that holds data and signs in (T5) to an X account that already has a page is merged into that page with the page's root kept (`linkInstallations(own, [root], { keep: root })`). A fresh installation is attached with `builder_id` only. No other path merges. **Superseded (controller ruling, no merge):** an installation signing in with an X that already has a page attaches alone (`builder_id` only); its old group or data is never merged into the page. T4's `attachToX` never calls `linkInstallations`, which keeps its v2.13 signature (no `keep`).
- **A8, what the App proves.** The App setup (sign-in hop, install, `appProof`) verifies the repo source with the new proof `github_app` (in `CONFIRMED_PROOFS`), storing GitHub's repo id, owner, owner type and `public_at`. A fork or template is refused (`derived`); a repo another person already holds stays theirs (`taken`). A daily `app_check` step returns a `github_app` source whose repo GitHub no longer lists an installation for to `proposed` (`reject_reason = 'app_removed'`) and rescores at once. The 90-day org proof expiry stays for old `proof_branch` rows; their re-proof is the App.
- **A9, an App installed outside the link.** It proves nothing until the builder opens the reply's install link once (the sign-in hop names the installer). The App's GitHub settings need "Redirect on update" so an already installed App still lands on the setup URL (owner step).
- **A10, the shared `GITHUB_TOKEN`.** Read only for repo sources with no App proof (public reads of things not yet installed, and pre-v2.14 verified public repos). An App-proven source is always read with its installation token, minted per call.
- **A11, ship log titles.** Only for App-proven projects (read with the installation token). PR titles merged in the week first, then commit titles, each newest first; conventional prefixes (`feat:`, `fix(x):`) stripped, first letter capitalized, 80 characters. A private repo's titles are neither read nor stored while titles are off (`builder_profiles.ship_titles_at` null). Stored in `project_updates.titles text[]`.
- **A12, `tell updates`.** `{ titles: true | false }` is the setting. `{ on }` from an older agent is accepted and answered "Your ship log writes itself every Monday from what you ship." `update { text }` adds the agent's one line to the week; `update { hide }` is unchanged; both pass `checkUpdate`.
- **A13, "Shipping weekly".** The project's `streak >= 2`; the streak reads "<n> weeks in a row" (the chip's words).
- **A14, the one link.** The state's action link (sign-in or install) is the reply's one https link and the page is named beside it without https ("Your page: earnkit.com/<handle>"); with no action link the page line is the https link.
- **A15, variants of "Project, App not installed".** Another person holds the repo: "<Project> is already on the Bench under another account." with "Want to use a different project?". A fork or template: "<Project> is a copy of someone else's project. Use your own." with the same question. No client documents a timeout for the interactive part of authorize (our page, the trip to X and back). Claude documents 10 seconds for the discovery, registration and token endpoints (30 for refresh), so the token exchange must stay fast (T4 binds in one transaction). MCP spec 2025-11-25 leaves the authorization server's user interaction out of scope (a third-party IdP in between is allowed), requires exact redirect matching and PKCE S256, and says the consent screen must show the redirect host when CIMD is used (A4's interstitial does this for unknown hosts).

What our server needs, from these findings: accept every redirect form above (today's `isAllowedRedirectUri` already does: https, loopback http, custom schemes); keep the pending authorize request server side keyed by our own X state (T4 `x_signins`); a `SameSite=Lax` cookie (X's return is a top-level GET); a 15-minute window; `iss` in the authorization response (A22).

**What can't be verified without a human (copied into the runbook, section 0):**
1. A full X round trip in each of the five clients, including one where the person waits 2 minutes on X before approving (a hidden timeout or state expiry in the client).
2. Whether Claude Desktop and Cursor open the system browser or an embedded window (an embedded window may not carry the person's X session; they then type their X password once).
3. Whether ChatGPT's DCR registration is per user or per workspace, and whether Plus can add a custom MCP server at all.
4. Whether claude.ai shows a reconnect prompt for a 401 (we issue no refresh tokens and our tokens don't expire, so this only matters if a token is ever revoked).
5. That each client lands back on its own chat with the connector shown as connected, and that the first reply shows the page link.

**The fallback (for a client that can't finish a browser step, and for installations from before v2.14), built in T5:**
- The first reply's stand line is "You're not on the Bench yet." and its question is "Sign in with X to get your page (one click): <link>" then "Want me to put your work on the Bench once you're in?" (the link is the reply's one link).
- The link is `https://earnkit.com/signin/<code>`: 16 random bytes, only its sha256 kept, valid 24 hours, one per installation at a time (an open one is shown again).
- The page names the agent ("This agent: Cursor, connected 3 minutes ago.") and warns "Only continue if your own agent gave you this link." before one "Continue with X" link; the X state is bound to this browser's cookie, as at install.
- After X the page says "Signed in as @handle." and "Paste this code to your agent: ABCD-EFGH-JKMN" (12 characters, 15 minutes, one use). The agent sends `find { sign_in_code }`; only the installation that minted the link can use it. Then the installation is bound exactly as an X-signed token is (T4 `attachToX`).

```ts
import { createHash } from 'node:crypto';
import { execFileSync } from 'node:child_process';
import { join } from 'node:path';

/**
 * v2.14 spec 6: one database per test file, so files never race. In a node:test child process (the runner
 * spawns one per file, NODE_TEST_CONTEXT=child...), with DATABASE_URL set, the guard creates
 * ek_t_<file hash>_<pid> from the template (schema run twice, programs synced) and points DATABASE_URL at it;
 * it is dropped when the process exits. Anything else (no DATABASE_URL, a script, the runner itself) is untouched.
 */
export const TEMPLATE_DB = 'ek_test_template';
export const testDbName = (file: string, pid: number) => `ek_t_${createHash('sha256').update(file).digest('hex').slice(0, 10)}_${pid}`;
export function withDatabase(url: string, db: string): string {
  const u = new URL(url);
  u.pathname = `/${db}`;
  return u.toString();
}
export function perFileDatabase(env: NodeJS.ProcessEnv = process.env, argv: string[] = process.argv): string | null {
  const url = env.DATABASE_URL;
  const file = argv[1] ?? '';
  if (!url || env.EK_TEST_DB || !env.NODE_TEST_CONTEXT?.startsWith('child') || !/\.test\.ts$/.test(file)) return null;
  const name = testDbName(file, process.pid);
  const here = import.meta.dirname;
  execFileSync(process.execPath, [join(here, 'test-db-create.mjs'), url, name], { stdio: 'inherit' });
  env.EK_TEST_DB = name;
  env.DATABASE_URL = withDatabase(url, name);
  process.once('exit', () => {
    try {
      execFileSync(process.execPath, [join(here, 'test-db-drop.mjs'), url, name], { stdio: 'ignore' });
    } catch {
      // A leftover is dropped by the next run's template step.
    }
  });
  return name;
```

```js
const at = (url, db) => {
  const u = new URL(url);
  u.pathname = `/${db}`;
  return u.toString();

/**
 * Builds ek_test_template from scratch: schema.sql twice (the rerun proof), then programs-sync, then marks
 * it a template. With `fresh`, also drops leftover ek_t_* databases from earlier runs. Serialized by an
 * advisory lock on the admin database, so concurrent first files wait for one build.
 */
export async function buildTemplate(adminUrl, { fresh = false, ifMissing = false } = {}) {
  const admin = postgres(adminUrl, { max: 1, onnotice: () => {} });
  try {
    await admin`SELECT pg_advisory_lock(hashtext('ek_test_template'))`;
    const [exists] = await admin`SELECT 1 FROM pg_database WHERE datname = ${TEMPLATE_DB}`;
    if (ifMissing && exists) return;
    if (fresh) for (const { datname } of await admin`SELECT datname FROM pg_database WHERE datname LIKE 'ek_t\\_%'`)
      await admin.unsafe(`DROP DATABASE IF EXISTS "${datname}" WITH (FORCE)`);
    if (exists) {
      await admin.unsafe(`ALTER DATABASE "${TEMPLATE_DB}" IS_TEMPLATE false`);
      await admin.unsafe(`DROP DATABASE "${TEMPLATE_DB}" WITH (FORCE)`);
    }
    await admin.unsafe(`CREATE DATABASE "${TEMPLATE_DB}"`);
    const db = postgres(at(adminUrl, TEMPLATE_DB), { max: 1, onnotice: () => {} });
    const schema = readFileSync(join(FRONTEND, 'db', 'schema.sql'), 'utf8');
    await db.unsafe(schema);
    await db.unsafe(schema);
    await db.end();
    execFileSync('pnpm', ['-s', 'exec', 'tsx', join(FRONTEND, 'scripts', 'programs-sync.mts')], {
      stdio: 'ignore', env: { ...process.env, DATABASE_URL: at(adminUrl, TEMPLATE_DB) },
    });
    await admin.unsafe(`ALTER DATABASE "${TEMPLATE_DB}" IS_TEMPLATE true`);
  } finally {
    await admin`SELECT pg_advisory_unlock(hashtext('ek_test_template'))`.catch(() => {});
    await admin.end();
  }
}
```

```ts
import { Client } from '@modelcontextprotocol/sdk/client/index.js';
import { InMemoryTransport } from '@modelcontextprotocol/sdk/inMemory.js';
import { createMcpServer } from '../mcp';
import type { ToolContext, ToolName } from '../tools';

/**
 * v2.14 spec 6: an agent's call as the MCP route makes it: the real server, the real schemas (zod parses and
 * strips before the handler runs), tools/call over an in-memory transport. `reply` is the JSON the tool
 * returned, or null for an error text.
 */
export type McpResult = { isError: boolean; text: string; reply: Record<string, unknown> | null };

async function connected(ctx: ToolContext, campaignOpen: boolean) {
  const server = createMcpServer(ctx, { campaignOpen });
  const [a, b] = InMemoryTransport.createLinkedPair();
  const client = new Client({ name: 'earnkit-test', version: '0' });
  await Promise.all([server.connect(a), client.connect(b)]);
  return client;
}

export async function mcpCall(ctx: ToolContext, name: ToolName, args: Record<string, unknown> = {}, o: { campaignOpen?: boolean } = {}): Promise<McpResult> {
  const client = await connected(ctx, o.campaignOpen ?? false);
  try {
    // An SDK that answers invalid arguments with a JSON-RPC error (instead of an isError result) throws here.
    const r = await client.callTool({ name, arguments: args }).catch((err: unknown) => ({
      isError: true, content: [{ type: 'text', text: err instanceof Error ? err.message : String(err) }],
    }));
    const text = ((r.content as { type: string; text?: string }[] | undefined) ?? []).map((c) => c.text ?? '').join('');
    let reply: Record<string, unknown> | null = null;
    try {
      reply = JSON.parse(text) as Record<string, unknown>;
    } catch {
      reply = null;
    }
    return { isError: r.isError === true, text, reply };
  } finally {
    await client.close();
  }
}

export async function mcpListTools(ctx: ToolContext) {
  const client = await connected(ctx, false);
  try {
    return (await client.listTools()).tools;
  } finally {
    await client.close();
  }
}
```

```ts
/**
 * Validates an authorize request as v2.4 did: an unknown client or an unregistered redirect throws (shown on
 * our page, never redirected); a request without response_type=code and a PKCE S256 challenge is sent back to
 * the redirect with invalid_request.
 */
export function checkAuthorize(params: URLSearchParams): CheckedAuthorize | { error: URL } {
  const clientId = params.get('client_id') ?? '';
  const redirectUri = params.get('redirect_uri') ?? '';
  const client = verify<ClientPayload>('client', clientId);
  if (!client) throw new OAuthError('invalid_client', 'Unknown client_id. Register first.');
  if (!client.r.includes(redirectUri)) throw new OAuthError('invalid_redirect_uri', 'redirect_uri was not registered');
  const state = params.get('state');
  const challenge = params.get('code_challenge');
  if (params.get('response_type') !== 'code' || !challenge || params.get('code_challenge_method') !== 'S256') {
    const back = new URL(redirectUri);
    if (state) back.searchParams.set('state', state);
    back.searchParams.set('error', 'invalid_request');
    back.searchParams.set('error_description', 'Requires response_type=code and a PKCE S256 code_challenge');
    return { error: back };
  }
  const { cls, host } = redirectClass(redirectUri);
  return { req: { client_id: clientId, redirect_uri: redirectUri, state, code_challenge: challenge }, redirectClass: cls, host, many: servesMany(client), clientName: clientNameOf(client.cn) };
}

/**
 * The redirect with a code. v2.14: `x` (the signed-in X user) rides in the signed payload, so the token
 * exchange binds it and nothing else can. The client and redirect are checked again (the request came back
 * from storage). `issuer`: RFC 9207's iss (A22).
 */
export function issueCode(req: PendingAuthorize, x: XUser | null, issuer?: string): URL {
  const client = verify<ClientPayload>('client', req.client_id);
  if (!client || !client.r.includes(req.redirect_uri)) throw new OAuthError('invalid_client', 'Unknown client_id. Register first.');
  const back = new URL(req.redirect_uri);
  if (req.state) back.searchParams.set('state', req.state);
  if (issuer) back.searchParams.set('iss', issuer);
  back.searchParams.set('code', sign('code', {
    c: req.client_id, r: req.redirect_uri, ch: req.code_challenge, e: Date.now() + CODE_TTL_MS, n: randomBytes(12).toString('base64url'),
    ...(x && { x: { id: x.id, u: x.username, n: x.name, a: x.avatar } }),
  } satisfies CodePayload));
  return back;
}

/** The anonymous approval (shared clients, X off): checkAuthorize then a code with no X user. */
export function authorize(params: URLSearchParams, issuer?: string): URL {
  const c = checkAuthorize(params);
  return 'error' in c ? c.error : issueCode(c.req, null, issuer);
}
```

```ts
/**
```

```ts
 * This browser's cookie must match the row (else 403, before any X call, and the row stays for its own
 * browser); the row is deleted on use. X down: 502, nothing issued.

export async function xSignInCallback(request: Request, deps: CallbackDeps = {}): Promise<Response | null> {
  const q = new URL(request.url).searchParams;
  const state = q.get('state') ?? '';
  if (!/^[A-Za-z0-9_-]{43}$/.test(state)) return null;

    if (err instanceof RateLimitError) return signinPage(SIGNIN_TEXT.busy, 429);
    throw err;

  if (!csrf || !/^[A-Za-z0-9_-]{43}$/.test(csrf)) return signinPage(SIGNIN_TEXT.failed, 403);

    DELETE FROM x_signins WHERE state_hash = ${h} AND csrf_hash = ${sha256(csrf)} AND expires_at > now()
    RETURNING purpose, oauth, installation_id, code_verifier`;
  const clear = clearCookie(h);
  if (!row) return signinPage(SIGNIN_TEXT.failed, 403, clear);
  const code = q.get('code') ?? '';
  if (!code || code.length > 1000) return signinPage(SIGNIN_TEXT.failed, 400, clear);
  const x = deps.x ?? xOAuth;

    return signinPage(SIGNIN_TEXT.failed, 502, clear);
  }
  const [cleared] = await sql()`SELECT 1 FROM x_owner_clears WHERE x_user_id = ${user.id}`;
  if (cleared) return signinPage(SIGNIN_TEXT.paused, 403, clear);
  if (row.purpose !== 'install' || !row.oauth) return signinPage(SIGNIN_TEXT.failed, 400, clear); // 'link' rows: T5
  return new Response(null, {
    status: 302,
    headers: { Location: issueCode(row.oauth, user, publicOrigin(request)).toString(), ...clear, 'Cache-Control': 'no-store', 'Referrer-Policy': 'no-referrer' },
  });
}

export type AttachResult = { ok: true; root: number; handle: string; created: boolean } | { ok: false; reason: 'shared' | 'other_x' | 'owner_cleared' | 'claimed_by_other' };

/** No members, not attached, nothing of its own: a token exchange's new installation. */
async function freshInstallation(own: number): Promise<boolean> {
  const [r] = await sql()<{ fresh: boolean }[]>`
    SELECT i.builder_id IS NULL
      AND NOT EXISTS (SELECT 1 FROM installations m WHERE m.builder_id = i.id)
      AND NOT EXISTS (SELECT 1 FROM projects p WHERE p.installation_id = i.id)
      AND NOT EXISTS (SELECT 1 FROM builder_sources s WHERE s.builder_id = i.id AND s.state = 'verified') AS fresh
    FROM installations i WHERE i.id = ${own}`;
  return r?.fresh === true;
}

/**
 * v2.14 spec 1: binds installation `own` to X account `user` (A3). Serialized per X account. The page that
 * holds the X user id is the person: a fresh installation is attached to it (builder_id), an older one with
 * data is merged into it keeping the page's root (A7); with no page yet, one is made from the X profile
 * (ensureProfile + bindX: handle, name, photo). Idempotent. Never a shared group; never an installation bound
 * to another X account; never an X account the owner cleared.
 */
export async function attachToX(own: number, user: XUser, now: Date): Promise<AttachResult> {
  // One X account at a time, by a session advisory lock on a reserved connection that does nothing else, so the
  // writes below (pooled connections, linkInstallations' own transaction and row locks) never wait on it.
  const lock = await sql().reserve();
  try {
    await lock`SELECT pg_advisory_lock(hashtext(${`x_attach:${user.id}`}))`;
    if (await sharedGroup(own)) return { ok: false, reason: 'shared' };
    const [mine] = await sql()<{ x: string | null }[]>`SELECT x_user_id AS x FROM installations WHERE id = ${own}`;
    if (mine?.x && mine.x !== user.id) return { ok: false, reason: 'other_x' };
    const [cleared] = await sql()`SELECT 1 FROM x_owner_clears WHERE x_user_id = ${user.id}`;
    if (cleared) return { ok: false, reason: 'owner_cleared' };
    const [held] = await sql()<{ root: number }[]>`SELECT builder_id AS root FROM builder_profiles WHERE x_user_id = ${user.id}`;
    let root: number;
    let created = false;
    if (held) {
      root = held.root;
      if ((await rootOf(own)) !== root) {
        if (await freshInstallation(own)) {
          await sql()`UPDATE installations SET builder_id = ${root} WHERE id = ${own}`;
          await sql()`DELETE FROM builder_profiles WHERE builder_id = ${own} AND x_user_id IS NULL`;
        } else {
          await linkInstallations(own, [root], { keep: root });
        }
      }
    } else {
      root = await rootOf(own);
      created = (await ensureProfile(root, now))?.created ?? false;
    }
    await sql()`UPDATE installations SET x_user_id = ${user.id} WHERE id = ${own} AND x_user_id IS NULL`;
    // The X profile's handle, name and photo, refreshed at every sign-in (v2.13 B14).
    const r = await bindX(root, user, now);
    if (!r.ok) return { ok: false, reason: r.reason === 'owner_cleared' ? 'owner_cleared' : 'claimed_by_other' };
    return { ok: true, root, handle: r.handle, created };
  } finally {
    await lock`SELECT pg_advisory_unlock(hashtext(${`x_attach:${user.id}`}))`.catch(() => {});
    lock.release();
  }
}
```

(`linkInstallations`, `ensureProfile` and `bindX` run on pooled connections; the reserved connection holds only the `x_attach:<id>` advisory lock, which none of them take, and no row lock, so nothing can deadlock. `bindX` takes `x_user:<id>` and `x_handle:<h>` in its own transaction, as today.)

**Security notes (T4):**
- **Token binding.** `installations.x_user_id` is written only by `attachToX` (and by the v2.14 bind migration; cleared by events-redact), called from the token exchange with the `x` that `exchangeCode` read from an HMAC-signed code (`sign('code', ...)` with `EARNKIT_AUTH_SECRET`); no agent input can set or change it (4.1's tampered code). An installation bound to one X never moves to another (`other_x`), and another X on the same registration is a new installation (A2), so one person's token never acts as another's page.
- **OAuth state and PKCE.** The client's `state` and `code_challenge` are stored server side and copied into the code; the client's verifier is still checked at the token exchange. EarnKit's own PKCE with X is separate. X's `state` is 32 random bytes, stored hashed, bound to this browser's `__Host-eki-` cookie (Secure, HttpOnly, Lax, path /, 15 minutes), deleted on use: a forwarded or replayed X return finishes nowhere (4.5). The redirect is checked against the signed client before X is called and again before the code is sent; we never redirect to an unregistered URI.
- **Phishing.** An attacker can only receive a victim's code through a redirect URI they control: loopback and app schemes land on the victim's own machine, the per-user agent hosts in the victim's own session. Any other https host gets a page naming it with "Only continue if you started this from your own agent." (A4, 4.3), which is the consent MCP 2025-11-25 asks to show.
- **X token.** Used for one `/2/users/me` read, never stored or logged; errors log the class name only.
- **Owner clears.** An X account in `x_owner_clears` gets no code (4.10) and `attachToX` refuses it.
- **Migration.** Only fills NULLs, never for shared clients, so a rerun on every deploy is a no-op (4.11).

```ts
  if (typeof raw !== 'string' || raw.length > 40) return null;
  const c = raw.toUpperCase().replace(/[\s-]/g, '');
  return /^[ABCDEFGHJKMNPQRSTUVWXYZ23456789]{12}$/.test(c) ? c : null;

/** "just now", "3 minutes ago", "2 hours ago", "4 days ago" (moved from claim.ts). Pure. */
export function agoText(at: Date, now: Date = new Date()): string {
  const m = Math.floor((now.getTime() - at.getTime()) / 60_000);
  if (m < 1) return 'just now';
  const [n, unit] = m < 60 ? [m, 'minute'] : m < 48 * 60 ? [Math.floor(m / 60), 'hour'] : [Math.floor(m / 1440), 'day'];
  return `${n} ${unit}${n === 1 ? '' : 's'} ago`;
}

export async function signInLink(own: number, now: Date): Promise<string | null> {
  const secret = process.env.EARNKIT_AUTH_SECRET;
  if (!secret || !xSignInEnabled() || (await sharedGroup(own))) return null;
  const [i] = await sql()<{ x: string | null }[]>`SELECT x_user_id AS x FROM installations WHERE id = ${own}`;
  if (!i || i.x) return null;
  // As github-verify.ts createVerifyLink: the code is HMAC(secret, seed), so an open link (unused, no sign-in on
  // it yet, an hour or more left) is shown again while the database never holds a usable code.
  const codeOf = (seed: string) => createHmac('sha256', secret).update(`signin:v1:${seed}`).digest().subarray(0, 16).toString('base64url');
  const [open] = await sql()<{ seed: string }[]>`
    SELECT seed FROM x_signin_links WHERE installation_id = ${own} AND used_at IS NULL AND x_user_id IS NULL AND seed IS NOT NULL
      AND expires_at > ${new Date(now.getTime() + LINK_REUSE_MIN_MS)} ORDER BY created_at DESC LIMIT 1`;
  if (open) return `${siteUrl()}/signin/${codeOf(open.seed)}`;
  const seed = randomBytes(16).toString('base64url');
  const code = codeOf(seed);
  await sql()`
    INSERT INTO x_signin_links (link_hash, seed, installation_id, created_at, expires_at)
    VALUES (${sha256(code)}, ${seed}, ${own}, ${now}, ${new Date(now.getTime() + LINK_TTL_MS)})`;
  return `${siteUrl()}/signin/${code}`;
}
```

**Security notes (T5):**
- **Phishing.** A forwarded link gets the victim to sign in, but the paste code shows on the victim's screen and binds only for the installation that minted the link (`installation_id = own` in `bindFromPaste`), so the attacker's agent can't use it without the victim reading it out (5.3, 5.5). The page names the agent and its connection time and warns first.
- **One use, short life.** The link: 24 hours, its code derived from a stored seed with `EARNKIT_AUTH_SECRET` (the database alone can't rebuild it), only its hash used for lookup. The paste code: 15 minutes, one use (`UPDATE ... used_at IS NULL ... RETURNING`), 12 characters from a 31-letter alphabet (about 59 bits).
- **No rebinding.** An installation bound to an X account gets no link and can't take a code for another (5.6, `attachToX`'s `other_x`).
- **Login CSRF.** The X state is the same cookie-bound `x_signins` row as at install.

```ts
/**
 * v2.14 spec 2: the read-only GitHub App is the only way a repo is proven. github-app.ts appSetup (the sign-in
 * hop names the installer; appProof: the installation lists the repo and the installer owns the account or
 * administers the repo) calls proveByApp, which reads the repo once with the installation token and verifies

export const APP_PROOF = 'github_app';
export const APP_REMOVED = 'app_removed';
export const APP_CHECK_PER_RUN = 50;
export const APP_CHECK_EVERY_MS = 24 * 60 * 60_000;
export type RepoProof = { ok: true; via: 'app' | 'kept'; owner: string; private: boolean } | { ok: false; why: 'none' | 'taken' | 'copy' };

/** A builder id's person: its installation's group root, else the id itself. */
const rootSql = (db: Db, id: number) => db`COALESCE((SELECT COALESCE(i.builder_id, i.id) FROM installations i WHERE i.id = ${id}), ${id})`;

/** Whether another person already holds a confirmed repo source for `key` (the first holder keeps a repo). Moved from proof-branch.ts. */
export async function heldByOther(builderId: number, key: string, db: Db = sql()): Promise<boolean> {
  const [r] = await db`
    SELECT 1 FROM builder_sources s WHERE s.kind = 'repo' AND s.state = 'verified'
      AND s.proof = ANY(${[...CONFIRMED_PROOFS]}::text[]) AND regexp_replace(lower(trim(s.ref)), '^(https?://)?(www[.])?github[.]com/', '') = ${key.toLowerCase()}
      AND COALESCE((SELECT COALESCE(i.builder_id, i.id) FROM installations i WHERE i.id = s.builder_id), s.builder_id) <> ${rootSql(db, builderId)}
    LIMIT 1`;
  return Boolean(r);
}

/** Whether `key` is this person's proven repo: by the App, or verified before v2.14 (kept). */
export async function repoProof(builderId: number, repoKey: string, db: Db = sql()): Promise<RepoProof> {
  const key = repoKey.toLowerCase();
  const [s] = await db<{ state: string; proof: string | null; gh_owner: string | null; reject_reason: string | null }[]>`
    SELECT state, proof, gh_owner, reject_reason FROM builder_sources
    WHERE builder_id = ${builderId} AND kind = 'repo' AND regexp_replace(lower(trim(ref)), '^(https?://)?(www[.])?github[.]com/', '') = ${key}
    ORDER BY (state = 'verified') DESC, id LIMIT 1`;
  if (s?.state === 'verified' && s.proof && CONFIRMED_PROOFS.has(s.proof))
    return { ok: true, via: s.proof === APP_PROOF ? 'app' : 'kept', owner: s.gh_owner ?? key.split('/')[0], private: !(await repoReadPublic(builderId, key, new Date(), db)) };
  if (s?.reject_reason === 'derived') return { ok: false, why: 'copy' };
  if (await heldByOther(builderId, key, db)) return { ok: false, why: 'taken' };
  return { ok: false, why: 'none' };
}

type RepoMeta = { id: number; private: boolean; fork: boolean; is_template: boolean; owner: { login: string; type: string } };

/** appSetup's last step: the person's repo source verified by the App (A8), then a rescore, so the next reply ranks it. */
export async function proveByApp(a: { builderId: number; repoKey: string; githubInstallationId: number }, deps: AppDeps = {}): Promise<RepoProof> {
  const key = a.repoKey.toLowerCase();
  if (await sharedGroup(a.builderId)) return { ok: false, why: 'none' }; // A19: no person on a shared client
  const f = deps.fetch ?? fetch;
  const token = await installationToken(a.githubInstallationId, key.split('/')[1], deps);
  const res = await f(`https://api.github.com/repos/${key}`, {
    headers: { Accept: 'application/vnd.github+json', Authorization: `Bearer ${token}`, 'User-Agent': 'earnkit', 'X-GitHub-Api-Version': '2022-11-28' },
    redirect: 'error', signal: AbortSignal.timeout(10_000),
  });
  if (!res.ok) {
    await res.body?.cancel().catch(() => {});
    return { ok: false, why: 'none' };
  }
  const meta = (await res.json()) as RepoMeta;
  const now = deps.now ?? new Date();
  await proposeSource({ builder_id: a.builderId, kind: 'repo', ref: key, project_key: key, proposed_by: 'server' });
  const [row] = await sql()<{ id: number }[]>`SELECT id::int AS id FROM builder_sources WHERE builder_id = ${a.builderId} AND kind = 'repo' AND regexp_replace(lower(trim(ref)), '^(https?://)?(www[.])?github[.]com/', '') = ${key} ORDER BY id LIMIT 1`;
  if (meta.fork || meta.is_template) {
    await rejectSource(row.id, 'derived');
    return { ok: false, why: 'copy' };
  }
  if (await heldByOther(a.builderId, key)) return { ok: false, why: 'taken' };
  // The App is the strongest proof: it verifies a proposed, rejected or stale row alike.
  await sql()`
    UPDATE builder_sources SET state = 'verified', proof = ${APP_PROOF}, verified_at = ${now}, reject_reason = NULL, app_checked_at = ${now},
      gh_repo_id = ${meta.id}, gh_owner = ${meta.owner.login.toLowerCase()}, gh_owner_type = ${meta.owner.type}, public_at = ${meta.private ? null : now}
    WHERE id = ${row.id}`;
  await (await import('./events')).noteEvent('source_verified', () => ({
    type: 'source_verified', dedupe_key: `source_verified:${row.id}`, installation_id: a.builderId, detail: { source_id: row.id, kind: 'repo', proof: APP_PROOF },
  }));
  await (await import('./person-score')).rescorePerson(a.builderId, now).catch((err: unknown) => console.error('[repo-proof] rescore', err instanceof Error ? err.name : 'error'));
  profileChanged();
  return { ok: true, via: 'app', owner: meta.owner.login.toLowerCase(), private: meta.private };
}

/** The reply's install link (the v2.10 App link: sign-in hop, then install), or null while the App is off. */

  if (!githubAppEnabled()) return null;
  return createVerifyLink({ installationId: builderId, projectId: null, repoKey: repoKey.toLowerCase(), purpose: 'app' }, now).catch(() => null);
}

/** One installation token for one repo of this person, and a GET with it (null on any failure). Never stored or logged. */
export async function appClient(builderId: number, repoKey: string, f: typeof fetch): Promise<(<T>(path: string) => Promise<T | null>) | null> {
  const token = await appTokenFor({ installationId: builderId, repoKey: repoKey.toLowerCase() }, { fetch: f });
  if (!token) return null;
  return async <T,>(path: string): Promise<T | null> => {
    const res = await f(`https://api.github.com${path}`, {
      headers: { Accept: 'application/vnd.github+json', Authorization: `Bearer ${token}`, 'User-Agent': 'earnkit', 'X-GitHub-Api-Version': '2022-11-28' },
      redirect: 'error', signal: AbortSignal.timeout(10_000),
    }).catch(() => null);
    if (!res?.ok) {
      await res?.body?.cancel().catch(() => {});
      return null;
    }
    return (await res.json()) as T;
  };
}

/**
 * A8: each run, up to APP_CHECK_PER_RUN `github_app` sources not checked in a day: GitHub still names an App
 * installation for the repo, or the source goes back to proposed (APP_REMOVED) and the person is rescored at
 * once, so it leaves the Bench (which reads benchConfirmedSql live).
 */
export async function appCheckStep(now: Date, o: { deadline: number; only?: number[]; fetch?: typeof fetch }): Promise<{ checked: number; removed: number }> {
  if (!githubAppEnabled()) return { checked: 0, removed: 0 };
  const db = sql();
  const due = await db<{ id: number; builder_id: number; key: string }[]>`
    SELECT id::int AS id, builder_id, regexp_replace(lower(trim(ref)), '^(https?://)?(www[.])?github[.]com/', '') AS key FROM builder_sources
    WHERE kind = 'repo' AND state = 'verified' AND proof = ${APP_PROOF}
      AND (app_checked_at IS NULL OR app_checked_at <= ${new Date(now.getTime() - APP_CHECK_EVERY_MS)})
      ${o.only ? db`AND builder_id IN ${db(o.only.length ? o.only : [-1])}` : db``}
    ORDER BY app_checked_at NULLS FIRST, id LIMIT ${APP_CHECK_PER_RUN}`;
  let checked = 0;
  let removed = 0;
  for (const s of due) {
    if (Date.now() >= o.deadline) break;
    const inst = await repoInstallation(s.key, { fetch: o.fetch, now }).catch(() => undefined);
    if (inst === undefined) continue; // GitHub didn't answer: try again next run
    checked++;
    if (inst !== null) {
      await db`UPDATE builder_sources SET app_checked_at = ${now} WHERE id = ${s.id}`;
      continue;
    }
    await db`UPDATE builder_sources SET state = 'proposed', reject_reason = ${APP_REMOVED}, app_checked_at = ${now} WHERE id = ${s.id} AND state = 'verified'`;
    removed++;
    await (await import('./person-score')).rescorePerson(s.builder_id, now).catch((err: unknown) => console.error('[repo-proof] rescore', err instanceof Error ? err.name : 'error'));
    profileChanged();
  }
  return { checked, removed };
}
```

```ts
import { checkUpdate, type OwnLinks } from './update-text';

/**
 * v2.14 spec 3: the ship log's words are the week's own PR and commit titles (no AI). Merges, "wip", bot
 * authors, version bumps and duplicates are dropped; conventional prefixes stripped; 80 characters; each title
 * must pass the update-text filter (links only to the project's own site or repo, no secrets, no @mentions, no
 * 7-digit runs) or it is dropped. At most 3, PRs merged in the week first, then commits, newest first.
 */
export const TITLES_MAX = 3;
export const TITLE_MAX = 80;
export type RawTitle = { title: string; at: string; source: 'pr' | 'commit'; bot: boolean; merge: boolean };
const DROP = [
  /^merge (pull request|branch|remote-tracking branch|tag)\b/i,
  /^(wip|work in progress)\b/i,
  /^v?\d+(\.\d+){1,3}([-+][\w.]+)?$/i,
  /^(chore|build|ci)\((release|deps|deps-dev)\)!?:/i,
  /^(release|bump(s|ed)?|version)\b.*\d/i,
  /\bbump(s|ed)? (the )?version\b/i,
];
const PREFIX = /^(feat|fix|chore|docs|refactor|perf|style|test|build|ci)(\([^)]*\))?!?:\s*/i;

export function cleanTitle(raw: string): string | null {
  const first = (raw.split(/\r?\n/)[0] ?? '').replace(/\s+/g, ' ').trim();
  if (!first || DROP.some((r) => r.test(first))) return null;
  let t = first.replace(PREFIX, '').trim();
  if (t.length < 3 || DROP.some((r) => r.test(t))) return null;
  t = t[0].toUpperCase() + t.slice(1);
  return t.length > TITLE_MAX ? `${t.slice(0, TITLE_MAX - 3).trimEnd()}...` : t;
}

export function shipTitles(items: RawTitle[], own: OwnLinks): string[] {
  const newest = (a: RawTitle, b: RawTitle) => b.at.localeCompare(a.at);
  const ordered = [...items.filter((i) => i.source === 'pr').sort(newest), ...items.filter((i) => i.source === 'commit').sort(newest)];
  const out: string[] = [];
  const seen = new Set<string>();
  for (const i of ordered) {
    if (i.bot || i.merge) continue;
    const t = cleanTitle(i.title);
    if (!t) continue;
    const k = t.toLowerCase().replace(/[^a-z0-9]+/g, ' ').trim();
    if (seen.has(k)) continue;
    const checked = checkUpdate(t, own);
    if (!checked.ok) continue;
    seen.add(k);
    out.push(checked.text);
    if (out.length === TITLES_MAX) break;
  }
  return out;
}

type ApiCommit = { commit?: { message?: string; author?: { name?: string; date?: string } }; author?: { login?: string; type?: string } | null; parents?: unknown[] };
type ApiPull = { title?: string; merged_at?: string | null; user?: { login?: string; type?: string } | null };
const isBot = (login: string | undefined, type: string | undefined, name?: string) =>
  type === 'Bot' || /\[bot\]$/i.test(login ?? '') || /\[bot\]$/i.test(name ?? '');

/** The week's raw titles through one installation client (repo-proof.ts appClient): 2 calls, at most 100 commits and 50 PRs. */
export async function readWeekTitles(get: <T>(path: string) => Promise<T | null>, repoKey: string, monday: string): Promise<RawTitle[]> {
  const since = `${monday}T00:00:00Z`;
  const until = new Date(new Date(since).getTime() + 7 * 86_400_000).toISOString();
  const [commits, pulls] = await Promise.all([
    get<ApiCommit[]>(`/repos/${repoKey}/commits?since=${encodeURIComponent(since)}&until=${encodeURIComponent(until)}&per_page=100`),
    get<ApiPull[]>(`/repos/${repoKey}/pulls?state=closed&sort=updated&direction=desc&per_page=50`),
  ]);
  const out: RawTitle[] = [];
  for (const p of Array.isArray(pulls) ? pulls : [])
    if (typeof p.title === 'string' && p.merged_at && p.merged_at >= since && p.merged_at < until)
      out.push({ title: p.title, at: p.merged_at, source: 'pr', bot: isBot(p.user?.login, p.user?.type), merge: false });
  for (const c of Array.isArray(commits) ? commits : [])
    if (typeof c.commit?.message === 'string')
      out.push({
        title: c.commit.message, at: c.commit.author?.date ?? since, source: 'commit',
        bot: isBot(c.author?.login, c.author?.type, c.commit.author?.name), merge: (c.parents?.length ?? 1) > 1,
      });
  return out;
}
```

```ts
const onBench = (name: string, rank: string | null) => (rank ? `${name} is on the Bench: ${rank}.` : `${name} is on the Bench.`);

/**

 * question; the link a state carries is its question's (sign-in, install), else the page.

export const STATE_COPY = {
  signed_out: {
    stand: () => NOT_ON_BENCH,
    ask: (link: string) => `Sign in with X to get your page (one click): ${link}\nWant me to put your work on the Bench once you're in?`,
  },
  no_project: {
    stand: () => NOT_ON_BENCH,
    ask: () => "What's your GitHub, or a link to something you've made?",

    ask: (link: string) => `Install the read-only EarnKit app on it (one click): ${link}\nWant me to count it once that's done?`,
  },
  proven: { stand: (name: string, rank: string | null) => onBench(name, rank) },
  shipping: { stand: (name: string, rank: string | null, streak: number) => `${onBench(name, rank)} ${streakWords(streak)}.` },
} as const;
/** A15: not counted, when the install link can't help. */
export const VARIANT_COPY = {
  taken: { stand: (n: string) => `${n} is already on the Bench under another account.`, ask: (_n: string) => OTHER_PROJECT_ASK },
  copy: { stand: (n: string) => `${n} is a copy of someone else's project. Use your own.`, ask: (_n: string) => OTHER_PROJECT_ASK },
  no_repo: { stand: (n: string) => `${n} isn't counted yet.`, ask: (n: string) => `Where does ${n} live on GitHub?` },
  app_off: { stand: (n: string) => `${n} isn't counted yet.`, ask: (n: string) => shipAsk(n) },
} as const;

export function replyState(i: { signedIn: boolean; project: BenchProject | null; counted: boolean; streak: number }): ReplyState {
  if (!i.signedIn) return 'signed_out';
  if (!i.project) return 'no_project';
  if (!i.counted) return 'not_counted';
  return i.streak >= 2 ? 'shipping' : 'proven';
}

export type BenchView = {
  state: ReplyState; variant: Variant; project: BenchProject | null; rank: string | null; streak: number;
  /** The signed-in person's handle (null: signed out). */
  handle: string | null;
  /** The state's action link: the sign-in link (signed_out) or the install link (not_counted, no variant). */
  link: string | null;
  fund: FundLine[]; due: string[]; ask: BenchAsk;
  /** A17: an outcome question or a submission step, asked instead of the state's question. */
  held: string | null;
};

/** The fixed question of states 1 to 3 (A16), or null for proven and shipping (nextStepAsk decides). Pure. */
export function stateAsk(v: Pick<BenchView, 'state' | 'variant' | 'project' | 'link'>): BenchAsk | null {
  const key = v.project?.key ?? null;
  const name = v.project?.name ?? '';
  if (v.state === 'signed_out') return v.link ? { kind: 'sign_in', project_key: null, line: STATE_COPY.signed_out.ask(v.link) } : null;
  if (v.state === 'no_project') return { kind: 'start', project_key: null, line: STATE_COPY.no_project.ask() };
  if (v.state !== 'not_counted') return null;
  if (v.variant === 'taken' || v.variant === 'copy') return { kind: 'other_project', project_key: key, line: VARIANT_COPY[v.variant].ask(name) };
  if (v.variant === 'no_repo') return { kind: 'repo_behind', project_key: key, line: VARIANT_COPY.no_repo.ask(name) };
  if (v.variant === 'app_off' || !v.link) return { kind: 'suggest', project_key: key, line: VARIANT_COPY.app_off.ask(name) };
  return { kind: 'install_app', project_key: key, line: STATE_COPY.not_counted.ask(v.link) };
}

/** Proven and shipping: the best fit's entry, else a community round, else going live, else one small thing (A16). Pure. */
export function nextStepAsk(o: { project: BenchProject; enter: BenchAsk | null; coin: BenchAsk | null; canHost: boolean; declined: string[] }): BenchAsk {
  const off = (k: BenchAskKind) => o.declined.includes(benchStepKey(k, o.project.key));
  if (o.enter && !off('enter')) return o.enter;
  if (o.coin) return o.coin;
  if (!o.project.live && o.canHost && !off('go_live')) return { kind: 'go_live', project_key: o.project.key, line: goLiveAsk(o.project.name) };
  return { kind: 'suggest', project_key: o.project.key, line: shipAsk(o.project.name) };
}

function standLine(v: BenchView): string {
  const name = v.project?.name ?? '';
  if (v.state === 'not_counted' && v.variant) return VARIANT_COPY[v.variant].stand(name);
  if (v.state === 'signed_out' || v.state === 'no_project') return NOT_ON_BENCH;
  if (v.state === 'not_counted') return STATE_COPY.not_counted.stand(name);
  return v.state === 'shipping' ? STATE_COPY.shipping.stand(name, v.rank, v.streak) : STATE_COPY.proven.stand(name, v.rank);
}

export function benchReply(v: BenchView): string {
  // A14: one https link a reply. Beside the state's action link the page is named without https.
  const page = v.handle ? `Your page: ${v.link && v.state !== 'signed_out' ? pageUrl(v.handle) : `${siteUrl()}${pagePath(v.handle)}`}` : null;
  const stand = [BENCH_HEADS.stand, standLine(v), ...(page && v.state !== 'signed_out' ? [page] : [])];
  const fund = fundLines(v);
  const money = [BENCH_HEADS.fund, ...(fund.length ? fund : [NO_MONEY_LINE])];
  const up = [BENCH_HEADS.up, v.held ?? v.ask.line];
  return [stand, money, up].map((x) => x.join('\n')).join('\n\n');
}
```

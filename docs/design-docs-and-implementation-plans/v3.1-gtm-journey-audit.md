## Growth review (Nikita Bier lens)

1. **The first 30 seconds decide everything.** The install is the hardest step and we make it harder with wrong copy. Grok Bot
   has `grokbot://app/v1/prompt?text=` (opens Grok Bot with the ask typed) and a true one-click once listed in the Cursor plugin
   marketplace (one listing covers Cursor and Grok Bot). Lead with a button, not instructions.
2. **Value before the ask.** The first reply must name money the builder can get, then the one step to unlock it.
3. **Don't lose the majority.** Vibecoders on Lovable/Bolt have no GitHub. Lovable and Bolt connect GitHub in two clicks; walk
   them there instead of "Okay."
4. **Make the money moment the share moment.** A coin launch, an acceptance and a first live page are the posts traders care
   about. Each must end in a one-tap post, and the launch must say "it's live" with the link.
5. **Every shared page is an install ad.** A visitor of a profile needs "Get your own page" with the same one-click install, and
   we must know which profile brought each install.
6. **Retention is a schedule, not a reminder.** The agent surfaces have schedulers; one yes sets a Monday check-in.
7. **Kill credibility leaks before launch.** One "Shipped timezone bug" on a shared page and traders read it as a joke.

## Strategy review (Peter Thiel lens) and decisions

- **One market first.** Grok Bot users are paying power users ($200/mo, 418K weekly): small, dense, high intent, the right
  monopoly to start. Win it completely before Muse (mass market, OAuth unclear) and Instinct (no MCP at all).
  Decision: Grok Bot gets the one-click install and the best path; Muse, OpenClaw, Hermes get correct copy only. No bearer-token
  fallback for Muse now (security surface, unproven demand).
- **Distribution is a product.** The Cursor marketplace listing is a distribution moat (two surfaces, one click). Decision:
  prepare the plugin package in the repo; the owner publishes (it needs his account).
- **The secret:** builders don't post, and an agent can post for them in one tap. Coins only make money when builders post.
  Decision: every money moment ends in a one-tap post; the coin is offered at the first moment the builder is proven
  (App-proven repo with code), not after the apply ask, and private repos with a public name can launch.
- **Quality is the moat, not volume.** The verified builder graph is what an ecosystem would buy. Decision: keep the proof
  gates (App-proven code before a coin), measure referrals without paying for them (no referral points: a farm magnet), and
  fix every credibility leak.
- **Don't build everything.** Cut: referral rewards, Muse token auth, Instinct, card redesign beyond what the post needs,
  new scoring. Ship four workstreams, nothing else.

## Build (four workstreams, separate branches)

- **W1 Install and arrival:** install sheet order and copy (Grok Bot button + fallback, Muse copy-message, OpenClaw with
  gateway stop/start, Hermes YAML), /docs, trusted Grok Bot OAuth callbacks, profile visitor CTA with the install sheet,
  `?ref=` attribution stored on the installation, Cursor plugin package for the owner to publish, llms.txt refresh.
- **W2 Reply journey:** value-first first reply; Lovable/Bolt no-GitHub path (no "Okay." dead end, no host-as-name, no
  "move to a coding agent"); hosted agents never told about "this folder"; ship question at most weekly; coin offer right after
  the builder is proven and before apply; private repos with a public name can launch; launch reply with text + one-tap intro
  post; backers asked gets backers; `tell submitted` works; acceptance gets congrats + post + page update; App-already-installed
  never re-asked; Monday check-in question for agents with schedulers.
- **W3 Credibility:** free summary never boasts a fix; qualify never says "You qualify" for team/company-only programs;
  one money headline that matches its rows; no guessed npm link; one rank format everywhere; one name casing.
- **W4 Share card:** card.png and the post card in the v3.1 site style; an unranked builder's card still shows project,
  live host and "Building since"; no octocat avatar.

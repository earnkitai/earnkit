**Status:** approved by the owner 2026-11-01 (answers below). This is the copy source for the v4.10 plan.

Owner, 2026-11-01: "it would be awesome if instead of asking, you'd find the best matching list of programs, pre-fill them and simply have them ready so I just have to say yes or no and it's all done for me."

## What changes from v4.8.1

- **Today.** EarnKit leads with one program and asks before each step: "Go?", then a draft, then the blanks, then "sent".
- **v4.10.** EarnKit picks the best programs, drafts every one of them before saying anything, and fills in everything it already knows. It then opens with the finished set. The builder answers once.

## The rules

1. **Which programs.** Up to 3, ranked by fit, then money, then time.
   - **Included:** real fits, grants one step away, and investor programs that close within 7 days.
   - **Left out:** anything closing before the step can be done, and anything the builder said no to, applied to, or already has a draft for.
2. **Pre-filled.** Every form field EarnKit can answer comes from the verified record or from the builder's earlier answers: team, money raised, contact details and the project fields. The builder is never asked the same thing twice across programs.
3. **One yes.** A yes means:
   - the agent does the steps it can (Builder Codes);
   - EarnKit re-checks them;
   - the agent opens each submit page with the answers ready.
   
   The builder only presses submit, or the agent does it in their browser when it can. EarnKit never says something was sent until the builder says "sent".
4. **"No", or a number to skip.** A no parks those programs. A number skips that one and keeps the rest.
5. **What EarnKit can't fill.** Something only the builder can provide (a pitch video, a legal entity) is named in the program's line. That program waits, and the others go.

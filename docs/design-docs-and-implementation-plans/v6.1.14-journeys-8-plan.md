- Builder text: no emoji, no em dash, never score, rank, grade, points, coin, token, streak; every builder line a full stop; never a tool, field or file name; money first, the gap, one action; yes means EarnKit does it or hands the builder the draft.
- Pinned texts updated, never loosened. Commit messages start with `v6.1.14:`. `pnpm -s programs:check` passes. Docs updated after the last task.

3. A chain object passed without `mainnet` keeps its chain.

# v3.8 G-A fix B: a submit host the official page links

Plan: v3.8 acceptance run G-A, failure item 6. Approval: earnkitai/earnkit#159. No flag of its own: it changes only
the automated lane (official-page check), which already runs for writes that send the check's fields.

## Problem

Growth's soonami Venturethon 11 write (`source_url` https://soonami.io/venturethon, `submission_url`
https://app.foundance.org/events/soonami-venturethon-11) was refused with
`submission_url: app.foundance.org is neither on soonami.io (the source's domain) nor a known submit platform`.

Root cause: `apiUrlProblems` (`lib/v5/api-text.ts`) refuses every builder link (`submission_url`, `pool_source_url`,
`form.url`) whose host is neither on the source's registrable domain nor on `API_SUBMIT_HOSTS`. It runs in
`apiRuleProblems` inside `writeRefusal`, before the automated lane reads the official page, so a link the official
page itself publishes was refused without the page ever being consulted. soonami's page links that exact Foundance URL
six times ("Open the application").

## Change

- `api-text.ts`: the off-site rule moves into `offSiteLinks(p)` (each off-site builder link with its problem, same
  wording as before). `apiUrlProblems` is built from it and returns exactly main's list.
- `programs-api.ts`: `writeRefusal(p, deps, at, offSite)`. `upsertAction` passes `'page'` only for an automated-lane
  write that carries every field `officialCheck` requires (`REQUIRED_CHECK_FIELDS`), so the page will be read. With
  `'page'`, when the only rule problems are off-site links, they are dropped here; with any other problem the write is
  refused here with every problem named (one answer, as before). `officialCheck`, after the quotes pass, calls
  `offSiteUnlinked(offSiteLinks(p), url, pageLinks(html, url))` and refuses whatever comes back.
- `official-page.ts`: `offSiteUnlinked` allows an off-site link only when
  1. the fetched official page links that exact URL (`sameLink`: host without www, path without trailing slash, query
     kept, fragment dropped), and
  2. the official page is not itself on a submit, hosting or shared platform (`linkPlatformName(host) === null`). On
     notion.site, dorahacks.io, devpost subdomains etc. other people's text and links can appear on the page, so its
     links vouch for nothing. Refusal wording names the platform.

A linked off-site link is on the page, so `linksOffPage` does not mark the program information only. Organizer status
is unchanged (soonami.io is not tied to soonami yet, so it is live as new organizer, `submit: builder`).

## Why this is safe

- Trust is the same as today's same-domain rule: the API already lets any page on the organizer's domain send
  builders anywhere on that domain. A link the organizer's own page publishes is the organizer's choice of form host.
- The link must still load (`writeRefusal` probes `submission_url` through `safeProbe`, unchanged), pass URL hygiene
  (`apiUrlProblem`, unchanged) and the page must still hold both quotes word for word (checked first).
- Exact URL, not just host: a page that links one Foundance event does not vouch for another.

## Held lane (EARNKIT_FLAGS unset, no check fields)

Unchanged. It never reads the page, so it keeps refusing an off-site host with main's message (test:
"a write without the check's fields keeps main's rule"). The owner approval path (`approveWrite`) also keeps
`'refuse'`. Choosing to keep the refusal rather than holding the write for approval keeps main's contract; Growth's
writer always sends the check's fields, so it takes the automated lane regardless of `auto_live`.

## Tests

`lib/v5/submit-host-linked.test.ts`, fixtures `lib/v5/fixtures/pages/soonami-venturethon.html` (trimmed from the page
saved in the G-A run) and `soonami-venturethon.payload.json` (Growth's payload; `verified_at` set to today in the
test). Fails on main (5 of 7), passes after:

- Growth's payload goes live: `created`, organizer `new`, `info_only` false; also with `auto_live` on.
- An unlinked Foundance URL, or the same host with a different path, is refused (`..., and the official page does not
  link it`), nothing live.
- A page on notion.site that links the URL is refused.
- Without the check's fields: main's refusal, page never read.
- With another rule problem (stale `verified_at`): both problems named, page never read.
- Pure: `offSiteLinks`, `apiUrlProblems` with and without `offSite: 'page'`, `offSiteUnlinked`.

No schema change, no new env var.

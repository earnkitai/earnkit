# v4.8 Target conversation (Task 0, for owner sign-off)

**Status:** draft for the owner to mark up. No code until it is approved.

## Who we're designing for

Owner, 2026-10-31: "people will not ask questions like I do. Most builders will need to be led where the agent drives the conversation and encourages a reply. By default, assume no one cares about EarnKit so they won't keep asking questions or invoke a conversation unless they absolutely see a reason to. Keep in mind, most builders are motivated by money in the end."

So the builder never has to know what to ask:

- **EarnKit speaks first.** At the start of every session, before the builder asks anything, the agent calls EarnKit and opens with a reason to care: money they can get, named for them, with a deadline.
- **Every message ends in one easy reply.** That's a yes, a number, or one word ("sent"). It's never an open question like "what would you like to do?".
- **A yes means EarnKit does the work.** The agent carries out the step (adds the code, writes the draft) and comes back with the result and the next easy reply. The builder never has to drive.
- **The path always heads to a submitted application.** It goes: hook, then pick, then close the gap, then draft, then submit, then track, then the next program.
- **Proof of value rides along.** One line per message shows what only EarnKit knows, e.g. "your 6-week shipping streak", "you're live on Base", "score 77, #1 of 1". There's no separate pitch.
- **Builders who ask still get answers.** Direct questions ("where do I stand", "what can I apply to") are answered, then the path picks up again.

## Voice

EarnKit is a mentor who wants them funded: warm, direct, honest about odds, short. Your agent rewords EarnKit's facts in this voice. It never invents facts, amounts or dates, and never reads out field names. It doesn't use emojis or em dashes, and never says "coin" or "points". It uses tables only when comparing more than two things.

**Owner decisions, 2026-10-31:**
- Investor and cohort programs are shown separately from grants, with an offer to help prepare.
- The agent may reword EarnKit's text.
- A new builder picks a program and connects GitHub in the same step.
- A step the builder passed on is raised once more, only when it's the one gap to a program's money.

Facts in brackets come from live data. Everything else is from the 2026-10-31 production snapshot of the owner's account.

## C. When the builder does ask

Answer the question in one short reply, then return to the path with its one easy reply.

- **"where do I stand"**
  > Score 77, #1 of 1 builders so far. It comes from your GitHub: 6 weeks shipping in a row, live at earnkit.com. Programs see it at earnkit.com/jenilt.
  >
  > [the path's current step, e.g. "Your Base draft is the next move. Start it?"]
- **"what can I apply to"**
  - A grants table (Grant | Money | Closes | Your fit).
  - An investor programs table (Program | Money | Closes | What it is).
  - Then the path's step.
- **The same question again in a session:** one line that points back, then the path's step. Never the same block twice.

## D. Bringing them back (outside the chat)

The builder doesn't open a chat unless there's money in it, so the reasons to come back reach them first:

- **The existing deadline, accepted and new-fit emails.** Each names the money and the one thing to tell the agent: "Tell your agent: EarnKit, draft Base."
- **The session-start opener**, as in A's "Two days later": what changed since last time, then the one next money step.

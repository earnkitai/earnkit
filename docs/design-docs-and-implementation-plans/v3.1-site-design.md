## Pages

- **Nav:** wordmark, Leaderboard, Feed, Docs, one blue "Add to your agent" pill. No Programs link.
- **Landing:** hero (chip "$N in grants open now" linking to #earn, "Earn from building." one line 96px Kaftan, one sub line, white CTA "Add EarnKit to your agent", agent marks Grok, Claude, Codex (OpenAI), Muse, white at 50%, no labels); "From commit to capital" (3 cards: thin blue line icons plug, rocket, coins at 56px, Kaftan titles); "Activity" (one row of 3 dark cards: X photo, name, X icon + @handle, score in band colour, summary, project and week; link "See the leaderboard"); "Earning opportunities" (4 program cards with real logos and the prize in Kaftan); full footer.
- **Profile:** blue hero card (photo, name in Kaftan, standing pill, @handle, X and GitHub icon buttons, Share; inset project panel with logo, name, Base square icon in a 20px white tile, one line, link); navy Shipping score card (ring); rust Streak card (12 squares, "This week: N commits" or "Ship by Sunday"); white Activity card (live dot "Shipped 2h ago" beside the title, week cards, quiet pagination); Token card (only with Backing open: coin, ticker, "Back <name> on Base", backers, earned, 12-week backers bars, "Back <name>", "<name> keeps 40% of fees"); Highlights card (verifiable milestones with icons: live since, Base Builder Code, contracts on Base, shipping since, applied to); minimal footer. No points, no Originality, no 52-week grid, no rank under 10 builders.
- **Leaderboard:** title, filter tabs All / Base / Backed, podium of 3 (blue, navy, rust) with metal rank pills, rows with photo, name, X icon + @handle, project, Backed tag, streak, score in band colour, quiet pagination.
- **Feed:** title with week tabs, 4 stat cards (builders shipped, commits, went live, applications sent), full-width rectangular dark rows (photo, name, X + @handle, project and week, summary, score), pagination.
- **Docs:** side nav, install card with per-agent tabs (Grok Bot first; commands from `app/components/sections/agents.tsx`, never invented) and copy button, three cards (week, score, money), selectors strip with the JSON URL.
- **404:** rust card "404", "Nothing shipped here.", "Back home".
- **Removed:** the programs list page (the landing section replaces it; program guide pages may stay for search but are not linked from the nav).

## Rules for the build

- No new paid service; fonts and paintings are static files served by the app.
- Every number on a page comes from real data; example data on the canvas is labelled and never ships.
- Copy rules from the brief apply (no em dashes, sentence case, "points" never shown until $EARN, "of N builders" only from 10 ranked).

## F1 Token questions get a pitch or a bare status
- Source: `tokenAsk()` bench-find.ts:1588-1612 (the handler for `tell {token:'ask'}`). Constants: `TOKEN_NOT_YET` (1581, "You don't have a token yet. Want me to launch it?"), `TOKEN_ALREADY_LIVE` (1480), `TOKEN_STAYS_OFF` (1482).
- Why: the function treats `token:'ask'` as "show status or offer", never "answer a question". With a row it returns the status constant (no link, no numbers). With no row it stores a `kind:'token'` ask and pitches. The question text is never passed in, and the reply carries no `facts` (only find and score get `withFacts`, tools.ts:2608/2646/2778).
- Fix: in `tokenAsk`, build the live/on-its-way/declined reply from `builderToken(id)` plus the `tokenCard` data (site-data.ts:464: `tradeUrl(coin)`, `backersOfCoin`, `allTimeCommunityUsd`), e.g. "Your $SYM is live: <trade link>. N backers, $X in fees, 40% of every trade fee goes to you." For no token, answer with the TOKEN_SENTENCE facts (bench-reply.ts:206) and keep the offer as a trailing question only when step 3 is not due. Also add a `token` entry to `aboutFacts` (F10) so the agent can answer without this tool.

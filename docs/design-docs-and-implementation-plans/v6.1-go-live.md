# EarnKit v6.1 go-live (owner steps)

v6.1 adds GitHub sign-in, the builder's record, `/me`, the `record` and `screen` tools and the screen queue. No new
environment variable beyond the two GitHub OAuth values below. Run the steps in this order after the merge and
deploy (`pnpm db:migrate` runs in `predeploy`).

1. **Create a fresh GitHub OAuth app** (GitHub, Settings, Developer settings, OAuth Apps, New OAuth App):
   Homepage URL `https://earnkit.com`, Authorization callback URL `https://earnkit.com/auth/github/callback`,
   "Enable Device Flow" left off. Generate a client secret. On Railway set `GITHUB_OAUTH_CLIENT_ID` and
   `GITHUB_OAUTH_CLIENT_SECRET` to the new values (replacing the v4 values). Until both are set, `/link/<code>` and
   the callback answer 503 "GitHub sign-in is not set up yet." and everything else works as v5.
   Note: the OAuth app may also be the old v4 app, with its callback URL changed to
   `https://earnkit.com/auth/github/callback`; then keep its client id and generate a new secret.
2. **Sign in once yourself.** In your own agent, call `find` (or `record`); open the `earnkit.com/link/<code>` it
   shows, confirm, sign in with GitHub, and check that `https://earnkit.com/me` shows your record, your applications
   and the agent you linked.
3. **Mark each pilot program's reviewer.** The reviewer signs in once first (step 2, from their own agent). The
   endpoint needs the programs API on: `EARNKIT_PROGRAMS_TOKEN` set (32 characters or more) and `EARNKIT_PROGRAMS_API`
   not `off`, `0` or `false`. While it is off the endpoint answers 404. Then:

   ```bash
   curl -X POST https://earnkit.com/api/programs/reviewers \
     -H "Authorization: Bearer $EARNKIT_PROGRAMS_TOKEN" \
     -d '{"program_id":"...","github_login":"...","contact":"..."}'
   ```

4. **To run a screen now** (instead of waiting for the daily cron), with the `job_id` the reviewer's `screen` call
   returned. A triggered run may take up to 10 minutes, so do not set a short `--max-time` on the curl (allow 660
   seconds):

   ```bash
   curl --max-time 660 -X POST https://earnkit.com/api/cron \
     -H "Authorization: Bearer $CRON_SECRET" \
     -H 'content-type: application/json' \
     -d '{"job_id":"..."}'
   ```

5. **The Grok Bot's instructions gain the catalog fields** (`submit`, `sign_in`, `needs`, `min_tier`, `prefers`, and each
   requirement's `kind` and `guidance`), as listed in `docs/programs-api.md`, so the programs it adds carry them.
6. **Reconnect EarnKit in each agent.** Remove the EarnKit connector and add it again in every agent you use, so the
   four tools (`find`, `track`, `record`, `screen`) show.

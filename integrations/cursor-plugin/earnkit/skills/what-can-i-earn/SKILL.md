# What can I earn?

1. Call the EarnKit `find` tool with `project` filled from this folder, never asking the builder: the name and one
   line on what it does from the README, `repo_url` from the git remote, `live_url` from the README or deploy config,
   and the first and last commit dates from git log.
2. Answer in your own words from its reply. Draft each form from its fields; submit only when the builder says yes.
3. After each submission, and each answer about a result, call `track`.

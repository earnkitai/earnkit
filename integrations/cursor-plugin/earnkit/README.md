# EarnKit for Cursor and Grok Bot

Get funded for shipping. EarnKit finds the grants you fit, drafts the application from what you ship, and ranks how
steadily you ship on a public leaderboard. Free.

## What it adds

| Part | What it does |
|---|---|
| MCP server `earnkit` | https://earnkit.com/mcp (remote, OAuth). Tools: find, prepare, tell, score |
| Skill `/what-can-i-earn` | Asks EarnKit what you can earn for the project in this folder |

## Use it

1. Install the plugin, then choose Authenticate on the EarnKit server and sign in with X.
2. Ask your agent: "What can I earn?"

Your X account is your EarnKit page: earnkit.com/<your handle>. EarnKit only reads your code through its read-only
GitHub App when you pick the repos. It never posts for you.

More: https://earnkit.com/docs

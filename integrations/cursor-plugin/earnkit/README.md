# EarnKit for Cursor and Grok Bot

Get funded for what you ship. EarnKit finds the grants, hackathons and programs your repo fits and drafts every
application. Free.

## What it adds

| Part | What it does |
|---|---|
| MCP server `earnkit` | https://earnkit.com/mcp (remote, OAuth). Tools: find, track |
| Skill `/what-can-i-earn` | Asks EarnKit what the project in this folder can earn |

## Use it

1. Install the plugin, then choose Authenticate on the EarnKit server. It connects at once. No account needed.
2. Ask your agent: "What can I earn?"

EarnKit reads public repos only. It never submits or posts for you.

More: https://earnkit.com/docs
